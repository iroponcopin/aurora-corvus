更新履歴

OUKA・Cherry・Aureum の更新履歴と、Alpha の終了のお知らせ。ブランドを選ぶと、各リリースの変更点を新しい順に見られます。

最終更新 2026-09-29

表示されているダメージ・速度などの数値は導入時点の既定値です。サーバー側の config 調整により、実際にプレイして体感する数値とは異なる場合があります。

条件に一致する更新はありません。

新機能

和室を建てるための 30 品と、工業化の第 2 弾の設備 10 種が入りました。畳と縁側、障子と襖、欄間と屏風、座卓と箪笥、掛け軸と香炉、灯籠と鹿威しと風鈴、それに碁盤。工場の側には、壁越しに品を送るトランシーバー、渡した道具で掘る採掘機、サイロから直接取り出す I/O バスなど。新しい音はすべて一から合成しました。

変更点 (10)

  • 畳: 本藺草の畳は 2 マスで 1 枚、縁は 4 種。8 マス以上つながった畳の部屋に立つと、食べ物の減りが半分になります。縁なし市松畳は並べると市松模様に。
  • 障子と襖: 素手かレッドストーンで、約 1 ブロック滑って開きます。2 枚並べれば引き違いにすれ違います。襖は 4 枚並べると、1 枚の金箔の山水画に。
  • 鴨居と長押: 透かし彫りの欄間が嵌まり、掛け軸・刀掛け・暖簾・簾・風鈴を掛けられます。暖簾はくぐった側がめくれ、簾は 3 段まで継いで 1 本に。
  • 調度: 座布団と座椅子に座れ、座卓には品を 4 つまで飾れます。桐箪笥は 27 枠。抹茶は点てて飲むと体力が満ち、採掘速度上昇 II が 3 分(5 分に 1 服)。
  • 床の間と坪庭: 掛け軸はゲームの中の 8 日ごとに季節の絵に替わり、雪見灯籠は冬に雪をかぶります。鹿威しは 4.4 秒ごとに石を打ち、風鈴は風で鳴ります。
  • 空間転送トランシーバー: 共振リンカーで結ぶと、壁を越えて 32 ブロック先まで、1 tick に最大 1 スタックと 1 バケツ。1 台から最大 4 台へ送れ、電気は要りません。
  • 自律共振式の掘削機: 渡したつるはしかシャベルを使い、速めなければ、人が掘るのと同じ時間で掘ります。シルクタッチも幸運も効き、範囲は最大 5×5、深さは 16 まで。
  • 量子サイロ直結 I/O バス: 選んだ品を 9 種まで、決めた数を残して 1 tick に 256 個まで取り出します。OUKA のコンベアへは 1 tick に 1 個。
  • インパルス・ホッパーと造石機: ホッパーはチェストや管へ 1 tick に 64 個(OUKA のコンベアへは 1 個)。造石機は溶岩と水を 1 バケツずつ入れれば、減らさずに、電力網の電気で丸石・砂利・砂・鉱砂を作り続けます。
  • ほかに: 3×3 のクラフター、1 tick に 8 バケツを送るポンプと導管、経験値をカプセルにためる粉砕機、別の次元からでもサイロを開ける端末、OUKA の機械を ×10 まで速める加速コア。

注意点 (3)

  • V1.0.1・V1.1.0・V1.2.0 で鳴っていなかった 2 つの音を直しました(OUKA ビーコンの端末の目盛りの音・桜花の杖の選択盤で選ぶ音)。前の版をお使いの方は入れ替えてください。
  • Corvus Store からも入れられます。初回は Corvus Store の「入手」を押してください。その後は Corvus Store が新しい版に自動で入れ替えます(「自動アップデート」を切っている場合は「アップデート」を押してください。手で入れる場合は OUKA のページから)。
  • Minecraft 26.3、Fabric Loader 0.19.5 以上、Fabric API 0.161.0+26.3 以上、GeckoLib 5.5.6(zip に同梱)、Java 25 が必要です。

新機能

Cherry でいちばん大きな更新です。一人称の動きと反動を持つ次世代の銃 5 丁、月に棲む 3 種の生き物、月の遠くの遺構に封じられたボス「ルナリス・プライム」、寒さと鉄の砂塵嵐の赤い惑星・火星、アペックス 1 を 3 つの世界のどこへでも飛ばす航法コンソール、そして銃・弾倉・乗り物の部品をすべて作る「高度分子加工機」が入りました。

変更点 (8)

  • 銃 5 丁: CR-14 ブルパップ突撃銃、CP-9 短機関銃、CS-50 対物レール狙撃銃、CX-12 マグパルス散弾銃、C-Pistol タクティカルハンドガン。右クリックで狙うと狙った先より手前と奥がなだらかにぼけ、R で装填(サバイバルでは装填ごとにその銃の弾倉を 1 つ使う)、F で確認。反動・発射の炎・薬莢・ホログラフィック照準、CS-50 の 6 倍サーマルスコープ、C-Pistol のレーザーサイトつき。
  • 月の生き物: 月面の下に潜み、しゃがまずに歩く者へ跳びかかって与圧スーツに穴を開けるセレナイト・ストーカー、EMP で銃の照準と弾数の表示を消すヴォイド・ドリフター、地面を打って人を空高く跳ね上げ、溶けた隕石を投げつけるレゴリス・デバウラー。
  • ルナリス・プライム: 月の 8,000 ブロックより遠くの巨大クレーターに「星核の牢獄」があります(/locate で見つかる)。封印の制御盤にアストラル・カタリストを注ぐとボスが目覚め、空が深紅に染まり、体力が半分になると装甲が飛び散って速い第 2 形態になります。
  • その遺物: ルナリスの星核破片、重力崩壊砲(撃つとブラックホールが開く)、セレーネの天球冠。
  • 火星: 発射台の上で発射キーを押すとアペックス 1 のステラ・ナビゲーション・コンソールが開き、地球・月・火星を選べます。火星は 0.38 G、−60 °C の吸えない空気。与圧スーツが空気を防ぎ、鍛冶台で縫い込む耐寒の内張りが寒さを防ぎます。
  • 火星には約 20 分ごとに鉄の砂塵嵐が吹き、霧が数ブロック先まで迫り、Cherry の HUD に雑音が走ります。
  • 火星の資源: 火星赤色フェライトと過塩素酸エナジーソルト。過塩素酸推進剤は推進剤キャニスター 3 本ぶんのロケット燃料です。
  • 高度分子加工機: レシピを選んで 6 つの口に材料を入れると、銃・弾倉・銃の部品・燃料・すべての乗り物を作ります。コズミック・ヘリウム3・セルとルナ・レゴリス・コアから補助ブースターとレールガン砲身を量産し、ブースターで Apex-1 を、砲身で Dreadnought級を組み立てます。ホッパーでも材料を入れられます。

注意点 (1)

  • Minecraft 26.3、Fabric Loader 0.19.5 以上、Fabric API 0.161.0 以上、GeckoLib 5.5.6 以上、Java 25 が必要です。

新機能

変更点 (3)

  • Alpha を無効化します。13 の MOD は、ゲームに何も足さないプレースホルダーに置き換わります(Cherry・OUKA・Aureum には触れません)
  • オーバーワールドの高さの上限(Y=1023)だけは残します。Y=319 より上に普通のブロックで建てたものを消さないためです
  • Corvus は古い jar を消してプレースホルダーを置き、置き換えたファイルのバックアップを残します。手で入れた場合とサーバーは、pack の README のとおりに古い jar を消してください

注意点 (3)

  • 先にワールドのバックアップを取ってください。Alpha が足したブロックは、Alpha 無しで開くと空気になり、1 度保存されると完全に消えます。Alpha を戻しても戻りません(専用サーバーで確認しました)。Alpha のアイテムと生き物も同じように消えると考えられます(試していません)
  • サーバーとプレイヤーは同時に移ってください。Alpha を残したプレイヤーは Alpha をやめたサーバーに入れず、その逆も同じです
  • Corvus の「アップデートを自動でインストールする」をオンにしている場合、この更新は確認なしで適用されます。Corvus のバックアップは mods フォルダーのもので、ワールドは含まれません

新機能

重工業の機械と道具が 20 種類入りました。電力網と発電所、巨大な格納庫、コンベアとドローンの物流、精錬と加工、採掘と自動の収穫、そして現場の道具と防護外骨格。どの機械も数字が増えるだけの箱ではなく、腕・ハンマー・ドリル・ローターが実際に動き、働きぶりに合わせて音が変わります。V1.1.0 の 2 つの欠陥もこの版で直しました。

変更点 (10)

  • 電力網: テスラパイロンが 64 ブロック以内で無線につながり、機械へ放電の弧が走ります。ケーブルは要りません。
  • 発電と蓄電: 核分裂リアクター(最大 2 MW。800 °C でスクラムし、爆発しません)、夜も蓄えから出し続ける太陽熱タワー、400 MJ の超伝導蓄電ブロック。
  • 超次元量子圧縮サイロ: 5×5×7 を組むと 2,147,483,647 個まで。名前でも「@MOD 名」でも探せます。
  • リニアコンベアは毎秒 20 個。形は隣から自動で決まり、品はベルトに載ったまま見え、落ちず、詰まれば並んで待ちます。分岐器と、6 方向へ振り分けるソーターも。
  • 物流ドローン: 航路カードで港どうしを結ぶと、荷を積んで往復します。区画が読み込まれていなくても、飛ぶ時間ぶん遅れて届きます。
  • 精錬と加工: 32 個を 16 倍の速さで溶かす電弧炉、粉 2 つと板を作る油圧クラッシャー、3 本の腕が溶接する組立ライン、チタン・リチウム・ヘリウム3 を取り出す遠心分離機。
  • 採掘と収穫: 岩盤を壊さずに鉱石と原油を掘り続けるクァーリー、毎秒 200 バケツの取水タービン、木を切って板にし植え直す製材ミル、培養槽。
  • 万能工業ラチェット(機械の反転・出口の開け閉め・×2.50 までのオーバークロック)と熱分解カッター(1 秒で機械を中身ごと回収)。
  • 回路投影ブループリント: 1 辺 16 マスまで写し、実物大のホログラムで確かめてから、持ち物の品で建てます。
  • 全天候型防護外骨格: 感電・熱・落下で傷つかず、溶岩を泳げ、採掘は 3 倍の速さ。

注意点 (3)

  • V1.1.0 の 2 つの欠陥を直しました(桜花合金ブロックを掘っても何も落ちない・シェルターの落とし物の表)。V1.1.0 をお使いの方は入れ替えてください。
  • Corvus からも入れられます。初回は Corvus の「ダウンロード」ボタンを押してください。その後は Corvus が新しい版に入れ替えます(手で入れる場合は OUKA のページから)。
  • Minecraft 26.3、Fabric Loader 0.19.5 以上、Fabric API 0.161.0+26.3 以上、GeckoLib 5.5.6(zip に同梱)、Java 25 が必要です。

新機能

音の出力の機器が変わると(イヤホンの抜き差し、設定で機器を選ぶ)、ゲームは音のエンジンを作り直し、鳴り続ける音をすべて止めます。1.1.0〜1.1.3 では、そのあと Cherry の飛行機のエンジン・アフターバーナー・ミサイルのモーター・ロックの音と、宇宙服の呼吸が、乗り直すかヘルメットを被り直すまで消えたままでした。いまはひとりでに鳴り直します。

変更点 (2)

  • 音の機器が変わっても、Stratos-900 と Aegis-X のエンジン、Aegis-X のアフターバーナー、ミサイルのモーター、ロックの音が、すぐにひとりでに鳴り直します。
  • 月では、宇宙服の呼吸も同じように鳴り直します。

注意点 (1)

  • Minecraft 26.3、Fabric Loader 0.19.5 以上、Fabric API 0.161.0 以上、GeckoLib 5.5.6 以上、Java 25 が必要です。

新機能

飛行機と艦の操縦を、誰でも動かせるよう作り直しました。視点の固定をやめ、飛行機は見た方へ飛び、艦はボートと同じ W・A・S・D で動きます。Dreadnought の主砲の弾も、当たった物に傷を与えるようになりました(1.1.0〜1.1.2 の弾は何も傷つけていませんでした)。

変更点 (11)

  • 飛行機は見た方へ飛びます。頭を向けると、Stratos-900 も Aegis-X もひとりでに傾いて、その方へ回り、上り、下ります。W と S で推力、左クリックで Aegis-X のミサイル(目標はレーダーが自動で選びます)。
  • フラップ・脚・ブレーキ・逆推力・アフターバーナー・キャノピー・着艦フックは自動になりました。乗ると、操作の案内が画面に出ます。
  • 視点は自由です。一人称に固定されず、機体と一緒に傾きません。飛行中も F5 が使え、左 Alt を押している間は、機体の向きを保ったまま見回せます。
  • 艦: 持ち場に立つと、就くキーが画面に出ます。舵輪では W と S で機関(0 より下で後進)、A と D で舵。離すと舵は中央に戻り、その方位を保ちます。スニークで離れます。フェリーの扉は Y です。
  • 砲術士のいない Dreadnought では、操舵手が舵輪から撃てます(左クリックで斉射、右クリックで VLS)。
  • 1.1.2 の艦の不具合を直しました: 舵がキーと逆に回った、後進が効かなかった、岸から艦を降ろせなかった(いまは狙った水面のすぐ先に、艦尾を手前にして浮かびます)、サバイバルで艦を回収できなかった。
  • 主砲の弾は、進む先で最初に当たったブロック・生き物・艦・飛行機で炸裂し、周り 4 m に傷を与えます。1 つの目標に落ちた斉射は 6 発すべてが数えられます。艦や飛行機のどこを見ても、2 基の砲塔はその点へ向きます。
  • 撃った艦とその乗組員は傷つけず、ブロックは決して壊しません。1 回の斉射で沈む艦や落ちる飛行機はありません。砲を扱っている間に、遠くのチャンクを読み込まなくなりました。
  • 名前を付けた物を手に持った人が Cherry の兵器で倒したとき、死亡メッセージが翻訳されない文字列のまま出なくなりました。
  • Aegis-X の飛行表示の左下にあるミサイルの数が、画面の下端で切れなくなりました。GUI の大きさが「自動」のとき、720p・1440p・4K やゲームの既定の窓など、多くの画面の大きさで切れていました。
  • 海図の航路の点は、いちばん広い縮尺で見える範囲(艦から約 1.4 km)の中だけ受け付けます。不正な航路の要求からサーバーを守るためでもあります。

注意点 (3)

  • 操作のキーが変わりました。1.1.2 の飛行機のキー(R・U・Y・K・Z・N・M・J と矢印キー)と舵輪のキー(, . = - ; ')は無くなり、割り当て直していても使われません。
  • 主砲の弾は、ほかのプレイヤーの艦や飛行機も含め、当たった物を傷つけます。傷は砲を指揮している乗組員のものとして数えられます。
  • Minecraft 26.3、Fabric Loader 0.19.5 以上、Fabric API 0.161.0 以上、GeckoLib 5.5.6 以上、Java 25 が必要です。

新機能

Leviathan 級と Dreadnought 級に本番の模型と艦内が入り、艦の持ち場がすべてゲームの中から使えるようになりました。1.1.0 と 1.1.1 では、レールガン・VLS・海図台を実際には使えませんでしたが、使えるようになりました。

変更点 (6)

  • 本番の艦: 船体・甲板・艦内を作り込みました —— フェリーの車両甲板・客室ラウンジ・展望デッキ・艦橋と、駆逐艦の艦橋・CIC・格納庫。窓は向こうが透けて見え、夜は灯ります。見えている甲板は、どれも歩けます。
  • 持ち場: 舵輪・海図台、駆逐艦の砲術席・ソナー席の前で持ち場のキー(既定は H)を押すと就きます。海図台ではクリックで航路を引く海図が開き、新しいソナー席は回る走査の画面に探知した相手を映します。
  • Dreadnought 級は 406mm 電磁レールガンの 3 連装砲塔 2 基に。2 基とも見ている点へ向き、左クリックで一斉射 —— 砲口の閃光、衝撃波の輪、弾道の光、後退する砲身。右クリックでは、レーダーでロックした目標へ、ハッチが開いてから白煙を噴いて VLS を撃ちます。
  • Leviathan 級のバウバイザーと船首・船尾ランプ: 止まっている時に舵輪で扉のキー(既定は ')を押します。バイザーが上がってからランプが下り、すべて閉じるまで機関は推力を出しません。下ろしたランプは歩いて上れます。
  • 引き波と泡: 進む艦はケルビン角に開く船首の波を立てて航跡を残し、回るスクリューは泡をかき立てます。
  • 舵輪のキーが Minecraft 自身のキーと重ならなくなりました: , と . で舵、= と - で機関、; で針路保持。舵輪の計器は、ホットバーと体力に重ならず、その上に出ます。

注意点 (2)

  • 舵輪のキーは名前が変わったため、1.1.0・1.1.1 で変更した割り当ては引き継がれません。付け直してください。
  • Minecraft 26.3、Fabric Loader 0.19.5 以上、Fabric API 0.161.0 以上、GeckoLib 5.5.6 以上、Java 25 が必要です。

新機能

ビデオ設定の「透明物の描画の改良」を有効にしていると、Cherry Aegis-X のアフターバーナーを点けた瞬間にゲームが落ちていました。直しました。

変更点 (1)

  • 「透明物の描画の改良」が有効でも、飛行中にアフターバーナー(既定は Z)を点けてもゲームは落ちません。噴流のショックダイヤモンドは、コックピットからキャノピー越しにも見えます。

注意点 (1)

  • Minecraft 26.3、Fabric Loader 0.19.5 以上、Fabric API 0.161.0 以上、GeckoLib 5.5.6 以上、Java 25 が必要です。

新機能

The wide blue halo behind your account picture is gone as well.

Verified by photographing the running window over a flat neutral desktop, which is the only way to tell the app's own painting from the desktop showing through: with the glass on, the window's empty field is perfectly flat and the cards sit inside the reference's own range; with it off, the atmosphere returns as designed. The macOS, Windows and Linux installers for this version were built by CI on each of those systems, but only the macOS build has been run.

Stops Corvus asking you to update forever. Every 1.8.1 build reported itself as "1.8.0" no matter what it actually was, so it compared itself against the published 1.8.1, decided it was out of date, and offered an update — which installed another build that also said 1.8.0, so the offer came straight back. Taking 1.8.2 once ends the loop: 1.8.2 correctly reports 1.8.2. This affected Windows, macOS and Linux alike; macOS simply hit it first. The version now comes from the build itself rather than a number someone had to remember to edit, and the release pipeline refuses to publish a build whose reported version disagrees with the version it was built as.

Fixes the Windows installer. 新機能

Fixes a bug that could leave your Minecraft unable to start. If you installed the mod pack by hand before pointing Corvus at the folder — which the guide tells you is fine — the first update added the new mod files but could not remove the old ones, because it had no record of what was already there. Two copies of the same mod stops the game loading. Corvus now recognises the pack's own files by name, so superseded ones are removed whether or not it has a record, and it checks afterwards that only one copy of each mod is left. Your own mods are never touched: only files matching the pack's exact naming are removed, everything is backed up first, and each removal is written to the log.

新機能

Corvus can now update itself. From this version on you should not need to visit this site again: when a new Corvus is released it downloads it, checks it against the SHA-256 published here, replaces itself and reopens. It always asks first, even with automatic updates turned on — restarting the app while you are using it is not something it should decide on its own. If anything goes wrong the previous version is put back automatically: the new build has to actually start before the old one is discarded. Two honest limitations. On Linux the .deb needs administrator rights that Corvus cannot request, so it downloads and verifies the file and then shows you the exact command to run — it does not pretend to have installed it. On Windows the update reinstalls the MSI, which means Windows will show its usual permission prompt. This release also follows the site to its new address; if you are on 1.4.0 or earlier you need to download once from here by hand, because those versions are still looking for the old address and cannot be reached.

A completely rebuilt interface. Settings is a proper settings screen rather than a row of plain controls. Nothing about how updating, Play or Settings work has changed, and your existing settings carry over untouched. Two practical notes: the interface is dark only for now, and the cross-platform jar is considerably larger than before (about 10 MB rather than 1 MB) because the new interface toolkit is bundled inside it — the native installers already included it, so their size barely moved. If you use the jar and would rather not download that each time, the native installer for your system is the better option.
