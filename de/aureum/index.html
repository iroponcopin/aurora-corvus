Aureum (leichte Optimierungs-Mod, separater Download)

Aureum ist eine eigenständige Mod, getrennt vom Alpha-Pack. Sie optimiert Spiellogik, Speicher und Server-Tick-Kosten und rührt bewusst nie die Chunk-Render-Pipeline an. Sie ersetzt Sodium nicht — sie optimiert die Seite, die Sodium nicht anfasst, also lässt sie sich gefahrlos zusammen mit Sodium betreiben. Für mehr FPS installieren Sie Sodium separat.

Bisher gemessen: −6,3 MB bei 2.209 geladenen Chunks, −17,2 MB nach dem Generieren eines ähnlich großen neuen Geländes (in zwei unabhängigen Läufen reproduziert). Die MSPT (Tick-Zeit) bleibt innerhalb der Messtoleranz unverändert. Zwei clientseitige Optionen (Partikel-Obergrenze, Render-Distanz für Block-Entities) sind standardmäßig deaktiviert und ungemessen, da diese Entwicklungsumgebung keinen Client hat. Installation und Konfiguration siehe README auf GitHub.

Jede Optimierung lässt sich einzeln abschalten

Jeder Schlüssel in config/aureum.json lässt sich unabhängig von den anderen abschalten. Wird einer abgeschaltet, werden Aureums Bytecode-Änderungen für dieses Feature überhaupt nicht mehr angewendet — die stärkste Garantie, die es gibt, falls es je mit einem anderen Mod kollidiert.

Voraussetzungen

  • Minecraft 26.2 (Fabric)
  • Fabric Loader 0.19.3+
  • Fabric API
  • Java 25+
