Discord-Bot

Corvus meldet neue Versionen, sagt deinem Server, was als Nächstes kommt, und sammelt Fehlermeldungen und Wünsche – in der Sprache, die dein Server wählt.

Bot zum Server hinzufügen

Öffnet Discords eigene Berechtigungsseite. Du brauchst „Server verwalten“ auf dem Zielserver.

Eine statische Seite kann nicht sehen, ob der Bot gerade online ist. Das sind die Angaben, die diese Seite für ihn veröffentlicht.

Einrichtung

  1. 1. Bot hinzufügen

    Nutze den Button oben. Er fragt vier Dinge ab – Kanal sehen, Nachrichten senden, Links einbetten, Verlauf lesen – plus das Recht, pro Meldung einen Thread zu öffnen. Administrator verlangt er nie.

  2. 2. Kanal wählen

    Führe /release channel aus und wähle, wohin Ankündigungen gehen. Das wird der Standard: Alles ohne eigenen Kanal landet hier.

  3. 3. Sprache wählen

    Führe /language set aus. Dreizehn Sprachen, jede in ihrer eigenen Schrift aufgeführt.

  4. 4. Aufteilen (optional)

    Mit /channels set bekommen Updates, Vorschauen, Fehlermeldungen und Wünsche je einen eigenen Kanal. Was du nicht setzt, nutzt weiter den Standard. updateupcomingbugrequest

Was der Bot von sich aus postet

Drei Dinge, jeweils in ihren eigenen Kanal, falls eingerichtet. Nichts wird zweimal gepostet.

  • Eine Version erscheint – das Modpack, und Corvus selbst, wenn du das eingeschaltet hast.
  • Etwas wird vorab angekündigt, direkt von der Seite „Als Nächstes“.
  • Jemand meldet einen Fehler oder äußert einen Wunsch, mit einem Thread für die Diskussion.

Alle Befehle

/bug

Einen Fehler melden und verfolgen, was daraus wird.

BefehlWas er tutWer ihn nutzen kann
/bug newÖffnet ein kurzes Formular: eine Zeile Zusammenfassung, was passiert ist, und – falls bekannt – wie es sich wiederholen lässt.Alle
/bug list <status>Zeigt die Meldungen dieses Servers, offene zuerst. Nur du siehst die Antwort, also prüfe hier vor einer Doppelmeldung.Alle
/bug close <number> <resolution>Markiert eine Meldung als erledigt und hält fest, wie sie gelöst wurde.Server verwalten
/bug reopen <number>Holt eine geschlossene Meldung zurück auf die Liste, falls sie doch nicht behoben war.Server verwalten

/channels

Jede Art von Nachricht in einen eigenen Kanal schicken.

BefehlWas er tutWer ihn nutzen kann
/channels set <kind> <channel>Richtet eine Kategorie – Updates, Vorschau, Fehlermeldungen oder Wünsche – auf einen bestimmten Kanal.Server verwalten
/channels showListet auf, wohin jede der vier Kategorien derzeit geht.Alle
/channels clear <kind>Schickt diese Kategorie wieder in den Standardkanal des Servers.Server verwalten

/language

Die Sprache wählen, in der dieser Bot auf diesem Server schreibt.

BefehlWas er tutWer ihn nutzen kann
/language set <language>Legt die Sprache fest. Ankündigungen, Formulare und Antworten folgen ihr ab sofort.Server verwalten
/language showZeigt, auf welche Sprache dieser Server eingestellt ist.Alle

/release

Update-Ankündigungen für das Modpack und für Corvus.

BefehlWas er tutWer ihn nutzen kann
/release channel <channel>Legt den Standardkanal fest. Alles ohne eigenen Kanal landet hier.Server verwalten
/release statusZeigt alles, worauf dieser Server derzeit eingestellt ist.Alle
/release latestZeigt die neueste bekannte Version, ohne sie im Kanal anzukündigen.Alle
/release enableSchaltet die Ankündigungen für diesen Server wieder ein.Server verwalten
/release disableStoppt die Ankündigungen, ohne den Bot zu entfernen oder Einstellungen zu verlieren.Server verwalten
/release launcher <enabled>Wählt, ob auch Corvus-Launcher-Builds angekündigt werden.Server verwalten
/release upcoming <enabled>Schaltet Vorankündigungen ein oder aus und zeigt, was als Nächstes kommt.Alle
/release testPostet eine Beispielankündigung, damit du Kanal und Rechte prüfen kannst.Server verwalten

/request

Eine Funktion oder Änderung wünschen und verfolgen, was daraus wird.

BefehlWas er tutWer ihn nutzen kann
/request newÖffnet ein kurzes Formular: was du dir wünschst und warum es helfen würde.Alle
/request list <status>Zeigt die Wünsche dieses Servers, offene zuerst. Nur du siehst die Antwort.Alle
/request close <number> <resolution>Markiert einen Wunsch als erledigt und hält die Entscheidung fest.Server verwalten
/request reopen <number>Holt einen geschlossenen Wunsch zurück auf die Liste.Server verwalten

Drei Meldungen einer Art pro zehn Minuten, pro Person, pro Server. Fehlermeldungen blockieren nie deine Wünsche.

Dreizehn Sprachen

Die Sprache wird pro Server gewählt, nicht pro Person: Ankündigungen landen in einem gemeinsamen Kanal, und alle dort sollen dasselbe lesen. Formulare, Antworten und Fehlermeldungen folgen derselben Einstellung.

Was gespeichert wird

Zu einer Meldung gehören: was du ins Formular geschrieben hast, deine Discord-Benutzer-ID und dein Anzeigename, und wo sie gepostet wurde. Mehr nicht. Der Bot speichert keinen Nachrichtenverlauf, liest keine Kanäle, auf die er nicht gerichtet wurde, und hat nichts mit deinem Minecraft-Konto zu tun.
