Übersicht: Über die Installation von Glimpse Alpha

Glimpse Alpha (ehemals: Sorakaze) ist die Sammlung von Fabric-MODs, die auf dem Sorakazekarasu-Server installiert ist. Sie besteht aus 11 unabhängigen MODs, die sich jeweils einzeln installieren und aktualisieren lassen. Vanilla-Inhalte (der Standardumfang ohne MODs) wie Bogen und Pfeil oder Loren werden weder ersetzt noch entfernt – stattdessen kommen neue Gegenstände, Blöcke und Dimensionen hinzu.

MODInhalt
SchusswaffenFernkampfwaffen, die es in Vanilla nicht gibt (Sturmgewehr, Schrotflinte, Scharfschützengewehr usw.)
SchienenverkehrEin Zug, der stetig schneller wird, sowie ankuppelbare Personen- und Güterwagen
Baumaterial & DekoBaumaterial für den Städtebau wie Ampeln und Leitplanken sowie Haushaltsgeräte wie Überwachungskamera, Geldautomat und Aufzug
FahrzeugeAutos, Busse, Flugzeuge und mehr
BosseMächtige Gegner und ihre eigene Drop-Ausrüstung
HimmelDie neue Dimension „Himmel“ mit der dort lebenden Engelsstadt und dem Königreich
SurvivalNeue Erze und Rüstungen sowie Alltagselemente wie Temperatur und Jahreszeiten
StromEin Netz zur Stromerzeugung und -übertragung sowie elektrisch betriebene Geräte
BackroomsErkundung einer Zwischenwelt mit Sanity-System

Die genauen Gegenstände und Rezepte der einzelnen MODs findest du in der Rezeptsammlung, alle bisherigen Änderungen im Änderungsprotokoll.

Für die MODs wird „Fabric“ benötigt

Fabric ist die Grundlage, die es Minecraft überhaupt erst ermöglicht, MODs zu laden. Stell es dir wie das Betriebssystem einer Spielkonsole vor, das vorhanden sein muss, bevor du Software installierst: Bevor die eigentlichen MOD-Dateien installiert werden können, muss Fabric sowohl auf dem Server als auch auf dem PC jedes einzelnen Spielers eingerichtet sein.

⚠ Der häufigste Stolperstein

Die MODs müssen nicht nur auf dem Server, sondern auf dem PC jeder einzelnen spielenden Person installiert werden. Es gibt keine Möglichkeit, mit „auf dem Server installieren“ automatisch alle mitzuversorgen. Server und alle Spieler müssen bei Minecraft-Version, Fabric und der MOD-Kombination exakt übereinstimmen, sonst ist eine Teilnahme am Server nicht möglich.

Wer stellt was bereit?

  • Der Server (Sorakazekarasu-Server) — Fabric-Server + Fabric API + die 11 Glimpse-Alpha-MODs
  • Der PC jeder teilnehmenden Person — Fabric-Client + Fabric API + die 11 Glimpse-Alpha-MODs (exakt dieselbe Kombination wie auf dem Server)
Die MOD-Dateien selbst werden auf dieser Seite nicht verteilt

Diese Seite enthält nur „Lesestoff“ wie Rezepttabellen, Änderungsprotokoll und Installationsanleitung – die MOD-Dateien selbst (jar-Dateien) werden hier nicht verteilt. Den vollständigen Satz an jar-Dateien erhältst du vom Server-Administrator.

Aufbau dieser Seite

Diese Anleitung ist in zwei Zielgruppen gegliedert. Die meisten Personen können bereits mit dem Kapitel für Spieler allein teilnehmen. Wer den Server selbst betreibt oder verwaltet, sollte anschließend auch das Kapitel für Server-Administratoren lesen.

Für Spieler

Für Spieler: Einstellungen für die Teilnahme am Server

Hier wird die Einrichtung für alle erklärt, die auf dem Server mitspielen möchten. Schwieriges Fachwissen ist nicht nötig. Arbeitest du die Schritte der Reihe nach ab, dauert es etwa 15–20 Minuten.

Nur 3 Dinge sind zu tun
  • ① Fabric (die Grundlage zum Laden der MODs) auf deinem eigenen PC installieren
  • ② Den vom Server-Administrator erhaltenen Satz an MOD-Dateien in den vorgesehenen Ordner legen
  • ③ Nur an einer Stelle die Startweise ändern und dem Server beitreten

Was du brauchst

  • Einen Windows- oder Mac-PC, auf dem Minecraft Java Edition läuft
  • Den vom Server-Administrator erhaltenen vollständigen MOD-Satz (12 jar-Dateien = 1 Fabric API + 11 Glimpse-Alpha-MODs)
🛑 Sehr wichtig

Ohne exakt dieselbe Version und exakt dieselben MOD-Dateien wie der Server ist eine Teilnahme nicht möglich. Auf dieser Seite wird als Beispiel die Minecraft-Version 26.2 verwendet – falls dir der Server-Administrator eine andere Nummer genannt hat, setze überall diese Nummer ein. Öffne die erhaltenen jar-Dateien nicht per Doppelklick. Es genügt, sie in den Ordner zu legen.

① Fabric installieren

Öffne https://fabricmc.net/use/installer/ und lade den Installer herunter. Bleibe auf dem Reiter „Client“ (nicht auf „Server“ wechseln), wähle bei Minecraft Version dieselbe Nummer wie beim Server und klicke auf „Install“.

Unter Windows

  1. Lade den Installer über einen Button wie „Download installer (Windows/.exe)“ herunter und führe ihn per Doppelklick aus (erscheint „Der PC wurde durch Windows geschützt“, klicke auf „Weitere Informationen“ → „Trotzdem ausführen“).
  2. Bleibe auf dem Reiter „Client“, wähle bei Minecraft Version 26.2 (dieselbe Nummer wie der Server), lasse Loader Version unverändert und klicke auf „Install“.

Unter Mac

  1. Lade den Installer (.jar) über den Button „Download universal jar“ herunter. Eine ausführbare Datei (.exe) für Mac gibt es nicht.
  2. Klicke die heruntergeladene Datei fabric-installer-〜.jar nicht per normalem Doppelklick, sondern mit der rechten Maustaste (oder bei gedrückter control-Taste) an und wähle „Öffnen“. Erscheint eine Warnung, klicke erneut auf „Öffnen“.
  3. Bleibe auf dem Reiter „Client“, wähle bei Minecraft Version dieselbe Nummer wie der Server und klicke auf „Install“.
⚠ Falls auf dem Mac „Der Entwickler kann nicht verifiziert werden“ erscheint

Bei neueren macOS-Versionen kann es vorkommen, dass auch Rechtsklick → „Öffnen“ keinen Button anzeigt und stattdessen nur die Warnung „‚fabric-installer〜.jar‘ kann nicht auf Schadsoftware überprüft werden“ erscheint. In diesem Fall öffnest du die Datei in folgender Reihenfolge:

  1. Klicke bei der Warnung auf „Fertig“ (klicke auf keinen Fall auf „In den Papierkorb legen“)
  2. Öffne oben links das Apple-Menü → „Systemeinstellungen“ → „Datenschutz & Sicherheit“
  3. Weiter unten erscheint die Meldung „Die Verwendung von ‚fabric-installer〜.jar‘ wurde blockiert“ – klicke daneben auf „Dennoch öffnen“
  4. Wirst du erneut gefragt, wähle „Dennoch öffnen“ → gib dein Mac-Passwort ein (oder nutze Touch ID)

Das ist die Standardwarnung, die bei allen nicht bei Apple registrierten Programmen erscheint – lädst du von der offiziellen Fabric-Website, besteht kein Grund zur Sorge. Einmal erlaubt, lässt sich die Datei danach ganz normal öffnen.

Falls sich der Installer auf dem Mac gar nicht öffnen lässt

Passiert nach Rechtsklick → „Öffnen“ gar nichts, ist auf dem System kein Java installiert. Öffne adoptium.net, installiere den macOS-Installer (.pkg) von „Temurin“ und versuche es danach erneut. Bei einem Mac mit Apple Silicon (M1/M2/M3/M4 usw.) wählst du „aarch64“, bei einem Intel-Mac „x64“. Falls du unsicher bist, prüfe oben links im Apple-Menü unter „Über diesen Mac“ das Feld „Chip“ (steht dort „Apple M…“, ist es aarch64).

② MOD-Dateien in den mods-Ordner legen

Windows: %appdata%\.minecraft\mods

  1. Gib im Adressfeld des Explorers %appdata%\.minecraft ein und drücke Enter.
  2. Falls es noch keinen mods-Ordner gibt, lege ihn neu an (komplett kleingeschrieben).
  3. Kopiere alle 12 erhaltenen jar-Dateien in diesen mods-Ordner (kein Entpacken nötig, sie bleiben als jar-Datei).

Mac: ~/Library/Application Support/minecraft/mods

  1. Klicke einmal auf den Schreibtisch und drücke dann gleichzeitig ⌘ command+⇧ shift+G (oder wähle im oberen Menü „Gehe zu“ → „Gehe zum Ordner…“).
  2. Füge im erscheinenden Eingabefeld ~/Library/Application Support/minecraft genau so ein und drücke Enter (die Tilde „~“ am Anfang nicht vergessen). „Library“ ist im Finder normalerweise ausgeblendet, daher ist dieser Weg am zuverlässigsten.
  3. Falls es noch keinen mods-Ordner gibt, erstelle ihn direkt hier per Rechtsklick → „Neuer Ordner“.
  4. Ziehe alle 12 erhaltenen jar-Dateien per Drag & Drop in diesen mods-Ordner.

③ Mit Fabric starten und dem Server beitreten

  1. Öffne den Minecraft-Launcher und wähle in der Liste der Startprofile in der Nähe des „Spielen“-Buttons ein Profil wie fabric-loader-26.2 aus (bleibst du bei „Neuestes Release“, startet das Spiel ohne MODs).
  2. Klicke dann auf „Spielen“, um zu starten. Erscheint auf dem Titelbildschirm zusätzlich ein „Mods“-Button, war es erfolgreich. Ein Klick darauf zeigt die 11 Glimpse-Alpha-MODs sowie die Fabric API an.
  3. Verbinde dich anschließend wie gewohnt über „Mehrspieler“ mit dem Server.

Wenn die MODs aktualisiert werden

Wird der MOD-Bestand auf dem Server aktualisiert, müssen alle Teilnehmenden gleichzeitig auf dieselbe neue Version wechseln.

  1. Erhalte die neuen MOD-Dateien vom Server-Administrator (warte auf die Ankündigung, bevor du beginnst).
  2. Öffne den mods-Ordner, lösche zuerst die bisher vorhandenen Glimpse-Alpha-jar-Dateien und lege danach die neuen Dateien hinein (auch wenn sich der Dateiname ändert, gilt der Inhalt als derselbe MOD – bleiben alte Dateien liegen, startet das Spiel nicht).
  3. Starte wie gewohnt über das fabric-loader-Profil.
⚠ Achtung

Bleibt auch nur eine Seite bei der alten Version, ist eine Teilnahme am Server nicht möglich. Schau bei Problemen auch in die Häufigen Fragen.

Für Server-Administratoren

Für Server-Administratoren: Vorbereitung (Backup und Versionsprüfung)

Ab hier richtet sich das Kapitel an alle, die den Server selbst betreiben und verwalten. Ausgehend von einem bereits laufenden Minecraft-Server (Vanilla, der MOD-lose Standardserver) wird hier erklärt, wie Fabric und die 11 Glimpse-Alpha-MODs hinzugefügt werden. Dieses Kapitel verwendet als Beispiel einen Windows-Server. Betreibst du den Server unter Mac/Linux, übertrage die Ordnerpfade und die Art der Befehlsausführung auf deine Umgebung und folge den entsprechenden Schritten (Anleitung der offiziellen Fabric-Website).

🛑 Unbedingt vor Beginn der Arbeit

Erstelle unbedingt ein Backup, bevor du beginnst, damit du deine Welt nicht verlierst, falls bei der Installation der MODs etwas schiefgeht.

1. Backup der Welt erstellen

Öffne den Server-Ordner (z. B. C:\MinecraftServer) und führe die von dir üblicherweise verwendete Backup-Routine aus (z. B. ein Backup-Skript wie Backup-Server.bat). Gibt es kein eigenes Skript, genügt es auch, den Server anzuhalten und den gesamten world-Ordner an einen anderen Ort zu kopieren.

2. Java-Version prüfen

  1. Öffne die Eingabeaufforderung (oder ein beliebiges Terminal).
  2. Gib java -version ein und drücke Enter.
  3. Prüfe, ob die angezeigte Zahl 25 lautet (Beispiel: java version "25.0.3").
🛑 Sehr wichtig

Um Minecraft 26.2 zu betreiben, wird Java 25 benötigt. In älteren Einrichtungsanleitungen steht manchmal „Java 21“ – das ist veraltet, mit Java 21 startet der Server nicht mehr. Liegt die Zahl unter 25, öffne adoptium.net, lade „Temurin 25 (LTS)“ herunter, installiere es, starte den Computer neu und prüfe die Version erneut.

3. Minecraft-Version des Servers prüfen

  1. Starte den Server wie gewohnt einmal (z. B. über Start-Server.bat).
  2. Suche in den ersten Zeilen der Konsole (das schwarze Fenster) nach einer Zeile wie Starting minecraft server version X.Y und notiere dir die Zahl.
  3. Gib in der Konsole stop ein und drücke Enter, um den Server sicher zu beenden.
⚠ Achtung

In dieser Anleitung wird als Beispiel „26.2“ verwendet – weicht die tatsächlich ermittelte Zahl davon ab, setze sie in allen folgenden Schritten (Auswahl der Version von Fabric, Fabric API und den MODs) entsprechend ein. Stimmen Server, alle Spieler und die MOD-Versionen auch nur an einer einzigen Stelle nicht überein, funktioniert gar nichts.

Für Server-Administratoren

Für Server-Administratoren: Installation von Fabric

Fabric-Server installieren

  1. Öffne im Browser https://fabricmc.net/use/server/ und lade den Installer über einen Button wie „Download installer (Windows/.exe)“ herunter.
  2. Führe die heruntergeladene Datei fabric-installer〜.exe per Doppelklick aus (erscheint „Der PC wurde durch Windows geschützt“, klicke auf „Weitere Informationen“ → „Trotzdem ausführen“).
  3. Prüfe im Einstellungsbildschirm des Installers folgende 4 Punkte:
    • Wähle den Reiter „Server“
    • Wähle bei Minecraft Version dieselbe Version, die du bei der Vorbereitung für den Server ermittelt hast (Beispiel: 26.2)
    • Loader Version kann unverändert bleiben
    • Gib bei Install Location den bestehenden Server-Ordner an (Beispiel: C:\MinecraftServer)
  4. Klicke auf „Install“.
  5. Erfolgreich war es, wenn im Server-Ordner die neue Datei fabric-server-launch.jar entstanden ist.

Neue Startdatei (Batch-Datei) erstellen

Deine bisherige Startdatei (Beispiel: Start-Server.bat) startet den Server „ohne MODs“. Lösche sie nicht, sondern behalte sie (damit du im Notfall zum MOD-losen Server zurückkehren kannst). Erstelle stattdessen zusätzlich eine neue Startdatei für Fabric.

  1. Öffne den Editor (Notepad).
  2. Kopiere den folgenden Inhalt unverändert hinein. 
    @echo off
cd /d "%~dp0"
title Minecraft Fabric Server
java -Xms2G -Xmx4G -jar fabric-server-launch.jar nogui
echo Der Server wurde beendet.
pause
  3. Wähle „Datei“ → „Speichern unter“, wähle als Speicherort den Server-Ordner (Beispiel: C:\MinecraftServer), als Dateiname Start-Fabric-Server.bat und als Dateityp „Alle Dateien“.
⚠ Achtung

Wählst du bei „Dateityp“ nicht „Alle Dateien“, entsteht die nicht funktionierende Datei Start-Fabric-Server.bat.txt. Weicht der beim Einrichten des Servers reservierte Arbeitsspeicher (RAM) von 4 GB ab, ändere zudem die „4“ in -Xmx4G auf die passende Zahl.

Für Server-Administratoren: Installation der MODs und Startprüfung

Die MODs selbst sind jeweils einzelne „jar-Dateien“. Du installierst sie, indem du sie einfach in den mods-Ordner des Server-Ordners legst.

1. mods-Ordner vorbereiten

Prüfe, ob im Server-Ordner (Beispiel: C:\MinecraftServer) ein Ordner namens mods existiert. Falls nicht, erstelle ihn per Rechtsklick → „Neu“ → „Ordner“ mit dem Namen mods (komplett kleingeschrieben).

2. Fabric API besorgen

Öffne https://modrinth.com/mod/fabric-api/versions und lade aus der Liste den obersten Eintrag herunter, bei dem „Game version“ mit der Version deines Servers übereinstimmt (Beispiel: fabric-api-0.154.2+26.2.jar).

3. Den vollständigen MOD-Satz in den mods-Ordner legen

Kopiere insgesamt 12 jar-Dateien – 1 Fabric API + 11 Glimpse-Alpha-MODs – in den mods-Ordner (kein Entpacken nötig, sie bleiben als jar-Dateien). Die 11 MOD-Dateien selbst besorgst du wie bisher über den gewohnten Verteilungsweg. Diese Seite verteilt die MOD-Dateien selbst nicht.

4. Server starten und prüfen

  1. Doppelklicke die zuvor erstellte Datei Start-Fabric-Server.bat (nicht mehr die bisherige Start-Server.bat).
  2. Prüfe in der Konsole (das schwarze Fenster) folgende 2 Punkte:
    • In der Zeile, in der die MODs geladen werden, erscheinen die Namen der installierten MODs
    • Am Ende erscheint Done (…s)! For help, type "help", und der Server läuft weiter, ohne stehen zu bleiben
💡 Falls der Start wegen eines Java-Fehlers fehlschlägt

Erscheint eine englischsprachige Fehlermeldung wie „class file version“ oder „requires Java“, ist dein Java vermutlich veraltet. Installiere über adoptium.net die Windows-Version (.msi) von „Temurin 25 (LTS)“, starte den Computer neu und versuche es erneut.

Sobald der Start bestätigt ist, verweise alle Teilnehmenden auf das Kapitel für Spieler, damit sie denselben Fabric- und MOD-Satz auch auf ihrem eigenen PC installieren.

Für Server-Administratoren

Beim Austausch der MODs gegen eine neue Version

Da bei Glimpse Alpha die 11 MODs jeweils vollständig unabhängig voneinander sind, werden bei einem Update nicht zwangsläufig alle 11 ausgetauscht. Es reicht, nur die MODs zu ersetzen, deren Inhalt sich tatsächlich geändert hat (welche MODs betroffen sind, erfährst du bei der Verteilung oder im Änderungsprotokoll).

Ablauf des Updates

  1. Gib in der Server-Konsole stop ein, um den Server anzuhalten.
  2. Erstelle mit der gewohnten Routine ein Backup der Welt.
  3. Lösche im mods-Ordner des Servers die alte jar-Datei des zu aktualisierenden MODs und lege die neue jar-Datei hinein (bleiben alte und neue Version desselben MODs gleichzeitig liegen, startet der Server nicht).
  4. Starte den Server über Start-Fabric-Server.bat und prüfe, ob in der Konsole die aktualisierte Version angezeigt wird.
  5. Verteile die neuen jar-Dateien auch an alle Teilnehmenden und lass sie denselben Austausch vornehmen (siehe Kapitel für Spieler). Ist nur der Server oder nur die Spieler auf der neuen Version, ist keine Teilnahme möglich.
🛑 Sehr wichtig

Startest du den Server, nachdem ein MOD (nicht aktualisiert, sondern) vollständig entfernt wurde, verschwinden die mit diesem MOD platzierten Blöcke und besessenen Gegenstände (z. B. Ampeln). Das liegt am Verhalten von Minecraft/Fabric selbst und lässt sich nicht rückgängig machen. Erstelle vor dem Entfernen unbedingt ein Backup.

Zu den Config-Dateien (automatischer Reparaturmechanismus)

Jeder MOD erzeugt beim Start automatisch eine Einstellungsdatei im Ordner config/ (Beispiel: sorakaze_guns.json). Werte wie Stärke oder Geschwindigkeit lassen sich hier anpassen, und in der Regel ist es nicht nötig, die Datei bei jedem Update manuell zu löschen oder zu bearbeiten.

💡 Wie der Mechanismus funktioniert

Ändert sich in einer neuen Version ein Standardwert, wird er ausschließlich bei noch nicht angepassten Einträgen (die noch den alten Standardwert enthalten) automatisch auf den neuen Standardwert aktualisiert. Von dir selbst angepasste Werte bleiben unangetastet. Auch neu hinzugekommene Einstellungspunkte werden beim Start automatisch ergänzt. Was dabei aktualisiert wurde, wird in logs/latest.log stets als „alter Wert → neuer Wert“ protokolliert.

⚠ Achtung beim Bearbeiten der Config-Datei

Löschst du von Hand nur einzelne Werte aus der Einstellungsdatei (z. B. nur die Schadenszeile aus dem Einstellungsblock einer Waffe), kann dieser Eintrag stillschweigend durch einen anderen internen Standardwert des MODs ersetzt werden (ohne Fehlermeldung). Willst du einen bestimmten Wert anpassen, ändere ihn direkt an seiner Stelle. Möchtest du die Einstellungen komplett auf den Ausgangszustand zurücksetzen, lösche die gesamte Config-Datei des jeweiligen MODs – sie wird beim nächsten Start mit den Standardwerten neu erstellt.

Wissenswertes vor dem Spielen

Glimpse Alpha enthält auch einige Änderungen, die sich auf Vanilla-Verhalten auswirken. Hier sind besonders leicht zu übersehende Punkte zusammengefasst. Da sich einzelne Werte mit jedem Update anpassen können, prüfe für den aktuellen Stand zusätzlich das Änderungsprotokoll und die Seite Bekannte Probleme. Config-Anpassungen nimmt der Server-Administrator vor.

Redstone braucht jetzt „Strom“

Durch die Installation des Strom-MODs funktioniert ein Teil des Vanilla-Redstonesystems nicht mehr allein für sich.

  • Braucht jetzt Strom: Redstone-Staub, Repeater, Komparator, Redstone-Block, Redstone-Fackel. Diese geben erst dann ein Signal aus, wenn sie per Kabel mit Strom verbunden sind. Automatische Farmen, Bahnhöfe, Automatiktüren und Trichterketten bleiben stehen, bis sie verkabelt sind.
  • Funktioniert weiterhin ohne Strom wie gewohnt: Hebel, Knopf, Druckplatte, Stolperdrahthaken, Beobachter, Tageslichtsensor, Sculk-Sensor, Zielblock, Fallentruhe, Loren-Detektorschiene, Lesepult, Musikbox, Blitzableiter und weitere. Auch das manuelle Öffnen von Türen und Toren funktioniert unverändert.
  • Ein Redstone-Block zerfällt etwa 10 Minuten nach dem Platzieren von selbst (und kehrt als Gegenstand zurück).
💡 So machst du es rückgängig (für Server-Administratoren)

Setzt du powerEnabled in config/sorakaze_power.json auf false, lässt sich die Elektrifizierung von Redstone vollständig deaktivieren.

Auch einige Geräte aus Baumaterial & Deko brauchen Strom

Überwachungskamera, Aufzug, Rolltreppe, Automatiktür und Geldautomat funktionieren nur, wenn Strom per Kabel zugeführt wird (der Aufzug funktioniert ohne Strom immerhin noch „abwärts“). Setzt du den jeweiligen Eintrag in config/sorakaze_deco.json pro Gerät auf false, kannst du einzelne Geräte von der Strompflicht ausnehmen.

Generatoren heizen den Raum auf

Laufende Generatoren und Kernkraftwerke erhöhen die Temperatur im selben Raum. Kühlen kann nur die Klimaanlage. Trennst du den Maschinenraum durch Wände und geschlossene Türen ab, breitet sich die Hitze nicht in andere Räume aus – die einfachste Gegenmaßnahme. Diese Funktion selbst lässt sich deaktivieren, indem temperatureMachineHeatEnabled in config/sorakaze_survival.json auf false gesetzt wird.

Die Welt „Himmel“ hat eine erweiterte Höhe

Durch die Installation des Himmel-MODs wurde die maximale Bauhöhe in der Oberwelt angehoben. Verändert wird ausschließlich die Obergrenze nach oben – die Tiefe unter der Erde (die Höhe des Weltbodens) und das bestehende Gelände bleiben unverändert.

Der Raketenwerfer zerstört Gelände

Der Raketenwerfer aus dem Schusswaffen-MOD zerstört mit den Standardeinstellungen das Gelände am Einschlagsort. Auch das Deaktivieren der Vanilla-Spielregel mobGriefing (auf false) verhindert das nicht. Um die Zerstörung zu stoppen, muss rocketDestroysTerrain in config/sorakaze_guns.json auf false gesetzt werden. Besondere Vorsicht ist in der Nähe deiner Basis geboten.

Zur Feuerkraft der Waffen

Die Waffen des Schusswaffen-MODs, insbesondere das Sturmgewehr, besitzen eine sehr hohe Feuerkraft, mit der sich viele der durch die MODs hinzugefügten Bosse in wenigen Sekunden besiegen lassen. Wer mehr Herausforderung möchte, kann den Schwierigkeitsgrad über die Schadenswerte der einzelnen Waffen in config/sorakaze_guns.json (durch den Server-Administrator) wieder anheben.

Wird ein MOD entfernt, verschwinden platzierte Blöcke und Gegenstände

Das ist ein allgemeines Verhalten von MODs und kein Glimpse-Alpha-spezifischer Fehler. Blöcke, die mit einem installierten MOD platziert wurden, sowie damit erhaltene Gegenstände gehen aus der Welt verloren, sobald der jeweilige MOD entfernt wird. Eine Wiederherstellung ist nur über ein Backup möglich.

Falls der Server nicht startet

  1. Verschiebe zunächst den gesamten Inhalt des mods-Ordners an einen anderen Ort.
  2. Lege die Dateien nach und nach einzeln zurück und starte jedes Mal neu, um herauszufinden, welche Datei die Ursache ist.
  3. Erscheinen Java-bezogene Fehler, prüfe anhand des Kapitels zur Vorbereitung deine Java-Version.

Falls du dem Server beitreten kannst, die Verbindung aber nicht klappt

  1. Prüfe, ob Version und MOD-Kombination bei allen Teilnehmenden exakt mit dem Server übereinstimmen.
  2. Besonders häufig liegt es an einer abweichenden Fabric-API-Version – prüfe diese zuerst.
💡 Wenn sich das Problem trotzdem nicht lösen lässt

Sende logs/latest.log an den Server-Administrator und bespreche es dort. Keine Sorge – mit einem vorhandenen Backup lässt sich der Ausgangszustand jederzeit wiederherstellen.

So stellst du die Welt aus einem Backup wieder her (für Server-Administratoren)

  1. Gib in der Server-Konsole stop ein, um den Server anzuhalten.
  2. Nimm das neueste Backup aus dem Speicherort deiner Backups (Beispiel: C:\MinecraftServer\backups) (bei einer zip-Datei: Rechtsklick → „Alle extrahieren“).
  3. Ersetze den world-Ordner im Server-Ordner durch den entpackten world-Ordner (überschreiben).
  4. Starte den Server.
