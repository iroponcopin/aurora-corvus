Discord Bot

Corvus はリリース時に告知し、次に来るものを伝え、バグ報告とリクエストを受け付けます。表示言語はサーバーごとに選べます。

Bot をサーバーに追加

Discord 公式の認証ページが開きます。追加先サーバーの「サーバー管理」権限が必要です。

導入手順

  1. 1. Bot を追加

    上のボタンから追加します。要求する権限は 4 つ（チャンネルを見る・メッセージを送信・埋め込みリンク・履歴を読む）と、報告 1 件につきスレッドを 1 本開く権限だけです。管理者権限は一切要求しません。

  2. 2. チャンネルを決める

    /release channel で告知先を選びます。これが既定になり、個別に振り分けないものはすべてここに届きます。

  3. 3. 言語を選ぶ

    /language set を実行します。13 言語から選べ、それぞれその言語自身の表記で並んでいます。

  4. 4. 種類ごとに分ける（任意）

    /channels set で、更新・予告・バグ報告・リクエストにそれぞれ専用チャンネルを割り当てられます。設定しなかったものは既定のチャンネルのままです。 updateupcomingbugrequest

Bot が自動で投稿するもの

次の 3 種類です。専用チャンネルを設定していればそちらへ届きます。同じ内容が二度投稿されることはありません。

  • リリース公開時。MOD パックと、有効にしていれば Corvus 本体も。
  • 事前予告が出たとき。「次に来るもの」ページの内容がそのまま届きます。
  • 誰かがバグ報告やリクエストを送ったとき。話し合い用のスレッドも作られます。

コマンド一覧

/bug

バグを報告し、その後の経過を追えます。

コマンド内容使える人
/bug new短いフォームが開きます。1行の概要、何が起きたか、そして分かれば再現方法を入力します。全員
/bug list <status>このサーバーの報告を、未対応のものから表示します。返信はあなたにしか見えないので、重複報告の前に確認できます。全員
/bug close <number> <resolution>報告を対応済みにし、どう解決したかを記録します。サーバー管理
/bug reopen <number>直っていなかった場合に、閉じた報告を一覧へ戻します。サーバー管理

/channels

種類ごとに別のチャンネルへ送ります。

コマンド内容使える人
/channels set <kind> <channel>更新・予告・バグ報告・リクエストのいずれか 1 つを、指定したチャンネルに向けます。サーバー管理
/channels show4 種類それぞれの現在の送信先を表示します。全員
/channels clear <kind>その種類を既定のチャンネルに戻します。サーバー管理

/language

このサーバーで Bot が使う言語を選びます。

コマンド内容使える人
/language set <language>言語を設定します。以降、告知・フォーム・返信のすべてがその言語になります。サーバー管理
/language showこのサーバーに設定されている言語を表示します。全員

/release

MOD パックと Corvus の更新告知。

コマンド内容使える人
/release channel <channel>既定のチャンネルを設定します。個別指定のないものはここに届きます。サーバー管理
/release statusこのサーバーの現在の設定をすべて表示します。全員
/release latestBot が把握している最新リリースを、チャンネルに告知せず表示します。全員
/release enableこのサーバーの告知を再開します。サーバー管理
/release disable設定を失わず、Bot も外さずに告知だけ止めます。サーバー管理
/release launcher <enabled>Corvus ランチャーの更新も併せて告知するかを選びます。サーバー管理
/release upcoming <enabled>事前予告の オン / オフ を切り替え、次に来るものを表示します。全員
/release test見本の告知を投稿し、チャンネルと権限を確認できます。サーバー管理

/request

機能や変更を要望し、その後の経過を追えます。

コマンド内容使える人
/request new短いフォームが開きます。何が欲しいか、なぜ役立つかを入力します。全員
/request list <status>このサーバーのリクエストを、未対応のものから表示します。返信はあなたにしか見えません。全員
/request close <number> <resolution>リクエストを対応済みにし、決定内容を記録します。サーバー管理
/request reopen <number>閉じたリクエストを一覧へ戻します。サーバー管理

同じ種類の報告は 1 人あたり 10 分に 3 件までです。バグ報告を続けてもリクエストは妨げられません。

13 言語対応

言語は個人単位ではなくサーバー単位で選びます。告知は共有チャンネルに届くため、同じチャンネルを見ている全員が同じ文面を読むことになるからです。フォーム・返信・エラー表示もこの設定に従います。

保存される情報

報告に紐づくのは、フォームに入力した内容・Discord のユーザー ID と表示名・投稿先だけです。メッセージ履歴は保存せず、指定されていないチャンネルは読まず、Minecraft アカウントとは一切関係がありません。
