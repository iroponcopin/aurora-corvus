Aureum (lightweight optimisation mod, separate download)

Aureum is a separate, independent mod from the Alpha pack. It optimises game logic, memory, and server tick cost, and deliberately never touches the chunk-render pipeline. It is not a replacement for Sodium — it optimises the side Sodium does not touch, so it is safe to run alongside it. If you want higher FPS, install Sodium separately.

Measured so far: -6.3 MB at 2,209 loaded chunks, -17.2 MB after generating a similarly sized area of new terrain (both reproduced across two independent runs). MSPT (tick time) is unchanged within measurement noise. Two client-side toggles (particle limit, block-entity render distance) ship off by default and unmeasured, because this development environment has no client. See the README on GitHub for installation and configuration.

Every optimisation, individually optional

Every key in config/aureum.json can be switched off on its own. Turning one off means Aureum's bytecode changes for that feature are never applied at all — the strongest guarantee available if it ever conflicts with another mod.

Requirements

  • Minecraft 26.2 (Fabric)
  • Fabric Loader 0.19.3+
  • Fabric API
  • Java 25+
