Discord bot

Corvus posts here when a release ships, tells your server what is coming next, and collects bug reports and requests — in the language your server chooses.

Add the bot to your server

Opens Discord's own authorisation page. You need Manage Server on the server you are adding it to.

Setting it up

  1. 1. Add the bot

    Use the button above. It asks for four things — see a channel, send messages, embed links, read history — plus permission to open one thread per report. It never asks to be an administrator.

  2. 2. Pick a channel

    Run /release channel and choose where announcements should go. This becomes the default: anything you do not route elsewhere arrives here.

  3. 3. Choose your language

    Run /language set. Thirteen languages are available, each listed in its own script.

  4. 4. Split it up (optional)

    Run /channels set to give updates, advance notices, bug reports and requests a channel each. Anything you leave unset keeps using the default. updateupcomingbugrequest

What the bot posts on its own

Three things, each to its own channel if you have set one. Nothing is posted twice: the bot remembers what your server has already been told.

  • A release goes live — the modpack, and Corvus itself if you have that switched on.
  • Something is announced in advance, straight from the Coming next page.
  • Somebody files a bug report or a request, with a thread for the discussion.

Every command

/bug

Report a bug and follow what happens to it.

CommandWhat it doesWho can use it
/bug newOpens a short form: a one-line summary, what happened, and — if you know — how to make it happen again.Anyone
/bug list <status>Shows this server's reports, open ones first. Only you see the reply, so check here before filing a duplicate.Anyone
/bug close <number> <resolution>Marks a report as dealt with and says how it was resolved.Manage Server
/bug reopen <number>Puts a closed report back on the list, for when it turns out not to be fixed.Manage Server

/channels

Send each kind of message to its own channel.

CommandWhat it doesWho can use it
/channels set <kind> <channel>Points one category — updates, advance notices, bug reports or requests — at a specific channel.Manage Server
/channels showLists where each of the four categories currently goes.Anyone
/channels clear <kind>Sends that category back to the server's default channel.Manage Server

/language

Choose the language this bot writes in, for this server.

CommandWhat it doesWho can use it
/language set <language>Sets the language. Announcements, forms and replies all follow it from then on.Manage Server
/language showSays which language this server is set to.Anyone

/release

Update announcements for the modpack and for Corvus.

CommandWhat it doesWho can use it
/release channel <channel>Sets the default channel. Anything without its own channel goes here.Manage Server
/release statusShows everything this server is currently set to.Anyone
/release latestShows the newest release the bot knows about, without announcing it to the channel.Anyone
/release enableTurns announcements back on for this server.Manage Server
/release disableStops announcements without removing the bot or losing your settings.Manage Server
/release launcher <enabled>Chooses whether Corvus launcher builds are announced alongside the modpack.Manage Server
/release upcoming <enabled>Turns advance notices on or off, and shows what is coming next.Anyone
/release testPosts a sample announcement so you can check the channel and permissions.Manage Server

/request

Ask for a feature or a change, and follow what happens to it.

CommandWhat it doesWho can use it
/request newOpens a short form: what you would like, and why it would help.Anyone
/request list <status>Shows this server's requests, open ones first. Only you see the reply.Anyone
/request close <number> <resolution>Marks a request as dealt with and says what was decided.Manage Server
/request reopen <number>Puts a closed request back on the list.Manage Server

Three reports of one kind per ten minutes, per person, per server. Filing bugs never stops you making requests.

Thirteen languages

The language is chosen per server, not per person: announcements go into a shared channel, so everyone reading that channel sees the same message. Forms, replies and error messages follow the same setting.

What is stored

A report keeps what you typed into the form, your Discord user id and display name, and where it was posted. That is all. The bot stores no message history, reads no channels it was not pointed at, and has nothing to do with your Minecraft account.
