Corvus is a desktop app that keeps your mods up to date automatically, verifying every download against this Wiki by SHA-256 - the Wiki remains the only source it trusts.

Native installers (no Java required)

These install like a normal desktop app and do not need Java installed separately. They are not code-signed yet, so your OS will show a first-run warning: on macOS, right-click the app and choose Open; on Windows, click "More info" then "Run anyway".

Aureum (lightweight optimisation mod, separate download)

Aureum is a separate, independent mod. It optimises game logic, memory, and server tick cost, and deliberately never touches the chunk-render pipeline. It is not a replacement for Sodium — it optimises the side Sodium does not touch, so it is safe to run alongside it. If you want higher FPS, install Sodium separately.
