Gates & Portals

Every gate you can actually walk through on this server, with how to build it, where it leads, and a diagram. This includes vanilla Nether and End alongside the pack's own gates.

Contents

  2. End Portal (vanilla, unmodified)

  4. Heaven Gate (glowstone portal)
  5. Backrooms Entrance (End City rift)

Nether Portal (vanilla, unmodified)

Destination: Overworld ↔ the Nether. This pack makes no changes to it at all — it behaves exactly as vanilla.

Frame material and shape

  • Obsidian only
  • Interior (the empty part): 2–21 blocks wide x 3–21 blocks tall. The classic 4x5 obsidian rectangle is the minimum size.
  • Corners are not required — as long as the four sides are sealed, the four corner blocks can be left empty and the portal still lights.

How to light it

Flint and steel, or a fire charge, used on the empty interior.

Common mistakes

  • An interior wider or taller than 21 blocks will never light.
  • Any non-obsidian block in the frame (e.g. basalt) stops it lighting.

End Portal (vanilla, unmodified)

Destination: Overworld → the End (one-way; return via an End Gateway or vanilla means such as a bed explosion). This pack makes no changes to it.

Frame material and shape

  • 12 End Portal Frame blocks arranged in a 5x5 ring (generates naturally in strongholds).
  • All 12 frames must face inward.

How to light it

Fill all 12 frames with an Eye of Ender each. The portal opens automatically the moment the last one is placed — no separate ignition item is needed.

Common mistakes

  • An incomplete stronghold generation leaves some frames missing — fill the gaps with Eyes of Ender.
  • A hand-placed frame in the wrong orientation won't work; normally you only ever fill in the naturally-generated ring.

Amethyst Gate

Destination: Overworld ↔ Planarcadia.

Frame material and shape

  • Portal Amethyst Block, or plain vanilla Amethyst Block (new as of V2.2). The two block types can be freely mixed in the same frame.
  • Exactly the same size rule as the Nether portal: 2–21 blocks wide x 3–21 blocks tall interior, corners not required.
  • Budding Amethyst, Amethyst Clusters and obsidian do not count as frame material.

How to light it

Flint and steel, or a fire charge.

Common mistakes

  • Using Budding Amethyst or an Amethyst Cluster in the frame — neither is recognised as frame material.
  • Mixing in obsidian stops it lighting. Conversely, a Nether Portal will never open on this frame — the two gates never share stone.

Heaven Gate (glowstone portal)

Destination: Overworld ↔ Heaven (Sky) — home to the angel city and kingdom.

Frame material and shape

  • Glowstone only.
  • Fixed size: an outer rectangle 4 wide x 5 tall, corners included. The inner face is 2 wide x 3 tall. Unlike the Nether portal, you cannot resize this one.

How to light it

Flint and steel. A fire charge does nothing here.

⚠ Needs an admin setting

Lighting a player-built glowstone frame is disabled by default until a server administrator explicitly turns it on. If lighting it does nothing, check with your admin first.

Common mistakes

  • Building any size other than 4x5 — Nether-portal habits don't transfer.
  • Leaving the corners empty — this gate needs glowstone in all four corners too.

Backrooms Entrance (End City rift)

Destination: the End → Backrooms Level 1, "The Lobby".

This one isn't player-built

Unlike the other four gates, this entrance generates naturally. Near a naturally-spawned End City, an automatic 3x3 stone pedestal with a 2-block-tall "rift" is placed in open space. At most one rift per End City. No existing End City block is ever overwritten.

How to enter (in place of ignition)

Just step onto the rift block. No tool is required.

Common mistakes

  • Not every End City has a visible rift — if the automatic placement search couldn't find clear open space near that particular city, that city is simply skipped (a safe-by-design choice; End Cities generate in large numbers, so this isn't fatal).
  • Level 1, "The Lobby", is a real, walkable, explorable room set — not a small demo box. There's no need to rush a wall-clip into a different level right away.
