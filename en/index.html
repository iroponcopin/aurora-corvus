Sorakazekarasu Server — Mod Reference

Aurora Corvus

This is an unofficial reference site for Glimpse Alpha (formerly known as Sorakaze), the Fabric mod group running on the Sorakazekarasu server — covering its recipes, changelog, and install instructions. We currently run 11 mods (guns, rail, building materials, boss, sky, survival, vehicles, power, Backrooms, and Planarcadia) together on Minecraft 26.2.

As of V2.2.0, this site distributes the mod files (jars) directly via the "Download" page. It also has "reading material" — recipe tables, changelogs, install instructions, and the like. If you need a version older than V2.2.0, please get it directly from your server admin.

New feature V2.4.9 2026-08-28

Latest update: ミサイルランチャーの見た目が二重になる不具合を修正、マップの移動を右ドラッグへ、一斉発射100発・弾薬庫200発の収納箱化。バックルームズでサーバーが落ちる不具合も修正

ミサイルランチャーについて所有者から届いた4点の指摘に対応しました。見た目が「旧デザインと新デザインが融合した」状態になっていた不具合、戦術マップがクリックしただけで動いてしまう不具合を直し、一度に狙える目標を100箇所に、弾薬庫を200発の「収納箱」に作り直しました。あわせて、V2.4.x より前に作られたバックルームズ階層0の区画を読み込んだときにサーバーが強制終了することがある不具合も修正しています。こちらは新しく作ったワールドでは起きないため今まで見つかっていませんでした。すでに遊んでいるワールドをお持ちのサーバーでは、この修正がいちばん大事な変更です。

  • 【サーバーが落ちる不具合を修正】V2.4.x より前に作られたバックルームズ階層0の区画が読み込まれると、サーバーが応答しなくなり約60秒後に強制終了することがある不具合を修正しました。古い区画を新しい見た目へ描き直す処理を、区画の読み込み中ではなく読み込み後に行うようにしています。新しく作ったワールドでは一度も起きないため、これまでのテストでは見つけられませんでした。長く遊んでいるワールドをお持ちの場合だけ影響します。
  • ミサイルランチャーの見た目が「旧デザインと新デザインが融合した」状態になっていた不具合を修正しました。原因は2つあり、(1) 脚とミサイル管を描く向きが4方向すべてで180度ずれていたため、発射台の1ブロック手前にミサイル管が、4本の脚のうち2本が空中に描かれていたこと、(2) 旧デザインのブロック模型13個のうち7個がまだ一緒に描かれ続けていたこと、でした。両方を直し、地面のパッド以外は新しい造形だけが描かれるようになりました。
  • あわせて、V2.4.6以降、発射台の脚の当たり判定が4方向のうち3方向でずれていたことが分かり(報告はいただいていませんでした)、向きごとに正しい当たり判定を持つよう作り直しました。
  • 戦術マップの視点移動を、左クリック長押しから右クリック長押しに変更しました。左クリックは目標の追加・削除だけになり、ただクリックしただけでマップが動くことはなくなりました。移動は押した場所から3ピクセル以上離れて初めて始まります(これまでは微小な手ぶれが積み重なって、止めているつもりでも動いていました)。操作方法はマップ画面の下部にも表示されます。

About this project

It started out under the name "Sorakaze," adding three mods — guns, rail, and building materials — on top of an otherwise vanilla survival experience. From there it kept expanding with craftable items, and was renamed "Glimpse Alpha" in v1.8.0. It's now a 11-mod pack that includes bosses, a new dimension, survival features, vehicles, and power infrastructure.

The consistent policy has been to never replace or remove vanilla content — things like bows and minecarts remain exactly as they were. No real-world firearm, company, or trademark names are used.
