Sorakazekarasu Server — Unofficial Mod Reference

Glimpse Alpha Wiki

This is an unofficial reference site for Glimpse Alpha (formerly known as Sorakaze), the Fabric mod group running on the Sorakazekarasu server — covering its recipes, changelog, and install instructions. We currently run 9 mods (guns, rail, building materials, boss, sky, survival, vehicles, power, and Backrooms) together on Minecraft 26.2.

This site does not distribute the mods themselves (the jar files). What's here is just "reading material" — recipe tables, changelogs, install instructions, and the like. Please get the mod files directly from your server admin.

New feature v1.9.3 2026-08-13

Latest update: Verified Nuclear-Warhead Power Generation, Major Rail Update, New Screen Design, Always-On Coordinates

Updated 5 mods at once (there are no v1.9.1 or v1.9.2 releases — the major rail update and the nuclear-warhead power generation requests are bundled together and shipped as v1.9.3). We've finally delivered Spark Doll α's art, which had actually been fixed two releases ago but had never once made it into a shipped build, along with a fix for batteries breaking when left fully charged for a long time, a new (not-yet-run) way to verify on a real server that nuclear warheads can be used as fuel, and a fix for the Rocket Launcher's scope bug. Rail gained a major update including automatic departure and automatic driving, Power/Guns/Boss screens got the new "Glimpse Glass" design, and always-on coordinate and TPS/ping displays were added.

  • [Important] The Spark Doll α art bug (part of the right ear appearing to vanish) had actually already been fixed after v1.9.0.2, but a flaw in the mechanism that compares build outputs meant it never once made it into a distributed build. The fixed art finally arrives with this release. To make sure this never happens again, we've introduced a new check (check_dist_drift.py) that directly diffs source assets against the distributed build.
  • [Important] Power: Fixed a bug where a fully charged Battery, left alone for about 18.6 hours, would stop producing Energy Cells forever. The cause was an addition overflow, which showed up faster with higher-output fuels (like nuclear warheads). Batteries already broken by this bug will fix themselves automatically once you install this release.
  • Power: The mechanism for using nuclear warheads as fuel has existed since v1.8.7, but this round we set up a way to verify it on a real dedicated server for the first time (however, the test environment was lost during this packaging round, so it hasn't actually been run yet -- see the warning below for details). Also fixed a bug where the fuel-grade display showed the raw, untranslated string "sorakaze_power.fuel_quality.nuclear."
  • Guns: The Rocket Launcher's scope is finally visible on screen (fixed after being reported twice). Its zoom level has also been raised from ×2 to ×4. The appearance of both sniper rifles is unchanged.

About this project

It started out under the name "Sorakaze," adding three mods — guns, rail, and building materials — on top of an otherwise vanilla survival experience. From there it kept expanding with craftable items, and was renamed "Glimpse Alpha" in v1.8.0. It's now a 9-mod pack that includes bosses, a new dimension, survival features, vehicles, and power infrastructure.

The consistent policy has been to never replace or remove vanilla content — things like bows and minecarts remain exactly as they were. No real-world firearm, company, or trademark names are used.
