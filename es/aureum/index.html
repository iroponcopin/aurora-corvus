Aureum (mod de optimización ligero, descarga aparte)

Aureum es un mod independiente, separado del pack Alpha. Optimiza la lógica del juego, la memoria y el coste de tick del servidor, y deliberadamente nunca toca la canalización de renderizado de chunks. No sustituye a Sodium: optimiza el lado que Sodium no toca, así que es seguro usarlo junto a él. Si quieres más FPS, instala Sodium por separado.

Medido hasta ahora: -6,3 MB con 2.209 chunks cargados, -17,2 MB tras generar una zona nueva de tamaño similar (reproducido en dos ejecuciones independientes). El MSPT (tiempo de tick) no cambia dentro del margen de ruido de medición. Dos ajustes del lado del cliente (límite de partículas, distancia de renderizado de bloque-entidad) vienen desactivados por defecto y sin medir, porque este entorno de desarrollo no tiene cliente. Consulta el README en GitHub para instalación y configuración.

Cada optimización se puede desactivar por separado

Cada clave de config/aureum.json puede desactivarse de forma independiente. Desactivar una significa que los cambios de bytecode de Aureum para esa función nunca se aplican — la garantía más fuerte posible si llega a chocar con otro mod.

Requisitos

  • Minecraft 26.2 (Fabric)
  • Fabric Loader 0.19.3+
  • Fabric API
  • Java 25+
