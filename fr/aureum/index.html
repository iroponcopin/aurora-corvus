Aureum (mod d'optimisation léger, téléchargement séparé)

Aureum est un mod indépendant, séparé du pack Alpha. Il optimise la logique du jeu, la mémoire et le coût des tick serveur, et ne touche délibérément jamais au pipeline de rendu des chunks. Ce n'est pas un remplacement de Sodium : il optimise le côté que Sodium ne touche pas, donc il est sûr de l'utiliser avec lui. Pour plus de FPS, installez Sodium séparément.

Mesuré jusqu'ici : -6,3 Mo à 2 209 chunks chargés, -17,2 Mo après génération d'une zone de taille similaire (reproduit sur deux exécutions indépendantes). Le MSPT (temps de tick) reste inchangé dans la marge de bruit de mesure. Deux réglages côté client (limite de particules, distance de rendu des blocs-entités) sont désactivés par défaut et non mesurés, cet environnement de développement n'ayant pas de client. Voir le README sur GitHub pour l'installation et la configuration.

Chaque optimisation peut être désactivée individuellement

Chaque clé de config/aureum.json peut être désactivée indépendamment des autres. La désactiver signifie que les modifications de bytecode d'Aureum pour cette fonctionnalité ne sont jamais appliquées — la garantie la plus forte possible en cas de conflit avec un autre mod.

Prérequis

  • Minecraft 26.2 (Fabric)
  • Fabric Loader 0.19.3+
  • Fabric API
  • Java 25+
