Bot Discord

Aurora Corvus annonce les sorties, dit à votre serveur ce qui arrive ensuite, et recueille bugs et demandes — dans la langue que votre serveur choisit.

Ajouter le bot à votre serveur

Ouvre la page d’autorisation officielle de Discord. Il vous faut « Gérer le serveur » sur le serveur visé.

Mise en place

  1. 1. Ajouter le bot

    Utilisez le bouton ci-dessus. Il demande quatre choses — voir un salon, envoyer des messages, intégrer des liens, lire l’historique — plus le droit d’ouvrir un fil par signalement. Jamais l’administration.

  2. 2. Choisir un salon

    Lancez /release channel et choisissez où vont les annonces. Ce salon devient le salon par défaut : tout ce que vous n’aiguillez pas ailleurs y arrive.

  3. 3. Choisir la langue

    Lancez /language set. Treize langues, chacune écrite dans sa propre graphie.

  4. 4. Séparer (facultatif)

    Avec /channels set, donnez un salon à chacun : mises à jour, avant-premières, bugs et demandes. Ce que vous ne réglez pas continue d’utiliser le salon par défaut. update upcoming bug request

Ce que le bot publie de lui-même

Trois choses, chacune dans son salon si vous en avez défini un. Rien n’est publié deux fois.

  • Une version sort — le pack, et Corvus lui-même si vous l’avez activé.
  • Quelque chose est annoncé à l’avance, directement depuis la page « À venir ».
  • Quelqu’un signale un bug ou fait une demande, avec un fil pour en discuter.

Toutes les commandes

Commande Ce qu’elle fait Qui peut l’utiliser
/bug — Signaler un bug et suivre ce qu’il devient.
/bug newOuvre un formulaire court : un résumé d’une ligne, ce qui s’est passé et, si vous le savez, comment le reproduire.Tout le monde
/bug list <status>Affiche les signalements de ce serveur, ouverts d’abord. Vous seul voyez la réponse : vérifiez ici avant d’en créer un doublon.Tout le monde
/bug close <number> <resolution>Marque un signalement comme traité et indique comment il a été résolu.Gérer le serveur
/bug reopen <number>Remet un signalement fermé dans la liste, s’il s’avère qu’il n’était pas corrigé.Gérer le serveur
/channels — Envoyer chaque type de message dans son propre salon.
/channels set <kind> <channel>Dirige une catégorie — mises à jour, annonces, bugs ou demandes — vers un salon précis.Gérer le serveur
/channels showIndique où va actuellement chacune des quatre catégories.Tout le monde
/channels clear <kind>Renvoie cette catégorie vers le salon par défaut du serveur.Gérer le serveur
/language — Choisir la langue que ce bot utilise sur ce serveur.
/language set <language>Définit la langue. Annonces, formulaires et réponses la suivent ensuite.Gérer le serveur
/language showIndique la langue configurée pour ce serveur.Tout le monde
/release — Annonces de mises à jour du pack et de Corvus.
/release channel <channel>Définit le salon par défaut. Tout ce qui n’a pas de salon dédié arrive ici.Gérer le serveur
/release statusAffiche tous les réglages actuels de ce serveur.Tout le monde
/release latestAffiche la dernière version connue, sans l’annoncer dans le salon.Tout le monde
/release enableRéactive les annonces pour ce serveur.Gérer le serveur
/release disableArrête les annonces sans retirer le bot ni perdre vos réglages.Gérer le serveur
/release launcher <enabled>Choisit si les versions du lanceur Corvus sont annoncées elles aussi.Gérer le serveur
/release upcoming <enabled>Active ou désactive les annonces anticipées, et montre ce qui arrive.Tout le monde
/release testPublie une annonce d’exemple pour vérifier le salon et les permissions.Gérer le serveur
/request — Demander une fonctionnalité ou un changement, et suivre ce qu’il devient.
/request newOuvre un formulaire court : ce que vous souhaitez et en quoi cela aiderait.Tout le monde
/request list <status>Affiche les demandes de ce serveur, ouvertes d’abord. Vous seul voyez la réponse.Tout le monde
/request close <number> <resolution>Marque une demande comme traitée et indique la décision.Gérer le serveur
/request reopen <number>Remet une demande fermée dans la liste.Gérer le serveur

Trois signalements d’un même type par dix minutes, par personne et par serveur. Signaler des bugs ne vous empêche jamais de faire des demandes.

Treize langues

La langue se choisit par serveur, pas par personne : les annonces arrivent dans un salon partagé, et tout le monde doit y lire la même chose. Formulaires, réponses et messages d’erreur suivent le même réglage.

Les noms des commandes restent en anglais : Discord les prend dans les réglages du client de chaque lecteur, pas dans ceux du serveur.

Ce qui est conservé

Un signalement conserve ce que vous avez écrit dans le formulaire, votre identifiant Discord et votre nom affiché, et l’endroit où il a été publié. Rien d’autre. Le bot ne stocke aucun historique, ne lit aucun salon vers lequel il n’a pas été dirigé, et n’a rien à voir avec votre compte Minecraft.
