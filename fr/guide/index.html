Présentation : à propos de l'installation de Glimpse Alpha

Glimpse Alpha (anciennement Sorakaze) est un ensemble de MOD Fabric installés sur le serveur Sorakazekarasu. Il se compose de 8 MOD indépendants, chacun pouvant être installé et mis à jour séparément. Il ne remplace ni ne supprime les éléments vanilla (le standard sans MOD) comme les arcs et les wagonnets : il se contente d'ajouter de nouveaux objets, blocs et dimensions.

MODContenu
Armes à feuArmes à distance absentes de la vanilla (fusil d'assaut, fusil à pompe, fusil de précision, etc.)
Chemin de ferDes trains qui accélèrent progressivement, avec des wagons voyageurs et des wagons de marchandises attelables
Matériaux et décorationMatériaux pour l'urbanisme (feux de circulation, glissières de sécurité, etc.) et appareils électroménagers (caméras de sécurité, distributeurs de billets, ascenseurs, etc.)
VéhiculesVoitures, bus, avions, etc.
BossDe puissants adversaires à vaincre, avec de l'équipement exclusif en butin
CielUne nouvelle dimension, le « Ciel », avec sa cité et son royaume d'anges
SurvieNouveaux minerais, armures, ainsi que des éléments de vie tels que la température et les saisons
ÉlectricitéProduction et réseau de distribution électrique, et appareils fonctionnant à l'électricité

Pour le détail des objets et recettes de chaque MOD, consultez le recueil de recettes ; pour l'historique des modifications, consultez le journal des mises à jour.

Pour utiliser les MOD, « Fabric » est nécessaire

Fabric est la base qui permet à Minecraft de charger des MOD. C'est un peu comme le système d'une console qu'il faut avoir avant d'y installer un jeu : avant d'installer les MOD eux-mêmes, il faut d'abord installer Fabric à la fois sur le serveur et sur le PC de chaque joueur.

⚠ Le point le plus souvent mal compris

Les MOD doivent être installés non seulement sur le serveur, mais aussi sur le PC de chaque personne qui joue. Il n'est pas vrai que « les installer sur le serveur suffit à ce qu'ils s'appliquent automatiquement à tout le monde ». Si la version de Minecraft, de Fabric et des MOD ne correspond pas exactement entre le serveur et tous les joueurs, il sera impossible de rejoindre le serveur.

Qui doit préparer quoi

  • Le serveur (serveur Sorakazekarasu) — Fabric (serveur) + Fabric API + les 8 MOD de Glimpse Alpha
  • Le PC de chaque participant — Fabric (client) + Fabric API + les 8 MOD de Glimpse Alpha (exactement la même combinaison que le serveur)
Les MOD eux-mêmes ne sont pas distribués sur ce site

Ce site ne propose que de la « lecture » : tableaux de recettes, historique des mises à jour, guide d'installation, etc. Il ne distribue pas les MOD eux-mêmes (les fichiers jar). Merci de récupérer l'ensemble des fichiers jar nécessaires auprès de l'administrateur du serveur.

Structure de cette page

Ce guide est écrit en deux parties, selon votre rôle. La plupart des personnes n'ont besoin de lire que le chapitre destiné aux joueurs pour pouvoir participer. Si vous gérez ou administrez vous-même le serveur, consultez ensuite également le chapitre destiné aux administrateurs du serveur.

Pour les joueurs

Pour les joueurs : configuration pour rejoindre le serveur

Cette section explique la configuration à faire du côté des personnes qui viennent jouer sur le serveur. Aucune connaissance technique particulière n'est nécessaire. En suivant les étapes dans l'ordre, cela prend environ 15 à 20 minutes.

Il n'y a que 3 choses à faire
  • ① Installer Fabric (la base qui permet de charger les MOD) sur son propre PC
  • ② Placer l'ensemble des fichiers MOD reçus de l'administrateur du serveur dans le dossier prévu
  • ③ Modifier un seul réglage de démarrage, puis rejoindre le serveur

Ce qu'il vous faut

  • Un PC Windows ou Mac capable de faire tourner Minecraft Java Edition
  • L'ensemble des MOD (9 fichiers jar = 1 Fabric API + 8 MOD de Glimpse Alpha) reçu de l'administrateur du serveur
🛑 Très important

Impossible de rejoindre le serveur si vous n'avez pas exactement la même version et exactement les mêmes fichiers MOD que le serveur. Cette page utilise par exemple la version Minecraft 26.2, mais si l'administrateur du serveur vous communique un autre numéro, remplacez-le partout par celui-ci. N'ouvrez pas les fichiers jar reçus en double-cliquant dessus : il suffit de les placer dans le dossier pour qu'ils fonctionnent.

Vous recevrez de l'administrateur du serveur environ 9 fichiers comme ceux-ci (les numéros de version changent à chaque mise à jour).

① Installer Fabric

Ouvrez https://fabricmc.net/use/installer/ pour récupérer l'installateur. Restez sur l'onglet « Client » (ne passez pas sur « Server »), choisissez dans Minecraft Version le même numéro que le serveur, puis cliquez sur « Install ».

Sur Windows

  1. Téléchargez l'installateur depuis un bouton du type « Download installer (Windows/.exe) », puis exécutez-le en double-cliquant dessus (si le message « Windows a protégé votre ordinateur » apparaît, cliquez sur « Informations complémentaires » puis « Exécuter quand même »).
  2. En restant sur l'onglet « Client », choisissez 26.2 (le même numéro que le serveur) dans Minecraft Version, laissez Loader Version tel quel, puis cliquez sur « Install ».

Sur Mac

  1. Téléchargez l'installateur (.jar) depuis le bouton « Download universal jar ». Il n'existe pas de fichier exécutable (.exe) pour Mac.
  2. Sur le fichier téléchargé fabric-installer-〜.jar, faites un clic droit (et non un simple double-clic) — ou cliquez en maintenant la touche control enfoncée — puis choisissez « Ouvrir ». Si un avertissement apparaît, cliquez de nouveau sur « Ouvrir ».
  3. En restant sur l'onglet « Client », choisissez dans Minecraft Version le même numéro que le serveur, puis cliquez sur « Install ».
⚠ Si un message « Impossible de vérifier l'identité du développeur » apparaît sur Mac

Sur les versions récentes de macOS, il arrive qu'un clic droit → « Ouvrir » ne fasse même pas apparaître ce bouton, et qu'un simple avertissement du type « Impossible de vérifier que "fabric-installer〜.jar" ne contient pas de logiciel malveillant » s'affiche. Dans ce cas, procédez dans cet ordre :

  1. Sur cet avertissement, cliquez sur « OK » (ne cliquez surtout pas sur « Déplacer vers la Corbeille »)
  2. Ouvrez le menu Apple en haut à gauche de l'écran → « Réglages Système » → « Confidentialité et sécurité »
  3. Plus bas, vous verrez un message indiquant que « l'utilisation de "fabric-installer〜.jar" a été bloquée » ; cliquez sur « Ouvrir quand même » à côté
  4. Si on vous le redemande, cliquez sur « Ouvrir quand même », puis saisissez le mot de passe de votre Mac (ou utilisez Touch ID)

Il s'agit d'un avertissement standard qui apparaît pour tous les logiciels non enregistrés auprès d'Apple : aucune inquiétude à avoir si vous l'avez obtenu depuis le site officiel de Fabric. Une fois l'autorisation donnée, il s'ouvrira normalement les fois suivantes.

Si rien ne se passe lors de l'installation sur Mac

Si rien ne se passe même après un clic droit → « Ouvrir », c'est que Java n'est pas installé sur votre système. Ouvrez adoptium.net et installez l'installateur macOS (.pkg) de « Temurin », puis réessayez. Pour un Mac avec une puce Apple Silicon (M1/M2/M3/M4, etc.), choisissez « aarch64 » ; pour un Mac Intel, choisissez « x64 ». En cas de doute, vérifiez le champ « Puce » dans le menu Apple en haut à gauche → « À propos de ce Mac » (si vous voyez « Apple M〜 », c'est de l'aarch64).

② Placer les fichiers MOD dans le dossier mods

Windows : %appdata%\.minecraft\mods

  1. Dans la barre d'adresse de l'Explorateur de fichiers, saisissez %appdata%\.minecraft puis appuyez sur Entrée.
  2. S'il n'existe pas de dossier mods, créez-en un (tout en minuscules).
  3. Copiez les 9 fichiers jar reçus dans ce dossier mods (inutile de les décompresser, placez-les tels quels).

Mac : ~/Library/Application Support/minecraft/mods

  1. Cliquez une fois sur le bureau, puis appuyez simultanément sur ⌘ command+⇧ shift+G (ou utilisez le menu du haut « Aller » → « Aller au dossier… »).
  2. Dans le champ qui apparaît, collez tel quel ~/Library/Application Support/minecraft puis appuyez sur Entrée (n'oubliez pas le « ~ » au début). Le dossier « Library » n'étant normalement pas visible dans le Finder, cette méthode est la plus sûre pour l'ouvrir.
  3. S'il n'existe pas de dossier mods, créez-en un sur place par un clic droit → « Nouveau dossier ».
  4. Faites glisser (glisser-déposer) les 9 fichiers jar reçus dans ce dossier mods.

③ Démarrer avec Fabric et rejoindre le serveur

  1. Ouvrez le launcher Minecraft, puis choisissez dans la liste des profils de démarrage (près du bouton « Jouer ») un nom du type fabric-loader-26.2 (si vous restez sur « Dernière version », le jeu démarrera sans les MOD).
  2. Cliquez sur « Jouer » pour démarrer. Si un bouton « Mods » est apparu sur l'écran-titre, c'est réussi. En cliquant dessus, vous pourrez vérifier que les 8 MOD de Glimpse Alpha et Fabric API sont bien présents.
  3. Il ne reste plus qu'à vous connecter au serveur comme d'habitude, depuis « Multijoueur ».

Quand les MOD sont mis à jour

Lorsque les MOD du serveur sont mis à jour, tous les participants doivent passer à la même version en même temps.

  1. Récupérez les nouveaux fichiers MOD auprès de l'administrateur du serveur (attendez qu'il vous prévienne avant de commencer).
  2. Ouvrez le dossier mods, supprimez les fichiers jar de Glimpse Alpha déjà présents, puis placez les nouveaux fichiers (même si le nom de fichier change, il s'agit toujours du même MOD en interne : si l'ancien fichier reste présent, le jeu ne pourra pas démarrer).
  3. Démarrez comme d'habitude avec le profil fabric-loader.
⚠ Attention

Si un seul côté reste sur l'ancienne version, il sera impossible de rejoindre le serveur. En cas de problème, consultez aussi la Foire aux questions.

Pour les administrateurs du serveur

Pour les administrateurs du serveur : préparatifs (sauvegarde et vérification de version)

À partir d'ici, ce chapitre s'adresse aux personnes qui font tourner et administrent le serveur lui-même. Nous partons du principe qu'un serveur Minecraft (vanilla, le serveur standard sans MOD) fonctionne déjà, et nous expliquons la procédure pour y ajouter Fabric et les 8 MOD de Glimpse Alpha. Ce chapitre prend un serveur Windows comme exemple. Si vous administrez votre serveur sous Mac / Linux, adaptez l'emplacement des dossiers et la façon d'exécuter les commandes à votre environnement, en suivant la procédure équivalente (indications du site officiel de Fabric).

🛑 Avant toute chose

Afin de ne pas perdre votre monde même en cas d'échec de l'installation des MOD, effectuez impérativement une sauvegarde avant de commencer.

1. Sauvegarder le monde

Ouvrez le dossier du serveur (exemple : C:\MinecraftServer) et exécutez votre procédure de sauvegarde habituelle (exemple : un script de sauvegarde du type Backup-Server.bat). Si vous n'avez pas de script dédié, il suffit d'arrêter le serveur puis de copier entièrement le dossier world vers un autre emplacement.

2. Vérifier la version de Java

  1. Ouvrez l'invite de commandes (ou n'importe quel terminal).
  2. Saisissez java -version puis appuyez sur Entrée.
  3. Vérifiez que le numéro affiché est bien 25 (exemple : java version "25.0.3").
🛑 Très important

Pour faire tourner Minecraft 26.2, Java 25 est nécessaire. Il arrive que d'anciennes procédures d'installation mentionnent « Java 21 » : il s'agit d'une information obsolète, et le serveur ne démarrera pas avec Java 21. Si le numéro affiché est inférieur à 25, ouvrez adoptium.net, téléchargez et installez « Temurin 25 (LTS) », puis redémarrez l'ordinateur et vérifiez de nouveau.

3. Vérifier la version Minecraft du serveur

  1. Démarrez une première fois le serveur comme d'habitude (exemple : Start-Server.bat).
  2. Repérez, au tout début de la console (l'écran noir), une ligne du type Starting minecraft server version X.Y, et notez ce numéro.
  3. Dans la console, saisissez stop puis appuyez sur Entrée pour arrêter le serveur en toute sécurité.
⚠ Attention

Ce guide utilise « 26.2 » comme exemple, mais si le numéro que vous avez effectivement vérifié est différent, remplacez-le dans toutes les étapes suivantes (choix des versions de Fabric, de Fabric API et des MOD). Si la version du serveur, de tous les joueurs et des MOD ne correspond pas exactement, rien ne fonctionnera.

Pour les administrateurs du serveur

Pour les administrateurs du serveur : installation de Fabric

Installer le serveur Fabric

  1. Dans votre navigateur, ouvrez https://fabricmc.net/use/server/ et téléchargez l'installateur depuis un bouton du type « Download installer (Windows/.exe) ».
  2. Double-cliquez sur le fichier téléchargé fabric-installer〜.exe pour le lancer (si le message « Windows a protégé votre ordinateur » apparaît, cliquez sur « Informations complémentaires » puis « Exécuter quand même »).
  3. Sur l'écran de configuration de l'installateur, vérifiez ces 4 points :
    • Sélectionnez l'onglet « Server »
    • Dans Minecraft Version, choisissez la même version que celle du serveur vérifiée lors de la préparation (exemple : 26.2)
    • Loader Version peut rester tel quel
    • Dans Install Location, indiquez le dossier du serveur existant (exemple : C:\MinecraftServer)
  4. Cliquez sur « Install ».
  5. Si un nouveau fichier nommé fabric-server-launch.jar apparaît dans le dossier du serveur, c'est réussi.

Créer un nouveau fichier de démarrage (fichier batch)

Le fichier de démarrage utilisé jusqu'à présent (exemple : Start-Server.bat) démarre la version « sans MOD ». Conservez-le sans le supprimer (pour pouvoir revenir à une version sans MOD en cas de besoin). À la place, nous allons créer un nouveau fichier de démarrage dédié à Fabric.

  1. Ouvrez le Bloc-notes (Notepad).
  2. Copiez-collez tel quel le contenu suivant. 
    @echo off
cd /d "%~dp0"
title Minecraft Fabric Server
java -Xms2G -Xmx4G -jar fabric-server-launch.jar nogui
echo Le serveur s'est arrete.
pause
  3. Faites « Fichier » → « Enregistrer sous », choisissez comme emplacement le dossier du serveur (exemple : C:\MinecraftServer), donnez comme nom de fichier Start-Fabric-Server.bat, réglez le type de fichier sur « Tous les fichiers », puis enregistrez.
⚠ Attention

Si vous ne réglez pas le « type de fichier » sur « Tous les fichiers », vous obtiendrez un fichier non fonctionnel nommé Start-Fabric-Server.bat.txt. Par ailleurs, si la mémoire (RAM) allouée lors de la mise en place du serveur n'est pas de 4 Go, remplacez le « 4 » de -Xmx4G par le chiffre correspondant.

Pour les administrateurs du serveur

Pour les administrateurs du serveur : installation des MOD et vérification du démarrage

Chaque MOD se présente sous la forme d'un fichier individuel appelé « fichier jar ». Pour l'installer, il suffit de le placer dans le dossier mods du dossier du serveur.

1. Préparer le dossier mods

Vérifiez si un dossier nommé mods existe dans le dossier du serveur (exemple : C:\MinecraftServer). S'il n'existe pas, créez-le par un clic droit → « Nouveau » → « Dossier », en le nommant mods (tout en minuscules).

2. Récupérer Fabric API

Ouvrez https://modrinth.com/mod/fabric-api/versions et téléchargez, dans la liste, le premier fichier dont la « Game version (version du jeu) » correspond au même numéro que le serveur (exemple : fabric-api-0.154.2+26.2.jar).

3. Placer l'ensemble des MOD dans le dossier mods

Copiez dans le dossier mods l'ensemble des 9 fichiers jar : 1 Fabric API + 8 MOD de Glimpse Alpha (inutile de les décompresser, placez-les tels quels). Procurez-vous ces 8 MOD par le canal de distribution habituel. Ce site ne distribue pas les MOD eux-mêmes.

MODExemple de nom de fichier
Armes à feuglimpse-alpha-guns-…+mc26.2.jar
Chemin de ferglimpse-alpha-rail-…+mc26.2.jar
Matériaux et décorationglimpse-alpha-deco-…+mc26.2.jar
Véhiculesglimpse-alpha-vehicles-…+mc26.2.jar
Bossglimpse-alpha-boss-…+mc26.2.jar

⚠ Attention

Ne double-cliquez pas sur les fichiers jar (inutile de les ouvrir). Il suffit de les placer dans le dossier.

4. Démarrer le serveur et vérifier

  1. Double-cliquez sur le fichier Start-Fabric-Server.bat créé précédemment (n'utilisez plus l'ancien Start-Server.bat).
  2. Dans la console (l'écran noir), vérifiez ces 2 points :
    • Le nom des MOD installés apparaît bien sur les lignes de chargement des MOD
    • La ligne Done (…s)! For help, type "help" s'affiche à la fin, et le serveur continue de tourner sans s'arrêter
💡 Si une erreur Java empêche le démarrage

Si vous obtenez une erreur en anglais du type « class file version » ou « requires Java », votre version de Java est probablement trop ancienne. Installez la version Windows (.msi) de « Temurin 25 (LTS) » depuis adoptium.net, redémarrez l'ordinateur, puis réessayez.

Une fois le démarrage confirmé, indiquez à tous les participants le chapitre destiné aux joueurs afin qu'ils installent le même Fabric et le même ensemble de MOD sur leur propre PC.

Pour les administrateurs du serveur

Lors du remplacement des MOD par une nouvelle version

Comme les 8 MOD de Glimpse Alpha sont entièrement indépendants les uns des autres, une mise à jour ne remplace pas forcément les 8 en même temps. Il suffit de remplacer uniquement les MOD dont le contenu a réellement changé (vous pouvez vérifier lesquels ont changé dans les indications fournies avec la mise à jour ou dans le journal des mises à jour).

Procédure de mise à jour

  1. Saisissez stop dans la console du serveur pour l'arrêter.
  2. Effectuez une sauvegarde du monde avec votre procédure habituelle.
  3. Dans le dossier mods du serveur, supprimez les anciens fichiers jar des MOD concernés par la mise à jour, puis placez les nouveaux fichiers jar (si l'ancienne et la nouvelle version du même MOD restent présentes en même temps, le serveur ne pourra pas démarrer).
  4. Démarrez le serveur avec Start-Fabric-Server.bat et vérifiez que la console affiche bien la nouvelle version.
  5. Distribuez également les nouveaux fichiers jar à tous les participants pour qu'ils fassent le même remplacement (voir le chapitre destiné aux joueurs). Si seul le serveur ou seuls les joueurs sont passés à la nouvelle version, personne ne pourra rejoindre le serveur.
🛑 Très important

Si vous démarrez le serveur après avoir complètement retiré un MOD (et non simplement mis à jour), les blocs posés et les objets possédés (feux de circulation, par exemple) grâce à ce MOD disparaîtront. C'est le comportement normal de Minecraft et de Fabric, et cela ne peut pas être annulé. Effectuez impérativement une sauvegarde avant de retirer un MOD.

À propos des fichiers de configuration (mécanisme de réparation automatique)

Chaque MOD génère automatiquement, au démarrage, un fichier de configuration (exemple : sorakaze_guns.json) dans le dossier config/. Vous pouvez y ajuster des valeurs comme la puissance ou la vitesse, et il n'est en principe pas nécessaire de les supprimer ou de les modifier manuellement à chaque mise à jour.

💡 Fonctionnement actuel

Lorsqu'une nouvelle version modifie une valeur par défaut, la mise à jour automatique vers la nouvelle valeur par défaut ne s'applique que si vous n'avez pas encore ajusté ce paramètre (c'est-à-dire s'il est resté sur l'ancienne valeur par défaut). Les valeurs que vous avez ajustées vous-même ne sont jamais modifiées. Les nouveaux paramètres ajoutés sont eux aussi complétés automatiquement au démarrage. Tout changement effectué est systématiquement consigné dans logs/latest.log, sous la forme « ancienne valeur → nouvelle valeur ».

⚠ Attention lors de la modification des fichiers de configuration

Si vous supprimez manuellement seulement une partie des valeurs d'un fichier de configuration (par exemple, en effaçant uniquement la ligne des dégâts au sein du bloc de réglages d'une arme), cet élément peut être silencieusement remplacé par une autre valeur par défaut interne au MOD (sans qu'aucune erreur ne s'affiche). Si vous souhaitez ajuster une valeur précise, modifiez-la directement. Si vous souhaitez réinitialiser entièrement la configuration, supprimez le fichier de configuration du MOD concerné dans son intégralité : il sera recréé avec les valeurs par défaut au prochain démarrage.

Points à connaître avant de jouer

Glimpse Alpha comporte aussi plusieurs modifications qui influencent le comportement de la vanilla. Voici un résumé des points les plus faciles à manquer. Les valeurs précises pouvant être ajustées à chaque mise à jour, consultez également le journal des mises à jour et la page des problèmes connus pour les informations les plus récentes. Les ajustements de configuration relèvent de l'administrateur du serveur.

La redstone a besoin d'« électricité »

Avec l'installation du MOD Électricité, une partie de la redstone vanilla ne fonctionne plus toute seule.

  • Éléments nécessitant de l'électricité : la poudre de redstone, le répéteur, le comparateur, le bloc de redstone, la torche de redstone. Ces éléments ne transmettent plus de signal tant qu'ils ne sont pas raccordés à l'électricité par un câble. Les fermes automatiques, les gares, les portes automatiques et les files d'entonnoirs resteront à l'arrêt tant qu'ils ne sont pas câblés.
  • Éléments qui continuent de fonctionner comme avant, même sans électricité : le levier, les boutons, les plaques de pression, les crochets de fil-piège, l'observateur, le capteur de lumière du jour, les capteurs sculk, le bloc cible, le coffre piégé, le rail détecteur, le lutrin, le juke-box, le paratonnerre, etc. Ouvrir une porte ou un portail à la main fonctionne aussi comme avant.
  • Environ 10 minutes après sa pose, un bloc de redstone se détruit naturellement (il revient sous forme d'objet).
💡 Comment revenir en arrière (pour les administrateurs du serveur)

En réglant powerEnabled sur false dans config/sorakaze_power.json, vous pouvez désactiver entièrement l'électrification de la redstone.

Certains appareils du MOD Matériaux et décoration nécessitent aussi de l'électricité

Les caméras de sécurité, les ascenseurs, les escaliers mécaniques, les portes automatiques et les distributeurs de billets (5 appareils) ne fonctionnent que si l'électricité leur est amenée par un câble (l'ascenseur reste toutefois capable de « descendre » même sans électricité). Pour chaque appareil, régler le paramètre correspondant sur false dans config/sorakaze_deco.json permet de le rendre indépendant de l'électricité.

Les générateurs réchauffent la pièce

Un générateur ou une centrale nucléaire en fonctionnement fait monter la température de l'espace où il se trouve. Seul le climatiseur permet de refroidir. Séparer la salle des machines du reste du bâtiment avec des murs et une porte fermée empêche simplement la chaleur de se propager aux autres pièces. Cette fonctionnalité elle-même peut être désactivée en réglant temperatureMachineHeatEnabled sur false dans config/sorakaze_survival.json.

La hauteur du monde du Ciel a été étendue

Avec l'installation du MOD Ciel, la limite de hauteur constructible dans le monde normal (l'Overworld) a été relevée. Seule la limite côté ciel change : la profondeur souterraine (la limite basse) et le terrain existant restent inchangés.

Le lance-roquettes détruit le terrain

Avec les réglages par défaut, le lance-roquettes du MOD Armes à feu détruit le terrain au point d'impact. Régler la règle de jeu vanilla mobGriefing sur false ne suffit pas à l'arrêter. Pour empêcher cette destruction, il faut régler rocketDestroysTerrain sur false dans config/sorakaze_guns.json. Soyez particulièrement prudent à proximité de votre base.

À propos de la puissance de feu des armes

Les armes du MOD Armes à feu, en particulier le fusil d'assaut, disposent d'une puissance de feu très élevée, au point que la plupart des boss ajoutés par les MOD peuvent être vaincus en quelques secondes. Si vous recherchez davantage de difficulté, l'administrateur du serveur peut restaurer un niveau de challenge en ajustant les valeurs de dégâts de chaque arme dans config/sorakaze_guns.json.

Retirer un MOD fait disparaître les blocs et objets posés

Il s'agit d'un comportement général des MOD, et non d'un problème propre à Glimpse Alpha. Les blocs posés et les objets obtenus alors qu'un MOD était installé disparaissent du monde dès que ce MOD est retiré. La seule façon de les récupérer est de restaurer une sauvegarde.

Questions fréquentes et dépannage

Questions fréquentes

QuestionRéponse
Le monde va-t-il disparaître ?Non. Même après l'installation de Fabric, votre monde existant reste utilisable tel quel. En cas d'inquiétude, effectuez toujours une sauvegarde avant l'installation.
Un ami qui n'a pas installé les MOD peut-il participer ?Non, c'est impossible. Tous les joueurs doivent effectuer la configuration décrite dans le chapitre destiné aux joueurs.
Je veux revenir à une version sans MOD (vanilla)Côté serveur, il suffit de redémarrer avec l'ancien fichier de démarrage sans MOD pour revenir à un serveur sans MOD (les blocs et objets ajoutés par les MOD disparaîtront).
Après une mise à jour des MOD, je ne peux plus jouer du toutVérifiez que la version des MOD correspond bien entre le serveur et les joueurs. Si un seul côté est passé à la nouvelle version, il est impossible de rejoindre le serveur.
Je ne comprends pas l'anglais du message d'erreurCe n'est pas grave, inutile de le comprendre. Envoyez simplement tel quel le fichier latest.log, situé dans le dossier logs, à l'administrateur du serveur.

Si le serveur ne démarre pas

  1. Retirez temporairement tout le contenu du dossier mods vers un autre emplacement.
  2. Remettez les fichiers un par un en redémarrant à chaque fois, afin d'identifier lequel pose problème.
  3. Si une erreur liée à Java apparaît, vérifiez la version de Java en vous référant au chapitre de préparation.

Si le jeu se lance mais que la connexion au serveur échoue

  1. Vérifiez que la version et la combinaison de MOD de tous les participants correspondent exactement à celles du serveur.
  2. Une différence de version de Fabric API en particulier en est souvent la cause : vérifiez-la en priorité.
💡 Si le problème persiste malgré tout

Envoyez logs/latest.log à l'administrateur du serveur pour lui demander de l'aide. Pas besoin de paniquer : avec une sauvegarde, vous pourrez toujours revenir à l'état initial.

Comment restaurer le monde à partir d'une sauvegarde (pour les administrateurs du serveur)

  1. Saisissez stop dans la console du serveur pour l'arrêter.
  2. Récupérez la sauvegarde la plus récente depuis son emplacement de stockage (exemple : C:\MinecraftServer\backups) (s'il s'agit d'un fichier zip, faites un clic droit → « Extraire tout »).
  3. Remplacez (écrasez) le dossier world du dossier du serveur par le dossier world récupéré.
  4. Démarrez le serveur.
