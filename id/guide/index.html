Ringkasan: Tentang Pemasangan Glimpse Alpha

Glimpse Alpha (dahulu bernama: Sorakaze) adalah kumpulan MOD Fabric yang dipasang di Server Sorakazekarasu. Terdiri dari 11 MOD independen yang masing-masing bisa dipasang dan diperbarui secara terpisah. Elemen vanilla (standar tanpa MOD) seperti busur panah dan minecart tidak diganti atau dihapus — MOD ini hanya menambahkan item, blok, dan dimensi baru.

Untuk item dan resep detail tiap MOD, lihat Kumpulan Resep, dan untuk perubahan sejauh ini, lihat Riwayat Pembaruan.

Untuk memakai MOD, dibutuhkan "Fabric"

Fabric adalah fondasi yang memungkinkan Minecraft memuat MOD. Bayangkan seperti sistem operasi yang dibutuhkan konsol game sebelum bisa memasang perangkat lunak — sebelum memasang MOD itu sendiri, Fabric harus dipasang lebih dulu, baik di server maupun di PC masing-masing pemain.

⚠ Poin yang paling sering salah

MOD perlu dipasang bukan hanya di server, tetapi juga di PC semua orang yang ingin bermain, dengan versi yang sama persis. Tidak ada istilah "cukup dipasang di server, otomatis berlaku untuk semua orang". Jika kombinasi versi Minecraft, Fabric, dan MOD antara server dan semua pemain tidak sama, kamu tidak akan bisa bergabung ke server.

Siapa yang menyiapkan apa

  • Server (Server Sorakazekarasu) — Fabric Server + Fabric API + 11 MOD Glimpse Alpha
  • PC setiap orang yang ingin bermain — Fabric Client + Fabric API + 11 MOD Glimpse Alpha (kombinasi yang sama persis dengan server)
File MOD tidak didistribusikan di situs ini

Situs ini hanya memuat "bacaan" seperti tabel resep, riwayat pembaruan, dan panduan pemasangan, dan tidak mendistribusikan file MOD (jar) itu sendiri. Untuk mendapatkan seluruh file jar yang dibutuhkan, silakan hubungi admin server.

Struktur halaman ini

Panduan ini ditulis untuk 2 kelompok pembaca. Sebagian besar orang cukup membaca bagian untuk pemain saja untuk bisa bergabung. Jika kamu adalah orang yang menjalankan dan mengelola server sendiri, lanjutkan membaca bagian untuk admin server juga.

Untuk Pemain

Untuk Pemain: Pengaturan untuk Bergabung ke Server

Di sini dijelaskan pengaturan untuk pihak yang ingin bergabung bermain ke server. Tidak dibutuhkan pengetahuan teknis yang rumit. Jika dikerjakan berurutan dari atas, biasanya selesai dalam 15–20 menit.

Hanya ada 3 hal yang perlu dilakukan
  • ① Pasang Fabric (fondasi untuk memuat MOD) di PC kamu sendiri
  • ② Masukkan seluruh file MOD yang diterima dari admin server ke folder yang sudah ditentukan
  • ③ Ubah satu bagian saja cara menjalankan game, lalu bergabung ke server

Yang perlu disiapkan

  • PC Windows atau Mac yang bisa menjalankan Minecraft Java Edition
  • Seluruh MOD (12 file jar = 1 Fabric API + 11 MOD Glimpse Alpha) yang diterima dari admin server
🛑 Sangat penting

Kamu tidak akan bisa bergabung kecuali menggunakan versi dan file MOD yang sama persis dengan server. Sebagai contoh, halaman ini menuliskan versi Minecraft 26.2, tetapi jika admin server memberitahukan angka yang berbeda, gunakan angka tersebut. Jangan membuka file jar yang kamu terima dengan cara diklik dua kali. Cukup letakkan di dalam folder saja, sudah bisa langsung dipakai.

① Memasang Fabric

Buka https://fabricmc.net/use/installer/ dan unduh installer-nya. Tetap di tab "Client" (jangan pindah ke "Server"), pilih Minecraft Version dengan angka yang sama seperti server, lalu tekan "Install".

Untuk Windows

  1. Unduh installer lewat tombol seperti "Download installer (Windows/.exe)" di halaman tersebut, lalu jalankan dengan klik dua kali (jika muncul "Windows melindungi PC Anda", tekan "Info lebih lanjut" → "Jalankan saja").
  2. Tetap di tab "Client", pilih 26.2 (angka yang sama seperti server) pada Minecraft Version, biarkan Loader Version apa adanya, lalu tekan "Install".

Untuk Mac

  1. Unduh installer (.jar) lewat tombol "Download universal jar". Tidak ada file executable (.exe) khusus Mac.
  2. Untuk fabric-installer-〜.jar yang sudah diunduh, jangan klik dua kali seperti biasa — klik kanan (atau klik sambil menekan tombol control) lalu pilih "Buka". Jika muncul peringatan, tekan "Buka" sekali lagi.
  3. Tetap di tab "Client", pilih angka yang sama seperti server pada Minecraft Version, lalu tekan "Install".
⚠ Jika muncul "Tidak dapat memverifikasi pengembang" di Mac

Pada macOS versi terbaru, terkadang klik kanan → "Buka" tidak menampilkan tombol apa pun, dan hanya muncul peringatan "'fabric-installer〜.jar' tidak dapat diverifikasi bebas dari malware". Jika begitu, kamu tetap bisa membukanya dengan langkah berikut.

  1. Pada peringatan tersebut, tekan "Selesai" (jangan pernah menekan "Pindahkan ke Sampah")
  2. Buka menu Apple di kiri atas layar → "Pengaturan Sistem" → "Privasi & Keamanan"
  3. Di bagian bawah akan ada tulisan "Penggunaan 'fabric-installer〜.jar' telah diblokir", tekan "Buka Saja" di sebelahnya
  4. Jika ditanya sekali lagi, pilih "Buka Saja" → masukkan password Mac (atau Touch ID)

Ini adalah peringatan standar yang muncul untuk semua distribusi yang tidak terdaftar di Apple, jadi tidak perlu khawatir selama kamu mendapatkannya dari situs resmi Fabric. Setelah diizinkan sekali, selanjutnya bisa dibuka dengan normal.

Jika installer tidak bereaksi apa pun di Mac

Jika klik kanan → "Buka" tidak menghasilkan apa pun, berarti Java belum terpasang di sistemmu. Buka adoptium.net, pasang installer "Temurin" untuk macOS (.pkg), lalu coba lagi. Untuk Mac Apple Silicon (M1/M2/M3/M4, dll.) pilih "aarch64", untuk Mac Intel pilih "x64". Jika tidak yakin, periksa kolom "Chip" pada menu Apple di kiri atas layar → "Tentang Mac Ini" (jika tertulis "Apple M〜", berarti aarch64).

② Memasukkan file MOD ke folder mods

Windows: %appdata%\.minecraft\mods

  1. Ketik %appdata%\.minecraft di kolom alamat File Explorer lalu tekan Enter.
  2. Buat folder mods baru jika belum ada (semua huruf kecil).
  3. Salin seluruh 12 file jar yang kamu terima ke dalam folder mods ini (tidak perlu diekstrak, masukkan dalam bentuk jar apa adanya).

Mac: ~/Library/Application Support/minecraft/mods

  1. Klik desktop sekali, lalu tekan ⌘ command+⇧ shift+G secara bersamaan (atau lewat menu atas "Go" → "Go to Folder…").
  2. Tempelkan ~/Library/Application Support/minecraft apa adanya ke kolom yang muncul, lalu tekan Enter (jangan lupa tanda "~" di depan). "Library" adalah folder yang biasanya tersembunyi di Finder, jadi cara ini adalah yang paling pasti untuk membukanya.
  3. Jika folder mods belum ada, klik kanan di situ → "New Folder" untuk membuatnya.
  4. Seret dan letakkan (drag & drop) seluruh 12 file jar yang kamu terima ke dalam folder mods ini.

③ Menjalankan dengan Fabric dan bergabung ke server

  1. Buka launcher Minecraft, lalu pilih konfigurasi peluncuran (profile) dengan nama seperti fabric-loader-26.2 dari daftar di dekat tombol "Play" (jika tetap di "Latest release", game akan berjalan tanpa MOD).
  2. Tekan "Play" seperti biasa untuk menjalankan. Jika di layar judul muncul tambahan tombol "Mods", berarti berhasil. Tekan tombol itu untuk memastikan 11 MOD Glimpse Alpha dan Fabric API terdaftar.
  3. Setelah itu, sambungkan ke server seperti biasa lewat "Multiplayer".

Saat MOD diperbarui

Jika MOD di sisi server diperbarui, semua orang yang bermain perlu memperbarui ke versi yang sama secara bersamaan.

  1. Terima file MOD baru dari admin server (tunggu pemberitahuan sebelum mulai mengerjakan).
  2. Buka folder mods, hapus dulu file jar Glimpse Alpha yang lama, baru masukkan file yang baru (meski nama filenya berubah, isinya tetap dianggap sebagai MOD yang sama, sehingga jika yang lama masih tersisa, game tidak akan bisa dijalankan).
  3. Jalankan seperti biasa lewat profile fabric-loader.
⚠ Perhatian

Jika hanya salah satu pihak (server atau kamu) yang menggunakan versi baru, kamu tidak akan bisa bergabung ke server. Jika bingung, periksa juga pertanyaan yang sering diajukan.

Untuk Admin Server: Persiapan Awal (Backup dan Pemeriksaan Versi)

Mulai dari sini adalah bagian untuk pihak yang menjalankan dan mengelola server itu sendiri. Panduan ini menjelaskan langkah menambahkan Fabric dan 11 MOD Glimpse Alpha, dimulai dari kondisi di mana server Minecraft (vanilla, server standar tanpa MOD) sudah berjalan. Bagian ini menggunakan server Windows sebagai contoh. Jika kamu menjalankan server di Mac / Linux, sesuaikan lokasi folder dan cara menjalankan perintah dengan lingkunganmu sendiri, lalu ikuti langkah yang serupa (sesuai panduan situs resmi Fabric).

🛑 Wajib dilakukan sebelum mulai

Agar tidak kehilangan world meski pemasangan MOD gagal, pastikan untuk membuat backup terlebih dahulu sebelum memulai pekerjaan.

1. Membuat backup world

Buka folder server (contoh: C:\MinecraftServer), lalu jalankan langkah backup yang biasa digunakan (contoh: skrip backup seperti Backup-Server.bat). Jika tidak ada skrip khusus, cukup salin seluruh folder world ke lokasi lain saat server dalam keadaan berhenti.

2. Memeriksa versi Java

  1. Buka Command Prompt (atau terminal apa pun).
  2. Ketik java -version lalu tekan Enter.
  3. Periksa apakah angka yang ditampilkan adalah 25 (contoh: java version "25.0.3").
🛑 Sangat penting

Untuk menjalankan Minecraft 26.2, dibutuhkan Java 25. Terkadang panduan setup lama menuliskan "Java 21", tetapi itu informasi lama — server tidak akan bisa dijalankan jika tetap menggunakan Java 21. Jika angkanya di bawah 25, buka adoptium.net, unduh dan pasang "Temurin 25 (LTS)", lalu restart komputer dan periksa lagi.

3. Memeriksa versi Minecraft di server

  1. Jalankan server terlebih dahulu dengan cara yang biasa digunakan (contoh: Start-Server.bat).
  2. Cari baris seperti Starting minecraft server version X.Y yang muncul di awal konsol (layar hitam), lalu catat angkanya.
  3. Ketik stop di konsol lalu tekan Enter untuk menghentikan server dengan aman.
⚠ Perhatian

Panduan ini menuliskan "26.2" sebagai contoh, tetapi jika angka yang sebenarnya kamu dapatkan berbeda, gunakan angka tersebut di semua langkah selanjutnya (pemilihan versi Fabric, Fabric API, dan MOD). Jika versi server, semua pemain, dan MOD tidak sama persis meski hanya satu saja, semuanya tidak akan berfungsi sama sekali.

Untuk Admin Server

Untuk Admin Server: Memasang Fabric

Memasang Fabric Server

  1. Buka https://fabricmc.net/use/server/ di browser, lalu unduh installer lewat tombol seperti "Download installer (Windows/.exe)".
  2. Klik dua kali fabric-installer〜.exe yang sudah diunduh untuk menjalankannya (jika muncul "Windows melindungi PC Anda", tekan "Info lebih lanjut" → "Jalankan saja").
  3. Pada layar pengaturan installer, periksa 4 hal berikut.
    • Pilih tab "Server"
    • Pilih Minecraft Version yang sama dengan versi server yang sudah diperiksa di langkah persiapan (contoh: 26.2)
    • Loader Version boleh dibiarkan apa adanya
    • Tentukan Install Location ke folder server yang sudah ada (contoh: C:\MinecraftServer)
  4. Tekan "Install".
  5. Jika file baru bernama fabric-server-launch.jar muncul di dalam folder server, berarti berhasil.

Membuat file peluncuran baru (file batch)

File peluncuran yang selama ini digunakan (contoh: Start-Server.bat) adalah file untuk menjalankan server "tanpa MOD". Jangan dihapus, biarkan tetap ada (agar bisa kembali ke kondisi tanpa MOD jika suatu saat dibutuhkan). Sebagai gantinya, buat file peluncuran baru khusus untuk Fabric.

  1. Buka Notepad.
  2. Salin dan tempelkan isi berikut apa adanya. 
    @echo off
cd /d "%~dp0"
title Minecraft Fabric Server
java -Xms2G -Xmx4G -jar fabric-server-launch.jar nogui
echo Server telah berhenti.
pause
  3. Pilih "File" → "Save As", lalu simpan di folder server (contoh: C:\MinecraftServer) dengan nama file Start-Fabric-Server.bat, dan atur "Save as type" menjadi "All Files".
⚠ Perhatian

Jika "Save as type" tidak diatur ke "All Files", file akan tersimpan sebagai Start-Fabric-Server.bat.txt yang tidak akan berfungsi. Selain itu, jika memori (RAM) yang dialokasikan saat membangun server bukan 4GB, ubah angka "4" pada -Xmx4G sesuai dengan angka tersebut.

Untuk Admin Server: Memasang MOD dan Memeriksa Server

File utama MOD berupa file "jar" tersendiri. Cukup letakkan file ini di dalam folder mods pada folder server untuk memasangnya.

1. Menyiapkan folder mods

Periksa apakah ada folder bernama mods di dalam folder server (contoh: C:\MinecraftServer). Jika belum ada, klik kanan → "New" → "Folder", lalu beri nama mods (semua huruf kecil).

2. Mendapatkan Fabric API

Buka https://modrinth.com/mod/fabric-api/versions, lalu unduh entri paling atas dalam daftar yang "Game version-nya sama dengan angka versi server" (contoh: fabric-api-0.154.2+26.2.jar).

3. Memasukkan seluruh MOD ke folder mods

Salin total 12 file jar — 1 Fabric API + 11 MOD Glimpse Alpha — ke dalam folder mods (tidak perlu diekstrak, masukkan dalam bentuk jar apa adanya). Untuk file utama 11 MOD ini, dapatkan seperti biasa lewat jalur distribusi yang sudah ada. Situs ini tidak mendistribusikan file MOD itu sendiri.

💡 Jika muncul error Java dan server tidak bisa berjalan

Jika muncul error berbahasa Inggris seperti "class file version" atau "requires Java", kemungkinan versi Java-mu sudah usang. Pasang "Temurin 25 (LTS)" versi Windows (.msi) dari adoptium.net, restart komputer, lalu coba lagi.

Setelah server berhasil dijalankan, langkah selanjutnya adalah memberitahukan bagian untuk pemain kepada semua orang yang ingin bergabung, dan minta mereka memasang Fabric serta seluruh MOD yang sama di PC masing-masing.

Saat Mengganti MOD ke Versi Baru

Karena 11 MOD Glimpse Alpha masing-masing sepenuhnya independen, tidak semua 11 MOD perlu diganti setiap kali ada pembaruan. Cukup ganti MOD yang isinya benar-benar berubah saja (MOD mana yang berubah bisa diperiksa lewat pengumuman saat distribusi atau Riwayat Pembaruan).

Langkah pembaruan

  1. Ketik stop di konsol server untuk menghentikannya.
  2. Buat backup world dengan langkah backup yang biasa digunakan.
  3. Di dalam folder mods server, hapus file jar lama dari MOD yang akan diperbarui, lalu masukkan file jar yang baru (jika versi lama dan baru dari MOD yang sama sama-sama tersisa, server tidak akan bisa dijalankan).
  4. Jalankan server dengan Start-Fabric-Server.bat, lalu pastikan versi terbaru muncul di konsol.
  5. Bagikan juga file jar baru ke semua pemain, dan minta mereka menggantinya dengan cara yang sama (lihat bagian untuk pemain). Jika hanya salah satu pihak (server atau pemain) yang menggunakan versi baru, mereka tidak akan bisa bergabung.
🛑 Sangat penting

Jika sebuah MOD dicabut sepenuhnya (bukan sekadar diperbarui) lalu server dijalankan, blok yang dipasang atau item yang dimiliki dari MOD tersebut (misalnya lampu lalu lintas) akan hilang. Ini adalah perilaku bawaan Minecraft dan Fabric, dan tidak bisa dikembalikan. Pastikan selalu membuat backup sebelum mencabut sebuah MOD.

Tentang file config (mekanisme perbaikan otomatis)

Setiap MOD secara otomatis membuat file pengaturan (contoh: sorakaze_guns.json) di dalam folder config/ saat dijalankan. Angka seperti kekuatan dan kecepatan bisa disesuaikan di sini, dan pada dasarnya tidak perlu dihapus atau diubah secara manual setiap ada pembaruan.

💡 Mekanisme saat ini

Item pengaturan yang nilai bawaannya berubah di versi baru hanya akan diperbarui secara otomatis ke nilai bawaan yang baru jika masih menggunakan nilai bawaan lama (belum pernah kamu sesuaikan). Nilai yang sudah kamu sesuaikan sendiri tidak akan disentuh sama sekali. Item pengaturan baru yang ditambahkan juga akan otomatis dituliskan saat server dijalankan. Apa saja yang diperbarui akan selalu tercatat di logs/latest.log dalam format "nilai lama → nilai baru".

⚠ Perhatian saat mengedit file pengaturan

Jika kamu menghapus sebagian nilai secara manual di dalam file pengaturan (contoh: menghapus hanya baris damage dari sekelompok pengaturan sebuah senjata), item tersebut bisa saja diam-diam tergantikan oleh nilai awal lain dari dalam MOD (tanpa muncul error). Jika ingin menyesuaikan angka tertentu, ubah langsung nilai pada item tersebut. Jika ingin mengembalikan seluruh pengaturan ke kondisi awal, hapus saja seluruh file pengaturan MOD yang bersangkutan — file tersebut akan dibuat ulang dengan nilai bawaan pada saat server dijalankan berikutnya.

Hal yang Perlu Diketahui Sebelum Bermain

Glimpse Alpha juga mencakup beberapa perubahan yang memengaruhi perilaku vanilla. Berikut ini merangkum hal-hal yang paling mudah terlewat. Karena angka detailnya bisa disesuaikan setiap ada pembaruan, periksa juga Riwayat Pembaruan dan halaman Bug yang Diketahui untuk kondisi terbaru. Penyesuaian config dilakukan oleh admin server.

Redstone kini membutuhkan "listrik"

Dengan dipasangnya MOD Listrik, sebagian redstone vanilla tidak akan berfungsi sendiri.

  • Yang membutuhkan listrik: Redstone Dust, Repeater, Comparator, Blok Redstone, Obor Redstone. Semua ini tidak akan mengeluarkan sinyal sampai listrik disambungkan lewat kabel. Ladang otomatis, stasiun, pintu otomatis, dan deretan Hopper akan tetap berhenti sampai kabelnya dipasang.
  • Yang tetap berfungsi seperti biasa tanpa listrik: Tuas, tombol, pelat tekan, Kait Kawat Pemicu, Observer, Sensor Cahaya Matahari, Sculk Sensor, Target, Trapped Chest, Detector Rail, Lectern, Jukebox, penangkal petir, dan lainnya. Membuka pintu atau gerbang secara manual juga tetap bisa dilakukan seperti biasa.
  • Sekitar 10 menit setelah dipasang, Blok Redstone akan hancur secara alami (kembali menjadi item di tanganmu).
💡 Cara mengembalikannya (untuk admin server)

Mengubah powerEnabled di config/sorakaze_power.json menjadi false akan menonaktifkan seluruh elektrifikasi redstone ini.

Sebagian perangkat bahan bangunan & dekorasi juga membutuhkan listrik

Kamera CCTV, Lift, Eskalator, Pintu Otomatis, dan ATM — kelima perangkat ini tidak akan berfungsi tanpa listrik yang disambungkan lewat kabel (khusus Lift, arah "turun" tetap berfungsi meski tanpa listrik). Listrik bisa dinonaktifkan satu per satu untuk tiap perangkat dengan mengubah item pengaturan yang sesuai di config/sorakaze_deco.json menjadi false.

Generator membuat ruangan menjadi panas

Generator dan Pembangkit Nuklir yang sedang beroperasi akan menaikkan suhu di ruangan yang sama. Satu-satunya yang bisa mendinginkannya adalah AC. Memisahkan ruang mesin dengan dinding dan pintu tertutup adalah cara mudah agar panasnya tidak menyebar ke ruangan lain. Fitur ini sendiri bisa dinonaktifkan dengan mengubah temperatureMachineHeatEnabled di config/sorakaze_survival.json menjadi false.

Batas tinggi dunia Langit diperluas

Dengan dipasangnya MOD Langit, batas tinggi bangunan di dunia normal (Overworld) dinaikkan. Yang berubah hanya batas atas ke arah langit — kedalaman bawah tanah (tinggi dasar dunia) dan medan yang sudah ada tetap sama.

Peluncur Roket merusak medan

Roket dari MOD Senjata Api, dengan pengaturan bawaan, akan merusak medan di titik jatuhnya. Ini tidak berhenti meski game rule vanilla mobGriefing diatur ke false. Untuk menghentikan perusakannya, rocketDestroysTerrain di config/sorakaze_guns.json perlu diubah menjadi false. Berhati-hatilah terutama di dekat markas.

Tentang kekuatan senjata

Senjata dari MOD Senjata Api, terutama Assault Rifle, memiliki kekuatan yang sangat tinggi, dan sebagian besar bos tambahan MOD bisa dikalahkan hanya dalam hitungan detik. Jika ingin tantangan yang lebih terasa, admin server bisa mengembalikan tingkat kesulitannya dengan menyesuaikan nilai damage tiap senjata di config/sorakaze_guns.json.

Jika MOD dicabut, blok dan item yang dipasang akan hilang

Ini adalah perilaku umum MOD secara keseluruhan, bukan bug khusus Glimpse Alpha. Blok yang dipasang atau item yang didapatkan saat sebuah MOD terpasang akan hilang dari world begitu MOD tersebut dicabut. Satu-satunya cara mengembalikannya adalah memulihkan dari backup.

Jika server tidak bisa dijalankan

  1. Pindahkan sementara seluruh isi folder mods ke lokasi lain.
  2. Kembalikan satu per satu sambil mencoba menjalankan server berulang kali, untuk menentukan file mana yang menjadi penyebabnya.
  3. Jika muncul error terkait Java, periksa versi Java dengan mengacu pada bagian persiapan.

Jika bisa masuk ke server tetapi tidak bisa terhubung

  1. Periksa apakah kombinasi versi dan MOD semua pemain sudah sama persis dengan server.
  2. Perbedaan versi Fabric API khususnya sering menjadi penyebabnya, jadi periksa ini terlebih dahulu.
💡 Jika masih belum teratasi juga

Kirimkan logs/latest.log kepada admin server untuk berkonsultasi. Tidak perlu panik. Selama ada backup, kamu selalu bisa mengembalikan ke kondisi semula kapan saja.

Cara mengembalikan world dari backup (untuk admin server)

  1. Ketik stop di konsol server untuk menghentikannya.
  2. Ambil backup terbaru dari lokasi penyimpanan backup (contoh: C:\MinecraftServer\backups) (jika berbentuk zip, klik kanan → "Extract All").
  3. Ganti (timpa) folder world di dalam folder server dengan folder world yang diambil dari backup tersebut.
  4. Jalankan server.
