Referensi MOD Tidak Resmi Server Sorakazekarasu

Glimpse Alpha Wiki

Ini adalah situs referensi tidak resmi yang merangkum resep, riwayat pembaruan, dan panduan pemasangan untuk kumpulan MOD Fabric 「Glimpse Alpha」(dahulu bernama: Sorakaze) yang dipasang di Server Sorakazekarasu. Saat ini terdapat 9 MOD (Senjata Api, Kereta Api, Bahan Bangunan, Bos, Langit, Survival, Kendaraan, Listrik, Backrooms) yang berjalan bersamaan 26.2 di Minecraft.

Situs ini tidak mendistribusikan file MOD (jar) itu sendiri. Yang ada di sini hanya "bacaan" seperti tabel resep, riwayat pembaruan, dan panduan pemasangan. Untuk mendapatkan file MOD-nya, silakan hubungi langsung admin server.

Fitur Baru v1.9.3 2026-08-13

Pembaruan terbaru: Verifikasi Pembangkit Listrik Hulu Ledak Nuklir, Update Besar Kereta Api, Desain Layar Baru, Koordinat Selalu Tampil

Memperbarui 5 MOD sekaligus (versi V1.9.1 dan V1.9.2 tidak pernah ada — update besar Kereta Api dan permintaan seputar pembangkit listrik hulu ledak nuklir digabung dan dirilis sekaligus sebagai V1.9.3). Akhirnya mengantarkan gambar Boneka Kembang Api α yang sebenarnya sudah diperbaiki dua rilis lalu tetapi belum pernah sekali pun sampai ke distribusi, sekaligus memperbaiki bug baterai yang rusak jika dibiarkan penuh dalam waktu lama, menyiapkan cara (belum dijalankan) untuk memverifikasi di server sungguhan bahwa hulu ledak nuklir bisa dijadikan bahan bakar, dan memperbaiki bug scope Peluncur Roket. Kereta Api mendapat update besar seperti keberangkatan otomatis dan mengemudi otomatis, layar Listrik/Senjata Api/Bos mendapat desain baru "Glimpse Glass", dan ditambahkan pula papan koordinat serta TPS/ping yang selalu tampil.

  • 【Penting】Bug gambar Boneka Kembang Api α (sebagian telinga kanan tampak hilang) sebenarnya sudah diperbaiki setelah v1.9.0.2, tetapi karena cacat pada mekanisme pembanding antar hasil rilis, perbaikan itu tidak pernah sekali pun sampai ke distribusi. Kini gambar yang sudah diperbaiki akhirnya sampai. Agar bug ini tidak terulang lagi, diperkenalkan pemeriksaan baru (check_dist_drift.py) yang membandingkan langsung aset sumber dengan hasil distribusi.
  • 【Penting】Listrik: Memperbaiki bug di mana Baterai yang dibiarkan penuh selama sekitar 18,6 jam akan berhenti menghasilkan Sel Energi selamanya. Penyebabnya adalah overflow pada operasi penjumlahan, yang muncul lebih cepat pada bahan bakar berdaya tinggi (seperti hulu ledak nuklir). Baterai yang sudah telanjur rusak pun akan otomatis diperbaiki begitu versi ini dipasang.
  • Listrik: Mekanisme untuk menjadikan hulu ledak nuklir sebagai bahan bakar sudah ada sejak v1.8.7, tapi kali ini untuk pertama kalinya disiapkan cara untuk memverifikasinya di dedicated server sungguhan (namun lingkungan pengujian hilang selama ronde pengemasan ini, sehingga verifikasi ini belum benar-benar dijalankan -- lihat peringatan di bawah untuk detailnya). Bug di mana tampilan tingkat bahan bakar masih menampilkan string mentah yang belum diterjemahkan, "sorakaze_power.fuel_quality.nuclear", juga diperbaiki.
  • Senjata Api: Scope Peluncur Roket akhirnya bisa terlihat di layar (diperbaiki setelah dilaporkan dua kali). Perbesarannya juga dinaikkan dari ×2 menjadi ×4. Tampilan kedua senapan sniper tidak diubah.

Tentang Proyek Ini

Proyek ini awalnya bernama "Sorakaze" dan dimulai dari penambahan 3 MOD — senjata api, kereta api, dan bahan bangunan — sambil tetap mempertahankan pengalaman survival vanilla. Sejak itu terus berkembang dengan menambahkan item yang bisa di-craft, hingga berganti nama menjadi "Glimpse Alpha" di versi v1.8.0. Saat ini sudah menjadi susunan 9 MOD yang mencakup bos, dimensi baru, elemen survival, kendaraan, hingga infrastruktur listrik.

Kami secara konsisten berpegang pada prinsip untuk tidak mengganti atau menghapus elemen vanilla — busur panah, minecart, dan elemen lain yang sudah ada tetap dibiarkan apa adanya. Nama senjata api, perusahaan, atau merek dagang yang benar-benar ada tidak digunakan.
