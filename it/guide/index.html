Panoramica: l'installazione del pacchetto Alpha

Alpha (ex Glimpse Alpha, e prima ancora Sorakaze) è un gruppo di mod Fabric installate sul server Sorakazekarasu. È composto da 12 mod indipendenti, ciascuna installabile e aggiornabile separatamente. Non sostituisce né rimuove elementi vanilla (lo standard senza mod) come archi e frecce o carrelli, ma si limita ad aggiungere nuovi oggetti, blocchi e dimensioni.

MODContenuto
Armi da fuocoArmi a distanza assenti nella vanilla (fucile d'assalto, fucile a pompa, fucile di precisione, ecc.)
FerroviaTreni che accelerano gradualmente, con carrozze passeggeri e vagoni merci agganciabili
Edilizia e arredamentoMateriali edili per la costruzione di città (semafori, guardrail, ecc.) ed elettrodomestici come telecamere di sicurezza, bancomat e ascensori
VeicoliAutomobili, autobus, aeromobili e altro
BossPotenti nemici da sconfiggere ed equipaggiamento esclusivo come ricompensa
CieloLa nuova dimensione «Cielo» e le città e il regno degli angeli che vi abitano
SopravvivenzaNuovi minerali e armature, oltre a elementi di vita quotidiana come la temperatura e le stagioni
ElettricitàReti di generazione e trasmissione elettrica, e dispositivi alimentati a corrente
BackroomsEsplorazione liminale con misuratore di sanità mentale

Ogni mod, con i relativi oggetti e ricette in dettaglio, è consultabile nel ricettario; per le modifiche apportate finora, consulta lo storico degli aggiornamenti.

Per usare le mod serve «Fabric»

Fabric è la base che permette a Minecraft di caricare le mod. È un po' come il sistema di una console che serve prima di poter installare qualsiasi software: prima di installare le mod vere e proprie, è necessario installare Fabric sia sul server sia sul PC di ciascun giocatore.

⚠ Il punto in cui si sbaglia più spesso

Le mod devono essere installate non solo sul server, ma anche sul PC di ognuno dei giocatori. Non è vero che «installandole sul server, si applicano automaticamente a tutti». Se la versione di Minecraft, Fabric e la combinazione di mod non coincidono esattamente tra il server e tutti i giocatori, non sarà possibile collegarsi al server.

Chi deve preparare cosa

  • Il server (server Sorakazekarasu) — Fabric server + Fabric API + le 12 mod di Alpha
  • Il PC di ogni singolo giocatore che partecipa — Fabric client + Fabric API + le 12 mod di Alpha (esattamente la stessa combinazione del server)
Le mod in sé non vengono distribuite su questo sito

Questo sito pubblica solo contenuti «da leggere», come tabelle delle ricette, storico degli aggiornamenti e guide all'installazione: non distribuisce i file delle mod (i file jar) in sé. Richiedi l'intero set di file jar necessari all'installazione all'amministratore del server.

Struttura di questa pagina

Questa guida è scritta pensando a due tipi di lettori. La maggior parte delle persone potrà partecipare leggendo solo il capitolo per i giocatori. Chi gestisce o amministra il server in prima persona dovrebbe leggere anche il capitolo per gli amministratori del server.

Per i giocatori

Per i giocatori: configurazione per partecipare al server

Qui viene spiegata la configurazione per chi si collega al server per giocare. Non sono necessarie conoscenze tecniche particolari. Seguendo i passaggi in ordine dall'alto, l'operazione richiede circa 15-20 minuti.

Ci sono solo 3 cose da fare
  • ① Installa Fabric (la base che carica le mod) sul tuo PC
  • ② Metti l'intero set di file delle mod ricevuto dall'amministratore del server nella cartella prevista
  • ③ Cambia un solo punto nel modo di avviare il gioco e collegati al server

Cosa ti serve

  • Un PC Windows o Mac in grado di far girare Minecraft Java Edition
  • L'intero set di mod ricevuto dall'amministratore del server (13 file jar in totale = 1 Fabric API + 12 mod di Alpha)
🛑 Molto importante

Per collegarti devi avere esattamente la stessa versione ed esattamente gli stessi file delle mod del server. In questa pagina, come esempio, viene indicata la versione Minecraft 26.2: se l'amministratore del server ti comunica un numero diverso, sostituisci mentalmente questo numero con quello. Non fare doppio clic per aprire i file jar ricevuti: basta metterli nella cartella per usarli.

① Installare Fabric

Apri https://fabricmc.net/use/installer/ e scarica l'installer. Lascia selezionata la scheda «Client» (non passare a «Server»), scegli in Minecraft Version lo stesso numero del server e premi «Install».

Per Windows

  1. Scarica l'installer da un pulsante simile a «Download installer (Windows/.exe)» presente sulla pagina ed eseguilo con un doppio clic (se compare «Windows ha protetto il tuo PC», premi «Ulteriori informazioni» → «Esegui comunque»).
  2. Lasciando selezionata la scheda «Client», scegli 26.2 (lo stesso numero del server) in Minecraft Version, lascia invariato Loader Version e premi «Install».

Per Mac

  1. Scarica l'installer (.jar) dal pulsante «Download universal jar». Non esiste un eseguibile (.exe) per Mac.
  2. Sul file fabric-installer-〜.jar scaricato, invece del normale doppio clic, fai clic con il tasto destro (oppure clic tenendo premuto control) e scegli «Apri». Se compare un avviso, premi di nuovo «Apri».
  3. Lasciando selezionata la scheda «Client», scegli in Minecraft Version lo stesso numero del server e premi «Install».
⚠ Se su Mac compare «Impossibile verificare lo sviluppatore»

Sulle versioni recenti di macOS, anche con clic destro → «Apri» può non comparire alcun pulsante, ma solo un avviso del tipo «Apple non è riuscita a verificare che "fabric-installer〜.jar" non contenga malware». In questo caso puoi procedere in questo modo.

  1. Nell'avviso premi «Fatto» (non premere mai «Sposta nel Cestino»)
  2. Apri il menu Apple in alto a sinistra → «Impostazioni di Sistema» → «Privacy e sicurezza»
  3. Più in basso trovi la scritta «L'uso di "fabric-installer〜.jar" è stato bloccato»: premi «Apri comunque» accanto a essa
  4. Se viene richiesto di nuovo, premi «Apri comunque» → inserisci la password del Mac (oppure usa Touch ID)

Questo è un avviso standard che compare per tutti i software distribuiti senza registrazione presso Apple, e non c'è nulla di cui preoccuparsi se lo hai scaricato dal sito ufficiale di Fabric. Una volta concessa l'autorizzazione, dalle volte successive si aprirà normalmente.

Se su Mac l'installer non fa nulla

Se anche con clic destro → «Apri» non succede nulla, significa che Java non è installato sul sistema. Apri adoptium.net, installa l'installer macOS (.pkg) di «Temurin» e riprova. Sui Mac con Apple Silicon (M1/M2/M3/M4, ecc.) scegli «aarch64», sui Mac Intel scegli «x64». Se non sei sicuro, controlla la voce «Chip» nel menu Apple in alto a sinistra → «Informazioni su questo Mac» (se indica «Apple M〜», si tratta di aarch64).

② Mettere i file delle mod nella cartella mods

Windows: %appdata%\.minecraft\mods

  1. Nella barra degli indirizzi di Esplora file digita %appdata%\.minecraft e premi Invio.
  2. Se la cartella mods non esiste, creala (tutto in minuscolo).
  3. Copia tutti e 13 i file jar ricevuti dentro questa cartella mods (non serve estrarli, vanno inseriti così come sono, in formato jar).

Mac: ~/Library/Application Support/minecraft/mods

  1. Fai clic una volta sulla scrivania, poi premi contemporaneamente ⌘ command+⇧ shift+G (oppure usa il menu in alto «Vai» → «Vai alla cartella…»).
  2. Nel campo che compare, incolla esattamente ~/Library/Application Support/minecraft e premi Invio (non dimenticare la «~» iniziale). «Library» è una cartella normalmente non visibile nel Finder, quindi questo metodo è il più affidabile per aprirla.
  3. Se la cartella mods non esiste, creala lì con clic destro → «Nuova cartella».
  4. Trascina tutti e 13 i file jar ricevuti in questa cartella mods.

③ Avviare con Fabric e collegarsi al server

  1. Apri il launcher di Minecraft e, dall'elenco dei profili di avvio vicino al pulsante «Gioca», scegli un nome del tipo fabric-loader-26.2 (lasciando «Ultima versione», il gioco si avvia senza mod).
  2. Premi «Gioca» così com'è per avviare il gioco. Se nella schermata del titolo è comparso in più il pulsante «Mods», l'operazione è riuscita: premendolo puoi verificare le 12 mod di Alpha e Fabric API.
  3. Per il resto, collegati al server come al solito tramite «Multiplayer».

Quando le mod vengono aggiornate

Quando le mod lato server vengono aggiornate, tutti i partecipanti devono aggiornarle contemporaneamente alla stessa versione.

  1. Ricevi i nuovi file delle mod dall'amministratore del server (aspetta la notifica prima di procedere).
  2. Apri la cartella mods, elimina i file jar di Alpha presenti fino a quel momento e poi inserisci i nuovi file (anche se il nome del file cambia, il contenuto viene trattato come la stessa mod: se quello vecchio resta lì, il gioco non si avvierà).
  3. Avvia come al solito con il profilo fabric-loader.
⚠ Attenzione

Se solo una delle due parti resta alla versione nuova, non sarai in grado di collegarti al server. In caso di problemi, consulta anche le domande frequenti.

Per gli amministratori del server

Per l'amministratore del server: preparazione preliminare (backup e verifica delle versioni)

Da qui in poi, questo capitolo è dedicato a chi gestisce e amministra il server vero e proprio. Partendo da un server Minecraft già funzionante (vanilla, cioè il server standard senza mod), spiegheremo come aggiungere Fabric e le 12 mod di Alpha. In questo capitolo useremo come esempio un server Windows. Se gestisci il server su Mac / Linux, adatta i percorsi delle cartelle e il modo di eseguire i comandi al tuo ambiente, seguendo comunque la stessa procedura (le indicazioni ufficiali del sito di Fabric).

🛑 Obbligatorio prima di iniziare

Per non rischiare di perdere il mondo in caso di problemi durante l'installazione delle mod, esegui sempre un backup prima di iniziare.

1. Esegui il backup del mondo

Apri la cartella del server (ad esempio C:\MinecraftServer) ed esegui la procedura di backup che usi normalmente (ad esempio uno script come Backup-Server.bat). Se non hai uno script dedicato, va bene anche semplicemente copiare l'intera cartella world in un'altra posizione mentre il server è fermo.

2. Verifica la versione di Java

  1. Apri il prompt dei comandi (o un qualsiasi terminale).
  2. Digita java -version e premi Invio.
  3. Controlla se il numero mostrato è 25 (esempio: java version "25.0.3").
🛑 Molto importante

Per far funzionare Minecraft 26.2 serve Java 25. Le vecchie guide di configurazione a volte riportano ancora «Java 21», ma è un'informazione superata: con Java 21 il server non si avvia. Se il numero è inferiore a 25, apri adoptium.net, scarica e installa «Temurin 25 (LTS)», riavvia il computer e verifica di nuovo.

3. Verifica la versione di Minecraft del server

  1. Avvia il server una volta con il metodo che usi di solito (ad esempio Start-Server.bat).
  2. Nella console (la schermata nera), cerca vicino all'inizio una riga simile a Starting minecraft server version X.Y e annota il numero.
  3. Digita stop nella console e premi Invio per fermare il server in modo sicuro.
⚠ Attenzione

In questa guida, come esempio, viene indicato «26.2», ma se il numero che hai verificato tu è diverso, da qui in avanti sostituisci quel numero in tutti i passaggi (scelta della versione di Fabric, di Fabric API e delle mod). Se anche una sola versione — server, tutti i giocatori, mod — non corrisponde alle altre, il sistema non funzionerà affatto.

Per gli amministratori del server

Per l'amministratore del server: installazione di Fabric

Installa il server Fabric

  1. Apri https://fabricmc.net/use/server/ nel browser e scarica l'installer da un pulsante simile a «Download installer (Windows/.exe)».
  2. Fai doppio clic sul file scaricato fabric-installer〜.exe per avviarlo (se compare «Windows ha protetto il tuo PC», clicca su «Ulteriori informazioni» → «Esegui comunque»).
  3. Nella schermata di configurazione dell'installer, controlla questi 4 punti.
    • Nella scheda, seleziona «Server»
    • Per Minecraft Version, seleziona lo stesso numero verificato nella preparazione preliminare per il server (ad esempio 26.2)
    • Per Loader Version va bene lasciare il valore predefinito
    • Per Install Location, indica la cartella del server già esistente (ad esempio C:\MinecraftServer)
  4. Premi «Install».
  5. Se nella cartella del server è comparso un nuovo file chiamato fabric-server-launch.jar, l'installazione è riuscita.

Crea un nuovo file di avvio (file batch)

Il file di avvio che usavi finora (ad esempio Start-Server.bat) è quello che avvia il server «senza mod». Non cancellarlo: lascialo dov'è (così, in caso di necessità, potrai tornare alla versione senza mod). Al suo posto, creeremo un nuovo file di avvio dedicato a Fabric.

  1. Apri Blocco note (Notepad).
  2. Copia e incolla il seguente contenuto esattamente così com'è. 
    @echo off
cd /d "%~dp0"
title Minecraft Fabric Server
java -Xms2G -Xmx4G -jar fabric-server-launch.jar nogui
echo サーバーが停止しました。
pause
  3. Vai su «File» → «Salva con nome»: come posizione scegli la cartella del server (ad esempio C:\MinecraftServer), come nome file Start-Fabric-Server.bat e come tipo file «Tutti i file», poi salva.
⚠ Attenzione

Se non imposti «Tipo file» su «Tutti i file», otterrai un file che non funziona chiamato Start-Fabric-Server.bat.txt. Inoltre, se la memoria (RAM) assegnata al server in fase di configurazione non è 4GB, sostituisci il «4» in -Xmx4G con il numero corretto.

Per gli amministratori del server

Per l'amministratore del server: installazione delle mod e verifica dell'avvio

Ogni mod è composta da un singolo file chiamato «file JAR» (si pronuncia «giar»). Per installarla basta mettere questo file nella cartella mods della cartella del server.

1. Prepara la cartella mods

Controlla se all'interno della cartella del server (ad esempio C:\MinecraftServer) esiste già una cartella chiamata mods. Se non c'è, creala con clic destro → «Nuovo» → «Cartella», dandole il nome mods (tutto minuscolo).

2. Procurati Fabric API

Apri https://modrinth.com/mod/fabric-api/versions e, nell'elenco, scarica la prima voce dall'alto in cui il «Game version» (versione di gioco) corrisponde al numero del tuo server (ad esempio fabric-api-0.154.2+26.2.jar).

3. Metti tutte le mod nella cartella mods

Copia nella cartella mods 1 file di Fabric API più le 12 mod di Alpha, per un totale di 13 file jar (non serve estrarli: vanno inseriti così come sono, in formato jar). Procurati questi 12 file delle mod tramite lo stesso canale di distribuzione usato finora. Questo sito non distribuisce i file delle mod stesse.

  2. Nella console (la schermata nera), controlla questi 2 punti.
    • Nelle righe di caricamento delle mod compaiono i nomi delle mod installate
    • Alla fine viene mostrato Done (…s)! For help, type "help" e il server resta in esecuzione senza fermarsi
💡 Se compare un errore Java e il server non si avvia

Se compaiono errori in inglese come «class file version» o «requires Java», è probabile che la versione di Java sia troppo vecchia. Installa la versione Windows (.msi) di «Temurin 25 (LTS)» da adoptium.net, riavvia il computer e riprova.

Una volta verificato che il server si avvia correttamente, indirizza tutti i partecipanti al capitolo dedicato ai giocatori e fai in modo che ciascuno installi sul proprio PC lo stesso Fabric e lo stesso pacchetto di mod.

Per gli amministratori del server

Come sostituire le mod con una versione più recente

Il pacchetto Alpha è composto da 12 mod completamente indipendenti l'una dall'altra, quindi non è detto che ad ogni aggiornamento debbano essere sostituite tutte e 12. È sufficiente sostituire solo le mod il cui contenuto è stato effettivamente modificato (per sapere quali mod sono cambiate, puoi controllare le note di distribuzione o lo storico degli aggiornamenti).

Procedura di aggiornamento

  1. Ferma il server digitando stop nella console del server.
  2. Esegui il backup del mondo seguendo la solita procedura di backup.
  3. Nella cartella mods del server, elimina il vecchio file jar della mod da aggiornare e inserisci il nuovo file jar (se restano sia la versione vecchia sia quella nuova della stessa mod, il server non potrà avviarsi).
  4. Avvia il server con Start-Fabric-Server.bat e verifica che nella console venga mostrata la versione aggiornata.
  5. Distribuisci il nuovo file jar anche a tutti i partecipanti e fai sostituire i file allo stesso modo (vedi il capitolo per i giocatori). Se solo il server o solo i giocatori hanno la versione più recente, non sarà possibile giocare insieme.
🛑 Molto importante

Se avvii il server dopo aver rimosso completamente una mod (anziché aggiornarla), i blocchi piazzati e gli oggetti posseduti grazie a quella mod (ad esempio i semafori) spariranno. Questo è un comportamento previsto da Minecraft e Fabric, e non può essere annullato. Esegui sempre un backup prima di rimuovere una mod.

I file config (il meccanismo di correzione automatica)

Ogni mod genera automaticamente, all'avvio, un file di configurazione nella cartella config/ (ad esempio sorakaze_guns.json). Qui puoi regolare valori come la potenza o la velocità, e in generale non è più necessario eliminarli o modificarli manualmente a ogni aggiornamento.

💡 Come funziona attualmente

Le voci il cui valore predefinito cambia in una nuova versione vengono aggiornate automaticamente al nuovo valore, ma solo quelle rimaste al vecchio valore predefinito («fossili», cioè non ancora modificate da te). I valori che hai regolato personalmente non vengono mai toccati. Anche le nuove voci di configurazione aggiunte vengono scritte automaticamente all'avvio. Ciò che viene aggiornato viene sempre registrato in logs/latest.log nel formato «valore precedente → nuovo valore».

⚠ Attenzione quando modifichi i file di configurazione

Se elimini manualmente solo una parte dei valori all'interno di un file di configurazione (ad esempio cancellando solo la riga del danno da un blocco di impostazioni di un'arma), quella voce potrebbe essere silenziosamente sostituita da un altro valore predefinito interno alla mod (senza che compaia alcun errore). Se vuoi modificare un valore specifico, riscrivi direttamente il valore di quella voce. Se invece vuoi riportare tutta la configurazione allo stato iniziale, elimina l'intero file di configurazione della mod in questione: verrà ricreato con i valori predefiniti al prossimo avvio.

Cose da sapere prima di giocare

Il pacchetto Alpha include anche alcune modifiche che influiscono sul comportamento vanilla del gioco. Qui sono riassunte quelle più facili da non notare. Poiché i valori numerici possono essere modificati a ogni aggiornamento, controlla anche lo storico degli aggiornamenti e i problemi noti per la situazione più aggiornata. La modifica del config spetta all'amministratore del server.

La redstone richiede l'«elettricità»

Con l'introduzione della mod Elettricità, alcuni componenti della redstone vanilla non funzionano più da soli.

  • Elementi che richiedono elettricità: polvere di redstone, ripetitore, comparatore, blocco di redstone, torcia di redstone. Questi non emettono segnale finché non vengono collegati all'elettricità tramite un cavo. Fattorie automatiche, stazioni, porte automatiche e file di imbuti restano ferme finché non vengono cablate.
  • Elementi che continuano a funzionare senza elettricità come prima: leva, pulsante, piastra a pressione, gancio per filo d'inciampo, osservatore, sensore di luce diurna, sensore di sculk, bersaglio, forziere trappola, binario rilevatore, leggio, jukebox, parafulmine e altri. Anche l'apertura manuale di porte e cancelli continua a funzionare normalmente.
  • Il blocco di redstone si rompe naturalmente circa 10 minuti dopo essere stato posizionato, tornando in inventario come oggetto.
💡 Come ripristinare il comportamento originale (per gli amministratori del server)

Puoi disattivare completamente l'elettrificazione della redstone impostando powerEnabled su false in config/sorakaze_power.json.

Anche alcuni dispositivi di Edilizia e arredamento richiedono elettricità

Telecamera di sicurezza, ascensore, scala mobile, porta automatica e ATM non funzionano se non ricevono elettricità tramite un cavo (l'ascensore continua a funzionare senza elettricità solo in «discesa»). Impostando su false la voce corrispondente in config/sorakaze_deco.json per ciascun dispositivo, è possibile rendere quel dispositivo indipendente dall'elettricità.

I generatori riscaldano la stanza

I macchinari in funzione, come generatori e centrali nucleari, fanno aumentare la temperatura dello spazio in cui si trovano. L'unico modo per raffreddare è il condizionatore. Se separi la sala macchine con pareti e una porta chiusa, il calore non si diffonde nelle altre stanze: è una contromisura semplice. Questa funzione può essere disattivata impostando temperatureMachineHeatEnabled su false in config/sorakaze_survival.json.

Il Cielo estende l'altezza del mondo

Con l'introduzione della mod Cielo, il limite massimo di altezza costruibile nel mondo normale (l'Overworld) è stato innalzato. Cambia solo il limite superiore verso il cielo: la profondità sotterranea (l'altezza del fondo) e il terreno già generato restano invariati.

Il lanciarazzi distrugge il terreno

Con le impostazioni predefinite, il lanciarazzi della mod Armi da fuoco distrugge il terreno nel punto d'impatto. Impostare la regola di gioco vanilla mobGriefing su false non lo ferma. Per impedire la distruzione è necessario impostare rocketDestroysTerrain su false in config/sorakaze_guns.json. Presta particolare attenzione vicino alla tua base.

La potenza di fuoco delle armi

Le armi della mod Armi da fuoco, in particolare il fucile d'assalto, hanno una potenza di fuoco molto elevata: molti dei boss aggiunti dalle mod possono essere sconfitti in pochi secondi. Se desideri più sfida, l'amministratore del server può ripristinare la difficoltà regolando i valori di danno di ciascuna arma in config/sorakaze_guns.json.

Se rimuovi una mod, i blocchi e gli oggetti piazzati spariscono

Si tratta di un comportamento comune alle mod in generale, non di un problema specifico del pacchetto Alpha. I blocchi piazzati o gli oggetti ottenuti mentre una mod era installata andranno persi dal mondo se quella mod viene rimossa. L'unico modo per ripristinarli è ripristinare un backup.

Domande frequenti

DomandaRisposta
Il mondo andrà perso?No. Anche installando Fabric, il mondo che avevi finora resta utilizzabile così com'è. Se sei preoccupato, esegui comunque un backup prima dell'installazione.

Non riesco a capire il messaggio di errore in ingleseNon è un problema. Invia semplicemente il file latest.log, che si trova nella cartella logs, così com'è all'amministratore del server.

Se il server non si avvia

  1. Sposta temporaneamente tutto il contenuto della cartella mods in un altro posto.
  2. Rimetti i file uno alla volta, riavviando il server ogni volta, per individuare quale file causa il problema.
  3. Se compaiono errori relativi a Java, consulta il capitolo sulla preparazione preliminare e verifica la versione di Java installata.

Il server si avvia, ma non riesci a connetterti

  1. Verifica che la versione e la combinazione di mod di tutti i partecipanti siano esattamente identiche a quelle del server.
  2. In particolare, una differenza nella versione di Fabric API è una causa frequente: controllala per prima.
💡 Se il problema persiste

Invia il file logs/latest.log all'amministratore del server e chiedi consiglio. Non c'è bisogno di preoccuparsi: se hai un backup, puoi sempre tornare allo stato precedente.

Come ripristinare il mondo da un backup (per gli amministratori del server)

  1. Ferma il server digitando stop nella console del server.
  2. Recupera il backup più recente dalla cartella in cui vengono salvati (ad esempio C:\MinecraftServer\backups) (se è in formato zip, fai clic con il tasto destro e seleziona «Estrai tutto»).
  3. Sostituisci la cartella world presente nella cartella del server con la cartella world estratta dal backup (sovrascrivendola).
  4. Avvia il server.
