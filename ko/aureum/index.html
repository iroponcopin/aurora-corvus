틱 시간(MSPT)

Aureum (경량화 모드, 별도 다운로드)

Aureum은 Alpha 팩과는 별개의 독립 모드입니다. 게임 로직·메모리·서버 tick 비용을 최적화하며, 청크 렌더링 파이프라인에는 절대 손대지 않습니다. Sodium을 대체하는 것이 아니라 Sodium이 다루지 않는 쪽을 최적화하도록 설계되어, Sodium과 함께 안전하게 사용할 수 있습니다. FPS를 높이고 싶다면 Sodium을 별도로 설치하세요.

현재까지 실측치: 2,209개 청크 로드 시 -6.3MB, 비슷한 규모의 신규 지형 생성 후 -17.2MB(두 차례 독립 측정에서 일치). MSPT(틱 시간)는 측정 오차 범위 내에서 변화 없습니다. 클라이언트 측 기능 2가지(파티클 상한, 블록 엔티티 렌더 거리)는 기본 꺼짐이며 미측정입니다 — 이 개발 환경에는 클라이언트가 없기 때문입니다. 설치 및 설정 방법은 GitHub의 README를 참고하세요.

모든 최적화는 개별적으로 끌 수 있습니다

config/aureum.json의 각 설정 키는 개별적으로 끌 수 있습니다. 하나를 끄면 해당 기능에 대한 Aureum의 바이트코드 변경이 전혀 적용되지 않습니다 — 다른 모드와 충돌할 경우 취할 수 있는 가장 확실한 격리 방법입니다.

요구 사항

  • Minecraft 26.2 (Fabric)
  • Fabric Loader 0.19.3+
  • Fabric API
  • Java 25+
