디스코드 봇

Corvus는 릴리스가 나오면 공지하고, 다음에 무엇이 오는지 알리며, 버그 신고와 요청을 받습니다. 언어는 서버가 고릅니다.

봇을 서버에 추가

디스코드 공식 인증 페이지가 열립니다. 추가할 서버의 '서버 관리' 권한이 필요합니다.

정적인 페이지에서는 봇이 지금 온라인인지 알 수 없습니다. 아래는 이 사이트가 공개하는 정보입니다.

설정하기

  1. 1. 봇 추가

    위 버튼을 사용하세요. 요청하는 권한은 네 가지(채널 보기, 메시지 보내기, 링크 첨부, 기록 읽기)와 신고 하나당 스레드 하나를 여는 권한뿐입니다. 관리자 권한은 요구하지 않습니다.

  2. 2. 채널 정하기

    /release channel로 공지가 갈 곳을 고르세요. 이것이 기본값이 되어, 따로 지정하지 않은 것은 모두 여기로 옵니다.

  3. 3. 언어 고르기

    /language set을 실행하세요. 13개 언어가 각자의 문자로 표시됩니다.

  4. 4. 나누기(선택)

    /channels set으로 업데이트·예고·버그 신고·요청에 각각 채널을 줄 수 있습니다. 지정하지 않은 것은 기본 채널을 그대로 씁니다. updateupcomingbugrequest

봇이 스스로 올리는 것

세 가지이며, 채널을 지정했다면 각각 그곳으로 갑니다. 같은 내용이 두 번 올라오지는 않습니다.

  • 릴리스가 나올 때 — 모드팩, 그리고 켜 두었다면 Corvus까지.
  • 사전 예고가 나올 때, '다음 소식' 페이지의 내용 그대로.
  • 누군가 버그 신고나 요청을 넣을 때, 논의용 스레드와 함께.

모든 명령

/bug

버그를 신고하고 이후 경과를 확인합니다.

명령하는 일사용 가능
/bug new짧은 양식이 열립니다. 한 줄 요약, 무슨 일이 있었는지, 그리고 알고 있다면 재현 방법을 적습니다.누구나
/bug list <status>이 서버의 신고를 미해결부터 보여 줍니다. 답변은 본인에게만 보이므로 중복 신고 전에 확인할 수 있습니다.누구나
/bug close <number> <resolution>신고를 처리 완료로 표시하고 어떻게 해결했는지 남깁니다.서버 관리
/bug reopen <number>고쳐지지 않았을 때, 닫힌 신고를 목록으로 되돌립니다.서버 관리

/channels

종류마다 다른 채널로 보냅니다.

명령하는 일사용 가능
/channels set <kind> <channel>업데이트·예고·버그 신고·요청 중 하나를 지정한 채널로 보냅니다.서버 관리
/channels show네 가지 종류가 지금 어디로 가는지 보여 줍니다.누구나
/channels clear <kind>해당 종류를 서버 기본 채널로 되돌립니다.서버 관리

/language

이 서버에서 봇이 사용할 언어를 고릅니다.

명령하는 일사용 가능
/language set <language>언어를 설정합니다. 이후 공지·양식·답변이 모두 그 언어가 됩니다.서버 관리
/language show이 서버에 설정된 언어를 보여 줍니다.누구나

/release

모드팩과 Corvus의 업데이트 공지.

명령하는 일사용 가능
/release channel <channel>기본 채널을 설정합니다. 따로 지정하지 않은 것은 모두 여기로 옵니다.서버 관리
/release status이 서버의 현재 설정을 모두 보여 줍니다.누구나
/release latest봇이 아는 최신 릴리스를 채널에 공지하지 않고 보여 줍니다.누구나
/release enable이 서버의 공지를 다시 켭니다.서버 관리
/release disable봇을 내보내거나 설정을 잃지 않고 공지만 멈춥니다.서버 관리
/release launcher <enabled>Corvus 런처 빌드도 함께 공지할지 고릅니다.서버 관리
/release upcoming <enabled>사전 예고를 켜거나 끄고, 다음에 올 것을 보여 줍니다.누구나
/release test견본 공지를 올려 채널과 권한을 확인할 수 있습니다.서버 관리

/request

기능이나 변경을 요청하고 이후 경과를 확인합니다.

명령하는 일사용 가능
/request new짧은 양식이 열립니다. 무엇을 원하는지, 왜 도움이 되는지 적습니다.누구나
/request list <status>이 서버의 요청을 미해결부터 보여 줍니다. 답변은 본인에게만 보입니다.누구나
/request close <number> <resolution>요청을 처리 완료로 표시하고 결정을 남깁니다.서버 관리
/request reopen <number>닫힌 요청을 목록으로 되돌립니다.서버 관리

같은 종류는 한 사람당 10분에 3건까지입니다. 버그를 신고해도 요청은 막히지 않습니다.

13개 언어

언어는 개인이 아니라 서버 단위로 고릅니다. 공지는 공용 채널로 가므로 그 채널을 보는 모두가 같은 글을 읽어야 하기 때문입니다. 양식·답변·오류 메시지도 같은 설정을 따릅니다.

저장되는 것

신고에는 양식에 적은 내용, 디스코드 사용자 ID와 표시 이름, 그리고 올라간 위치만 남습니다. 그게 전부입니다. 메시지 기록은 저장하지 않고, 지정되지 않은 채널은 읽지 않으며, 마인크래프트 계정과는 무관합니다.
