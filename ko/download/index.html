다운로드

Alpha MOD 팩(총 11개 MOD)의 배포 ZIP을 이 페이지에서 바로 다운로드하실 수 있습니다. 내용물은 11개의 MOD jar·삿포로 MOD용 데이터 파일·설치 안내서·README·리소스 팩입니다.

Alpha_MODs_v3.2.0+mc26.2.zip

SHA-256 5514ad49630cbaebf3dafaf399c1aeefa36568e301bb4dad672c1f12e52172f3

다운로드

서버 관리자용: ZIP 안의 jar 파일을 그대로 mods 폴더에 풀어 주십시오. 삿포로 MOD만은 함께 들어 있는 sapporo_mode_a.spro를 서버 쪽 config/sorakaze_sapporo/data/ 폴더에 추가로 복사해야 합니다(아래 「설치 방법」도 참고해 주십시오).

삿포로 MOD(sorakaze-sapporo)는 V2.2.0에서 처음 배포되었습니다. 실제 삿포로시의 지형·건물을 바탕으로 한 도시 생성 월드입니다(건물 높이는 현재 추정값이며, 3D 건물 데이터를 확보한 뒤 갱신할 예정입니다).

V3.2.0의 변경 내용

컴퓨터와 휴대전화의 운영체제를 Mine OS에서 Corvus OS로, 은행 화면을 Mine Bank에서 Corvus 뱅크로 변경했습니다. 데스크톱 앱과 이 사이트가 이미 쓰는 이름과 같아집니다. 운영체제의 외형은 Linux 풍으로 새단장하여 부팅 로그, 차분한 배색, 까마귀 모양의 마크를 넣었습니다. 컴퓨터 화면은 더 이상 뒤의 세계가 비쳐 보이지 않고 불투명해져 진짜 디스플레이처럼 보입니다. ATM도 투입구와 키패드가 그림이 아니라 실제 형태가 되도록 다시 만들었습니다. 업데이트 기록 보기 →

Corvus

Corvus는 Alpha MOD 팩을 자동으로 최신 상태로 유지해 주는 데스크톱 앱입니다. 다운로드하는 파일은 모두 SHA-256으로 이 Wiki와 대조됩니다 —— 신뢰하는 정보원은 이 Wiki뿐입니다.

소라카제카라스 서버 도입 MOD 비공식 레퍼런스

본 사이트는 비공식 레퍼런스입니다. V2.2.0부터 MOD 본체(jar 파일)는 이 사이트의 "다운로드" 페이지에서 직접 배포합니다. 레시피·수치는 설치된 버전이나 서버 측 config 조정에 따라 실제와 다를 수 있습니다. Minecraft는 Mojang Studios의 상표입니다. 본 사이트와 여기서 배포하는 MOD는 공식이 아니며 Mojang Studios·Microsoft와 관련이 없습니다.
