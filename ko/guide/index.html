개요: Glimpse Alpha 설치에 대해

Glimpse Alpha(구칭: Sorakaze)는 소라카제카라스 서버에 도입되어 있는 Fabric MOD 모음입니다. 8개의 독립된 MOD로 구성되어 있으며, 각각 개별적으로 설치·업데이트할 수 있습니다. 활과 화살, 광산 수레 등 바닐라(MOD 없는 표준) 요소를 대체하거나 삭제하지 않고, 새로운 아이템·블록·차원을 추가하는 형태로 되어 있습니다.

MOD내용
총기바닐라에 없는 원거리 무기(어설트 라이플·샷건·스나이퍼 등)
철도점점 빨라지는 전철과, 연결할 수 있는 객차·화물차
건축자재·장식신호등·가드레일 등 도시 건설용 건축자재와, 방범 카메라·ATM·엘리베이터 등의 가전
탈것자동차·버스·항공기 등
보스강력한 토벌 대상과, 전용 드롭 장비
천공새로운 차원 "천공"과, 그곳에 사는 천사의 도시·왕국
서바이벌새로운 광석·방어구와, 기온·사계절 같은 생활 요소
전력발전·송전망과, 전기로 움직이는 기기

각 MOD의 자세한 아이템·레시피는 레시피 모음, 지금까지의 변경 사항은 업데이트 기록을 참고해 주세요.

MOD를 사용하려면 "Fabric"이 필요합니다

Fabric(패브릭)은 Minecraft가 MOD를 불러올 수 있게 해주는 토대입니다. 게임기에 소프트웨어를 넣기 전에 본체 시스템이 필요한 것과 같은 이미지로, MOD 본체를 넣기 전에 먼저 서버와 각 플레이어의 PC 양쪽 모두에 Fabric을 설치해야 합니다.

⚠ 가장 헷갈리기 쉬운 부분

MOD는 서버뿐만 아니라 플레이하는 사람 전원의 PC에도 동일한 것을 설치해야 합니다. "서버에 넣으면 모두에게 자동으로 반영된다"는 일은 없습니다. 서버와 모든 플레이어의 Minecraft 버전·Fabric·MOD 조합이 맞지 않으면 서버에 참가할 수 없습니다.

누가 무엇을 준비하는가

  • 서버(소라카제카라스 서버) — Fabric 서버 본체 + Fabric API + Glimpse Alpha 8개 MOD
  • 참가하는 사람 각자의 PC — Fabric 클라이언트 + Fabric API + Glimpse Alpha 8개 MOD(서버와 완전히 동일한 조합)
MOD 본체는 이 사이트에서 배포하지 않습니다

이 사이트는 레시피표·업데이트 기록·설치 방법 등 "읽는 자료"만 게재하고 있으며, MOD 본체(jar 파일) 자체는 배포하지 않습니다. 설치에 필요한 jar 파일 일체는 서버 관리자에게 받아 주세요.

이 페이지의 구성

이 가이드는 두 가지 입장으로 나뉘어 작성되어 있습니다. 대부분의 경우 플레이어용 장만 읽으면 참가할 수 있습니다. 직접 서버를 운영·관리하는 입장이신 분은 이어서 서버 관리자용 장도 봐 주세요.

플레이어용: 서버에 참가하기 위한 설정

여기서는 서버에 놀러 가는 쪽의 설정을 설명합니다. 어려운 전문 지식은 필요 없습니다. 위에서부터 순서대로 하면 대략 15~20분이면 끝납니다.

할 일은 딱 3가지
  • ① Fabric(MOD를 불러오는 토대)을 내 PC에 설치
  • ② 서버 관리자에게 받은 MOD 파일 일체를, 정해진 폴더에 넣기
  • ③ 실행 방법을 한 곳만 바꿔서 서버에 참가

준비물

  • Minecraft Java 에디션을 플레이할 수 있는 Windows 또는 Mac PC
  • 서버 관리자에게 받은 MOD 일체(jar 파일 9개 = Fabric API 1개 + Glimpse Alpha MOD 8개)
🛑 매우 중요

서버와 완전히 동일한 버전·완전히 동일한 MOD 파일이 아니면 참가할 수 없습니다. 이 페이지에서는 예시로 Minecraft 버전 26.2라고 적지만, 서버 관리자에게 다른 숫자를 안내받았다면 그 숫자로 바꿔서 읽어 주세요. 받은 jar 파일은 더블클릭해서 열지 마세요. 폴더에 넣기만 하면 사용할 수 있습니다.

① Fabric 설치하기

https://fabricmc.net/use/installer/를 열어 인스톨러를 받습니다. "Client" 탭 그대로 두고("Server"로 바꾸지 않음), Minecraft Version에 서버와 같은 숫자를 선택한 뒤 "Install"을 누릅니다.

Windows의 경우

  1. 페이지의 "Download installer (Windows/.exe)" 같은 버튼으로 인스톨러를 다운로드하고, 더블클릭으로 실행합니다("Windows에서 PC를 보호했습니다"라는 메시지가 뜨면 "추가 정보" → "실행"을 누릅니다).
  2. "Client" 탭 그대로 둔 채, Minecraft Version에 26.2(서버와 같은 숫자)를 선택하고 Loader Version은 그대로 두어 "Install"을 누릅니다.

Mac의 경우

  1. "Download universal jar" 버튼으로 인스톨러(.jar)를 다운로드합니다. Mac용 실행 파일(.exe)은 없습니다.
  2. 다운로드한 fabric-installer-….jar를 일반 더블클릭이 아니라 우클릭(또는 control 키를 누른 채 클릭)해서 "열기"를 선택합니다. 경고가 뜨면 다시 한번 "열기"를 누릅니다.
  3. "Client" 탭 그대로 둔 채, Minecraft Version에 서버와 같은 숫자를 선택해 "Install"을 누릅니다.
⚠ Mac에서 "개발자를 확인할 수 없음"이 뜨는 경우

최신 macOS에서는 우클릭 → "열기"를 해도 버튼이 나오지 않고, "'fabric-installer….jar'에 멀웨어가 없는지 확인할 수 없습니다"라는 경고만 뜨는 경우가 있습니다. 그럴 때는 다음 순서로 열 수 있습니다.

  1. 경고 창에서는 "완료"를 누름("휴지통으로 이동"은 절대 누르지 마세요)
  2. 화면 왼쪽 위 Apple 메뉴 → "시스템 설정" → "개인정보 보호 및 보안"을 엽니다
  3. 아래쪽에 "'fabric-installer….jar'의 사용이 차단되었습니다"라는 표시가 있으니, 옆의 "그래도 열기"를 누릅니다
  4. 다시 물어보면 "그래도 열기" → Mac 비밀번호(또는 Touch ID) 입력

이는 Apple에 등록되지 않은 배포물 전반에 뜨는 표준 경고이며, Fabric 공식 사이트에서 받은 것이라면 걱정하지 않아도 됩니다. 한 번 허용하면 다음부터는 평범하게 열립니다.

Mac에서 인스톨러가 아무 반응이 없는 경우

우클릭 → "열기"를 해도 아무 일도 일어나지 않는다면 시스템에 Java가 설치되어 있지 않은 것입니다. adoptium.net을 열어 "Temurin"의 macOS용 인스톨러(.pkg)를 설치한 뒤 다시 시도해 주세요. Apple 실리콘(M1/M2/M3/M4 등) Mac은 "aarch64", Intel Mac은 "x64"를 선택합니다. 잘 모르겠다면 화면 왼쪽 위 Apple 메뉴 → "이 Mac에 관하여"의 "칩" 항목을 확인해 주세요("Apple M…"이라고 되어 있으면 aarch64입니다).

② MOD 파일을 mods 폴더에 넣기

Windows: %appdata%\.minecraft\mods

  1. 탐색기 주소 표시줄에 %appdata%\.minecraft를 입력하고 Enter를 누릅니다.
  2. mods 폴더가 없다면 새로 만듭니다(모두 소문자).
  3. 받은 9개의 jar 파일을 모두 이 mods 폴더 안에 복사합니다(압축을 풀 필요 없이 jar 그대로 넣습니다).

Mac: ~/Library/Application Support/minecraft/mods

  1. 바탕화면을 한 번 클릭한 뒤, ⌘ command+⇧ shift+G를 동시에 누릅니다(또는 상단 메뉴의 "이동" → "폴더로 이동…").
  2. 나타난 입력란에 ~/Library/Application Support/minecraft를 그대로 붙여넣고 Enter를 누릅니다(맨 앞의 "~"도 잊지 마세요). "Library"는 Finder에서 평소에는 보이지 않는 폴더이므로, 이 방법으로 여는 것이 확실합니다.
  3. mods 폴더가 없다면 그 자리에서 우클릭 → "새로운 폴더"로 만듭니다.
  4. 받은 9개의 jar 파일을 모두 드래그 앤 드롭으로 이 mods 폴더에 넣습니다.

③ Fabric으로 실행해서 서버에 참가하기

  1. Minecraft 런처를 열고, "플레이" 버튼 근처의 실행 구성(프로필) 목록에서 fabric-loader-26.2 같은 이름을 선택합니다("최신 릴리스" 상태로는 MOD 없이 실행되어 버립니다).
  2. 그대로 "플레이"를 눌러 실행합니다. 타이틀 화면에 "Mods" 버튼이 늘어나 있으면 성공입니다. 눌러 보면 Glimpse Alpha의 MOD 8개와 Fabric API를 확인할 수 있습니다.
  3. 이후에는 평소처럼 "멀티플레이"에서 서버에 접속합니다.

MOD가 업데이트되었을 때

서버 측 MOD가 업데이트되면, 참가자 전원이 동시에 같은 버전으로 업데이트해야 합니다.

  1. 서버 관리자에게 새 MOD 파일을 받습니다(공지를 기다린 뒤 작업해 주세요).
  2. mods 폴더를 열고, 지금까지 있던 Glimpse Alpha의 jar 파일을 삭제한 다음 새 파일을 넣습니다(파일명이 바뀌어도 내용은 같은 MOD로 취급되므로, 기존 것이 남아 있으면 실행할 수 없습니다).
  3. 평소처럼 fabric-loader 프로필로 실행합니다.
⚠ 주의

한쪽만 새 버전인 채로 두면 서버에 참가할 수 없습니다. 곤란할 때는 자주 묻는 질문도 확인해 주세요.

인스톨러를 더블클릭해도 아무 일도 일어나지 않는다Java가 설치되어 있지 않은 것입니다. adoptium.net에서 Temurin(macOS용 .pkg)을 설치한 뒤 다시 시도해 주세요.
"Library" 폴더를 찾을 수 없다직접 찾을 필요는 없습니다. ⌘+⇧+G로 ~/Library/Application Support/minecraft를 붙여넣는 것이 확실합니다(평소에는 숨겨진 폴더입니다).
서버에 들어가려고 하면 버전이 다르다고 한다①런처에서 올바른 fabric-loader 프로필을 선택했는지, ②mods 폴더의 내용물이 서버와 같은지를 확인해 주세요. 하나라도 다르면 참가할 수 없습니다.

MOD 없는 일반 Minecraft로 되돌리고 싶다런처의 실행 구성을 "최신 릴리스"로 되돌리기만 하면 됩니다. MOD 파일을 지울 필요는 없습니다.

Apple 실리콘(M1/M2/M3/M4 등)이든 Intel Mac이든 절차는 동일합니다. 다른 점은 Java(Temurin)를 선택할 때 aarch64인지 x64인지뿐입니다.

서버 관리자용

서버 관리자용: 사전 준비(백업과 버전 확인)

여기서부터는 서버 본체를 운영·관리하는 입장인 분들을 위한 장입니다. 이미 Minecraft 서버(바닐라, MOD 없는 표준 서버)가 가동 중인 상태에서, Fabric과 Glimpse Alpha의 8개 MOD를 추가하는 절차를 설명합니다. 이 장에서는 Windows 서버를 예로 듭니다. Mac / Linux로 서버를 운영하는 경우에는 폴더 위치나 명령어 실행 방법을 각자의 환경에 맞게 바꿔서, 동일한 절차(Fabric 공식 사이트의 안내)를 따라 주세요.

🛑 작업 전에 반드시

MOD 설치에 실패하더라도 월드를 잃지 않도록, 반드시 백업을 받아 놓은 뒤 작업을 시작해 주세요.

1. 월드 백업하기

서버 폴더(예: C:\MinecraftServer)를 열고, 평소 사용하는 백업 절차(예: Backup-Server.bat 같은 백업용 스크립트)를 실행합니다. 전용 스크립트가 없다면, 서버를 정지한 상태에서 world 폴더를 통째로 다른 위치에 복사해 두는 것만으로도 괜찮습니다.

2. Java 버전 확인하기

  1. 명령 프롬프트(또는 원하는 터미널)를 엽니다.
  2. java -version을 입력하고 Enter를 누릅니다.
  3. 표시된 숫자가 25인지 확인합니다(예: java version "25.0.3").
🛑 매우 중요

Minecraft 26.2를 실행하려면 Java 25가 필요합니다. 오래된 설치 안내서에 "Java 21"이라고 적혀 있는 경우가 있는데, 이는 오래된 정보이며 Java 21 그대로는 서버가 실행되지 않습니다. 숫자가 25 미만이라면 adoptium.net을 열어 "Temurin 25 (LTS)"를 다운로드·설치한 뒤, 컴퓨터를 재시작하고 다시 확인해 주세요.

3. 서버의 Minecraft 버전 확인하기

  1. 평소 방법(예: Start-Server.bat)으로 서버를 일단 실행합니다.
  2. 콘솔(검은 화면) 초반에 나오는 Starting minecraft server version X.Y 같은 줄을 찾아, 그 숫자를 메모합니다.
  3. 콘솔에 stop을 입력하고 Enter를 눌러 서버를 안전하게 정지합니다.
⚠ 주의

이 가이드에서는 예시로 "26.2"라고 표기하지만, 실제로 확인한 숫자가 다르다면 이후 모든 절차(Fabric·Fabric API·각 MOD 버전 선택)를 그 숫자로 바꿔서 진행해 주세요. 서버·모든 플레이어·MOD의 버전이 하나라도 맞지 않으면 전혀 작동하지 않습니다.

서버 관리자용

서버 관리자용: Fabric 설치

Fabric 서버 설치하기

  1. 브라우저에서 https://fabricmc.net/use/server/를 열고, "Download installer (Windows/.exe)" 같은 버튼으로 인스톨러를 다운로드합니다.
  2. 다운로드한 fabric-installer….exe를 더블클릭해 실행합니다("Windows에서 PC를 보호했습니다"라고 뜨면 "추가 정보" → "실행").
  3. 인스톨러 설정 화면에서 다음 4가지를 확인합니다.
    • 탭은 "Server"를 선택
    • Minecraft Version은 사전 준비에서 확인한 서버 버전(예: 26.2)과 동일한 것을 선택
    • Loader Version은 그대로 두면 OK
    • Install Location은 기존 서버 폴더(예: C:\MinecraftServer)를 지정
  4. "Install"을 누릅니다.
  5. 서버 폴더 안에 fabric-server-launch.jar라는 새 파일이 생겼다면 성공입니다.

새로운 실행용 파일(배치 파일) 만들기

지금까지의 실행용 파일(예: Start-Server.bat)은 "MOD 없음"을 실행하는 파일입니다. 이것은 삭제하지 말고 남겨 둡니다(만약을 위해 MOD 없는 상태로 돌아갈 수 있도록). 대신 Fabric용 새 실행 파일을 만듭니다.

  1. 메모장(Notepad)을 엽니다.
  2. 다음 내용을 그대로 복사해 붙여넣습니다. 
    @echo off
cd /d "%~dp0"
title Minecraft Fabric Server
java -Xms2G -Xmx4G -jar fabric-server-launch.jar nogui
echo 서버가 정지되었습니다.
pause
  3. "파일" → "다른 이름으로 저장"에서, 저장 위치를 서버 폴더(예: C:\MinecraftServer), 파일 이름을 Start-Fabric-Server.bat, 파일 형식을 "모든 파일"로 하여 저장합니다.
⚠ 주의

"파일 형식"을 "모든 파일"로 하지 않으면 Start-Fabric-Server.bat.txt라는 작동하지 않는 파일이 되어 버립니다. 또한 서버 구축 시 할당한 메모리(RAM)가 4GB가 아닌 경우에는 -Xmx4G의 "4"를 해당 숫자로 고쳐 주세요.

서버 관리자용

서버 관리자용: MOD 설치와 실행 확인

MOD 본체는 "jar(자)" 파일이라는 파일 하나하나로 되어 있습니다. 이것을 서버 폴더의 mods 폴더에 넣기만 하면 설치할 수 있습니다.

1. mods 폴더 준비하기

서버 폴더(예: C:\MinecraftServer) 안에 mods라는 이름의 폴더가 있는지 확인합니다. 없다면 우클릭 → "새로 만들기" → "폴더"로 mods(모두 소문자)라는 이름으로 만듭니다.

2. Fabric API 받기

https://modrinth.com/mod/fabric-api/versions를 열고, 목록에서 "Game version(게임 버전)이 서버와 같은 숫자"로 되어 있는 것 중 맨 위의 것을 다운로드합니다(예: fabric-api-0.154.2+26.2.jar).

3. MOD 일체를 mods 폴더에 넣기

Fabric API 1개 + Glimpse Alpha MOD 8개, 총 9개의 jar 파일을 mods 폴더 안에 복사합니다(압축을 풀 필요 없이 jar 파일 그대로 넣습니다). 이 8개 MOD 본체는 지금까지와 같은 배포 경로로 받아 주세요. 이 사이트에서는 MOD 본체 자체를 배포하지 않습니다.

MOD파일명 예시
총기glimpse-alpha-guns-…+mc26.2.jar
철도glimpse-alpha-rail-…+mc26.2.jar
건축자재·장식glimpse-alpha-deco-…+mc26.2.jar
탈것glimpse-alpha-vehicles-…+mc26.2.jar
보스glimpse-alpha-boss-…+mc26.2.jar
천공glimpse-alpha-sky-…+mc26.2.jar
서바이벌glimpse-alpha-survival-…+mc26.2.jar
전력glimpse-alpha-power-…+mc26.2.jar
⚠ 주의

jar 파일은 더블클릭하지 마세요(열 필요가 없습니다). 폴더에 넣기만 하면 OK입니다.

4. 서버를 실행해서 확인하기

  1. 앞서 만든 Start-Fabric-Server.bat을 더블클릭합니다(지금까지의 Start-Server.bat은 사용하지 않습니다).
  2. 콘솔(검은 화면)에서 다음 2가지를 확인합니다.
    • MOD를 불러오는 줄에 설치한 MOD의 이름이 나와 있는지
    • 마지막에 Done (…s)! For help, type "help"가 표시되고, 멈추지 않고 계속 작동하는지
💡 Java 오류가 나며 실행되지 않는 경우

"class file version", "requires Java" 같은 영어 오류가 나온다면 Java가 오래되었을 가능성이 있습니다. adoptium.net에서 "Temurin 25 (LTS)"의 Windows용(.msi)을 설치하고, 컴퓨터를 재시작한 뒤 다시 시도해 주세요.

실행이 확인되었다면, 다음으로 플레이어용 장을 참가자 전원에게 안내하여 각자의 PC에도 동일한 Fabric·MOD 일체를 설치하도록 해 주세요.

서버 관리자용

MOD를 새 버전으로 교체할 때

Glimpse Alpha는 8개의 MOD가 각각 완전히 독립되어 있으므로, 업데이트할 때마다 8개 전부가 교체되는 것은 아닙니다. 실제로 내용이 바뀐 MOD만 교체하면 됩니다 (어떤 MOD가 바뀌었는지는 배포 시 안내나 업데이트 기록에서 확인할 수 있습니다).

업데이트 절차

  1. 서버 콘솔에 stop을 입력해 서버를 정지시킵니다.
  2. 평소의 백업 절차로 월드를 백업합니다.
  3. 서버의 mods 폴더 안에서 업데이트 대상 MOD의 예전 jar 파일을 삭제하고, 새 jar 파일을 넣습니다(같은 MOD의 신구 버전이 둘 다 남아 있으면 실행할 수 없습니다).
  4. Start-Fabric-Server.bat으로 서버를 실행하여, 콘솔에 업데이트된 버전이 표시되는지 확인합니다.
  5. 참가자 전원에게도 새 jar 파일을 배포하여, 마찬가지로 교체하도록 안내합니다(플레이어용 장 참고). 서버 쪽만, 또는 플레이어 쪽만 새 버전이 된 상태로는 참가할 수 없습니다.
🛑 매우 중요

MOD를(업데이트가 아니라) 완전히 제거한 상태로 서버를 실행하면, 그 MOD로 설치한 블록이나 가지고 있던 아이템(신호등 등)은 사라집니다. 이는 Minecraft·Fabric의 사양이며 되돌릴 수 없습니다. 제거하기 전에 반드시 백업을 받아 주세요.

config 파일에 대해(자동 복구 구조)

각 MOD는 실행 시 config/ 폴더 안에 설정 파일(예: sorakaze_guns.json)을 자동으로 생성합니다. 위력이나 속도 같은 수치는 여기서 조정할 수 있으며, 업데이트할 때마다 수동으로 지우거나 고쳐 쓸 필요는 기본적으로 없습니다.

💡 현재의 구조

새 버전에서 기본값이 바뀐 항목은, 아직 조정하지 않은(예전 기본값 그대로인) 항목에 한해 자동으로 새 기본값으로 갱신됩니다. 직접 조정한 값에는 손대지 않습니다. 새로 추가된 설정 항목도 실행 시 자동으로 추가됩니다. 무엇이 갱신되었는지는 logs/latest.log에 "이전 값 → 새 값" 형태로 반드시 기록됩니다.

⚠ 설정 파일을 편집할 때 주의할 점

설정 파일 안의 값 일부만 수동으로 삭제하면(예: 어떤 무기 설정 묶음에서 데미지 줄만 지우는 경우), 그 항목이 MOD 내부의 다른 초기값으로 조용히 바뀌어 버릴 수 있습니다 (오류는 나타나지 않습니다). 특정 수치를 조정하고 싶을 때는 그 항목의 값을 직접 고쳐 쓰도록 해 주세요. 설정을 통째로 초기 상태로 되돌리고 싶다면, 해당 MOD의 설정 파일 자체를 삭제하면 다음 실행 시 기본값으로 다시 만들어집니다.

플레이 전에 알아두면 좋은 주의사항

Glimpse Alpha는 바닐라 동작에 영향을 주는 변경도 몇 가지 포함하고 있습니다. 여기서는 특히 놓치기 쉬운 것들을 정리했습니다. 세부 수치는 업데이트마다 조정될 수 있으므로, 최신 상황은 업데이트 기록이나 알려진 문제 페이지도 함께 확인해 주세요. config 조정은 서버 관리자가 수행하는 작업입니다.

레드스톤에 "전기"가 필요합니다

전력 MOD 도입으로 바닐라 레드스톤의 일부가 단독으로는 작동하지 않게 됩니다.

  • 전기가 필요해지는 것: 레드스톤 가루·반복기(리피터)·비교기(컴퍼레이터)·레드스톤 블록·레드스톤 횃불. 이들은 케이블로 전기를 연결하기 전까지는 신호를 내지 않습니다. 자동 농장·역·자동문·호퍼 라인은 배선할 때까지 멈춰 있습니다.
  • 전기가 없어도 지금까지처럼 사용할 수 있는 것: 레버·버튼·감압판·트립와이어 고리·관측기·햇빛 감지기·스컬크 감지기·표적(타깃)·트랩 상자·감지 레일·강독대·주크박스·피뢰침 등. 문이나 대문을 손으로 여는 조작도 그대로 사용할 수 있습니다.
  • 설치 후 10분 정도 지나면 레드스톤 블록은 자연히 부서집니다(아이템으로 손에 돌아옵니다).
💡 원래대로 되돌리는 방법(서버 관리자용)

config/sorakaze_power.json의 powerEnabled를 false로 하면 레드스톤 전기화를 통째로 비활성화할 수 있습니다.

건축자재·장식 일부 기기도 전기가 필요합니다

방범 카메라·엘리베이터·에스컬레이터·자동문·ATM, 이 5가지는 케이블로 전기를 끌어오지 않으면 작동하지 않습니다(엘리베이터는 전기가 없어도 "하강"만은 작동하도록 되어 있습니다). 기기별로 config/sorakaze_deco.json의 해당 항목을 false로 하면 개별적으로 전기를 필요 없게 할 수 있습니다.

발전기는 방을 덥게 만듭니다

가동 중인 발전기·원자력 발전소는 같은 공간의 기온을 높입니다. 식힐 수 있는 것은 에어컨뿐입니다. 기계실을 벽과 닫힌 문으로 구분해 두면, 열이 다른 방으로 퍼지지 않아 쉽게 대처할 수 있습니다. 이 기능 자체는 config/sorakaze_survival.json의 temperatureMachineHeatEnabled를 false로 하면 비활성화할 수 있습니다.

천공 세계의 높이가 확장되어 있습니다

천공 MOD 도입으로 인해, 일반 세계(오버월드)에서 건축할 수 있는 높이 상한이 상향되었습니다. 바뀌는 것은 하늘 쪽 상한뿐이며, 지하 깊이(바닥 높이)나 기존 지형은 그대로입니다.

로켓 런처는 지형을 파괴합니다

총기 MOD의 로켓 런처는 기본 설정에서 착탄 지점의 지형을 파괴합니다. 바닐라 게임 규칙 mobGriefing을 false로 해도 멈추지 않습니다. 파괴를 막으려면 config/sorakaze_guns.json의 rocketDestroysTerrain을 false로 설정해야 합니다. 거점 근처에서는 특히 주의해 주세요.

총기 화력에 대해

총기 MOD의 무기, 특히 어설트 라이플은 매우 높은 화력을 가지고 있어, MOD로 추가된 보스 대부분을 몇 초 만에 쓰러뜨릴 수 있습니다. 손맛을 원한다면 서버 관리자가 config/sorakaze_guns.json에서 각 무기의 데미지 값을 조정해 난이도를 되돌릴 수 있습니다.

MOD를 제거하면 설치한 블록·아이템은 사라집니다

이는 MOD 전반의 사양이며, Glimpse Alpha만의 문제가 아닙니다. MOD를 설치한 상태에서 설치한 블록이나 입수한 아이템은 그 MOD를 제거하면 월드에서 사라집니다. 원래대로 되돌리려면 백업에서 복원하는 수밖에 없습니다.

오류 메시지의 영어를 읽을 수 없어요읽지 못해도 괜찮습니다. logs 폴더 안의 latest.log라는 파일을 그대로 서버 관리자에게 보내 주세요.

서버가 실행되지 않는 경우

  1. mods 폴더 안의 내용을 일단 전부 다른 곳으로 옮겨 둡니다.
  2. 하나씩 되돌려 넣으면서 실행을 반복해, 어떤 파일이 원인인지 찾아냅니다.
  3. Java 관련 오류가 나온다면, 사전 준비 장을 참고해 Java 버전을 확인합니다.

서버에는 들어가지지만 접속이 안 되는 경우

  1. 참가자 전원의 버전과 MOD 조합이 서버와 완전히 동일한지 확인합니다.
  2. 특히 Fabric API 버전 차이가 원인이 되기 쉬우므로 우선적으로 확인합니다.
💡 그래도 해결되지 않을 때는

logs/latest.log를 서버 관리자에게 보내 상담해 주세요. 서두르지 않으셔도 됩니다. 백업이 있으면 언제든 원래 상태로 되돌릴 수 있습니다.

백업에서 월드를 복원하는 방법(서버 관리자용)

  1. 서버 콘솔에 stop을 입력해 서버를 정지합니다.
  2. 백업 저장 위치(예: C:\MinecraftServer\backups)에서 가장 최신 백업을 꺼냅니다(zip 형식이라면 우클릭 → "압축 풀기").
  3. 꺼낸 world 폴더를, 서버 폴더 안의 world 폴더와 교체합니다(덮어씁니다).
  4. 서버를 실행합니다.
