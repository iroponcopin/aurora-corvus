현재 파악된 사소한 문제와, 개발 환경 특성상 아직 실기에서 확인하지 못한 요소를 정리했습니다. 심각한 문제는 발견되는 대로 업데이트 기록과 같이 수정판이 배포됩니다.

현재 파악된 사소한 문제

작동에는 지장이 없지만, 표시나 외형에 영향을 주는 알려진 문제입니다.

의도적으로 대응하지 않은 요소

버그가 아니라, 사양으로서 향후 대응이 검토되고 있는 항목입니다.

크라켄·타이탄의 전용 공격 모션

이 두 거대 보스는 필살기 예고는 파티클로 표시되지만, 몸을 움직이는 전용 공격 모션은 아직 구현되지 않았습니다. 의도적으로 보류된 사양이며, 대응 여부는 서버 관리자의 판단을 기다리고 있습니다.

실기에서 아직 확인하지 못한 최근 변경 사항

이 MOD 팩은 개발 시 Minecraft 클라이언트를 직접 조작할 수 없는 환경에서 제작되었습니다. 서버 구동과 데이터 정합성은 기계적으로 검증되었지만, 외형·소리·조작 시 느낌은 실제로 플레이한 사람의 피드백을 통해서만 확인할 수 있습니다. 아래는 최근 업데이트 중 아직 실기 확인이 되지 않은 항목입니다. 이상한 점이 있다면 서버 관리자에게 알려 주세요.

  • 수도관·방독면의 외형: v1.8.5에서 새로 만든 외형·충돌 판정이 실제 화면에서 어떻게 보이는지는 미확인입니다.
  • 강화 비콘 GUI의 조작감: 알파/베타 강화 비콘의 능력 선택 화면 사용 편의성은 미확인입니다.
  • 적 스폰 밀도(오버월드): v1.8.5에서 조정된 스폰 밀도가 실제로 플레이하기에 딱 좋은지는 미검증입니다.
  • 탄두·휴대폰 앱의 새 아이콘: v1.8.6에서 추가된 미사일 탄두·핵탄두 아이콘과 휴대폰 앱의 새로운 화면 디자인은, 실제 게임 화면에서는 아직 확인되지 않았습니다.
  • 방범 카메라·엘리베이터 등 전기화 이후의 동작: v1.8.3에서 전기가 필요해진 5가지 기기(방범 카메라·엘리베이터·에스컬레이터·자동문·ATM)에 대해, 전기가 있는/없는 상태 각각에서의 실제 동작 확인은 아직 이루어지지 않았습니다.
  • 레드스톤 전기화(v1.8.1~)의 플레이 감각: 농장이나 역의 자동화가 어느 정도 멈추는지, 다시 배선하는 수고가 얼마나 드는지는 실제로 플레이해 보지 않으면 알 수 없습니다.

소라카제카라스 서버 도입 MOD 비공식 레퍼런스

본 사이트는 비공식 레퍼런스입니다. V2.2.0부터 MOD 본체(jar 파일)는 이 사이트의 "다운로드" 페이지에서 직접 배포합니다. 레시피·수치는 설치된 버전이나 서버 측 config 조정에 따라 실제와 다를 수 있습니다. Minecraft는 Mojang Studios의 상표입니다. 본 사이트와 여기서 배포하는 MOD는 공식이 아니며 Mojang Studios·Microsoft와 관련이 없습니다.
