향후 계획

향후 계획

개발 측 발주 문서를 바탕으로, 현재 계획 중인 차기 업데이트 내용을 소개합니다.

이 페이지의 내용은 아직 구현·배포되지 않았습니다. 사내 기획 메모를 바탕으로 한 소개이며, 실제로 구현될 내용·시기·사양은 변경되거나 취소될 수 있습니다. 확정된 내용은 "업데이트 기록" 페이지에 반영됩니다.

계획 중 v1.9.0

새 지역 "백룸에서의 탈출"·위더 스톰 통합

새 지역 "백룸에서의 탈출"

  • 원작을 충실히 재현한 전용 맵을 새로 추가.
  • 지역 체류 중에는 "정신력(새니티)" 상태가 도입되며, 지역 내에서 드롭되는 "아몬드 워터" 등으로 회복할 수 있을 예정.
  • 지역 내에서는 블록 설치·파괴가 불가능한 특수 규칙.
  • 전리품이 든 상자를 곳곳에 배치.
  • 원작을 재현한 몬스터·기믹이 등장.
  • 입구는 엔드 시티 내부에 무작위로 생성될 예정.
  • 진행 상황은 화면 왼쪽에 텍스트로 항상 표시될 예정.

위더 스톰 통합

  • 외부 "Wither Storm" MOD를 mods 폴더에 동봉하는 형태로 통합할 예정.
  • 페스트 의사가 위더 스톰을 소환하게 됨.
  • 토벌 보상으로 "만물 채집기 알파", "불꽃 인형 알파"(기존 만물 채집기·불꽃 인형의 상위 버전)가 드롭될 예정.
  • 만물 채집기 알파는 금 곡괭이 상당의 내구도이며 인챈트 불가.
  • 불꽃 인형 알파는 사용 횟수 무제한·쿨다운 3분이라는, 기존 불꽃 인형(3회 사용 제한)과는 다른 사양이 검토되고 있음.
계획 중 v1.9.1

철도 MOD 대폭 강화

운행 자동화

  • 열차 자동정지 블록에 자동 발차 기능을 추가할 예정.
  • 플레이어가 타지 않아도 달리는 "자동운전 모드"를 검토 중.
  • 주행음 추가.

새로운 차량·설비

  • 그린석 차량·그란클래스 등 상급 클래스 차량을 추가할 예정.
  • 가선(전차선)을 설치 아이템으로 추가.
  • 차량 내외 조명으로 야간 주행을 밝게.
  • 광산 수레끼리의 연결 지원.
  • 바닐라 레일을 완전 3D 모델화.
  • 스마트폰풍 다음 역·발차 안내 UI를 추가할 예정.
계획 중 v1.9.3

핵탄두 에너지·좌표 표시·UI 개선

새 기능

  • 핵탄두를 전력 MOD의 에너지원으로 사용할 수 있게 할 예정(v1.8.4에서 선행 구현된 미사일 탄두·핵탄두와는 다른 용도).
  • 항상 표시되는 좌표 UI를 추가할 예정.

개선

  • TPS·핑을 표시하는 UI 개선.

그보다 더 먼 구상(이번 업데이트에는 아직 포함되지 않음)

  • "고성능 코어": 작업대에서 메이스와 조합해, 메이스의 성능을 20배로 만드는 구상이 있다고 함.

Glimpse Alpha Wiki — 소라카제카라스 서버 도입 MOD 비공식 레퍼런스

본 사이트는 비공식 레퍼런스입니다. MOD 본체(jar 파일)는 배포하지 않습니다. 레시피·수치는 설치된 버전이나 서버 측 config 조정에 따라 실제와 다를 수 있습니다.
