Aureum (mod leve de otimização, download separado)

O Aureum é um mod independente. Ele otimiza a lógica do jogo, a memória e o custo do tick do servidor, e deliberadamente nunca toca no pipeline de renderização de chunks. Ele não substitui o Sodium: otimiza o lado que o Sodium não toca, por isso pode rodar junto. Se quiser mais FPS, instale o Sodium separadamente.

Medido até agora: -6,3 MB com 2.209 chunks carregados, -17,2 MB após gerar uma área nova de tamanho semelhante (reproduzido em duas execuções independentes). O MSPT (tempo de tick) não muda dentro da margem de ruído da medição. Dois ajustes do lado do cliente (limite de partículas, distância de renderização de bloco-entidade) vêm desativados por padrão e não medidos, pois este ambiente de desenvolvimento não tem cliente. Veja o README no GitHub para instalação e configuração.

Cada otimização pode ser desativada individualmente

Cada chave em config/aureum.json pode ser desativada de forma independente. Desativar uma significa que as alterações de bytecode do Aureum para aquele recurso nunca são aplicadas — a garantia mais forte possível caso haja conflito com outro mod.

Requisitos

  • Minecraft 26.3 (Fabric)
  • Fabric Loader 0.19.5+
  • Fabric API
  • Java 25+
