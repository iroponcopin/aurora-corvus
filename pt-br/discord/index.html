Bot do Discord

O Corvus avisa quando sai uma versão, conta ao seu servidor o que vem a seguir e recebe relatos e pedidos — no idioma que o servidor escolher.

Adicionar o bot ao seu servidor

Abre a página de autorização do próprio Discord. Você precisa de «Gerenciar servidor» no servidor de destino.

Uma página estática não consegue saber se o bot está online agora. Estes são os fatos que este site publica sobre ele.

Configuração

  1. 1. Adicione o bot

    Use o botão acima. Ele pede quatro coisas — ver um canal, enviar mensagens, incorporar links, ler o histórico — mais permissão para abrir um tópico por relato. Nunca pede administrador.

  2. 2. Escolha um canal

    Execute /release channel e escolha para onde vão os avisos. Esse passa a ser o canal padrão: tudo que você não direcionar chega ali.

  3. 3. Escolha o idioma

    Execute /language set. São treze idiomas, cada um escrito na sua própria grafia.

  4. 4. Separe (opcional)

    Com /channels set, dê um canal a cada coisa: atualizações, prévias, problemas e pedidos. O que você não definir continua no canal padrão. updateupcomingbugrequest

O que o bot publica sozinho

Três coisas, cada uma no seu canal se você tiver definido um. Nada é publicado duas vezes.

  • Sai uma versão — o pacote e, se você ativou, o próprio Corvus.
  • Algo é anunciado com antecedência, direto da página «A seguir».
  • Alguém relata um problema ou faz um pedido, com um tópico para conversar.

Todos os comandos

/bug

Relatar um problema e acompanhar o que acontece com ele.

ComandoO que fazQuem pode usar
/bug newAbre um formulário curto: um resumo de uma linha, o que aconteceu e, se você souber, como repetir.Qualquer pessoa
/bug list <status>Mostra os relatos deste servidor, os abertos primeiro. Só você vê a resposta, então confira antes de duplicar.Qualquer pessoa
/bug close <number> <resolution>Marca um relato como resolvido e registra como foi resolvido.Gerenciar servidor
/bug reopen <number>Devolve à lista um relato fechado, caso não estivesse mesmo corrigido.Gerenciar servidor

/channels

Enviar cada tipo de mensagem para o seu próprio canal.

ComandoO que fazQuem pode usar
/channels set <kind> <channel>Direciona uma categoria — atualizações, prévias, problemas ou pedidos — para um canal específico.Gerenciar servidor
/channels showLista para onde vai cada uma das quatro categorias no momento.Qualquer pessoa
/channels clear <kind>Devolve essa categoria ao canal padrão do servidor.Gerenciar servidor

/language

Escolher o idioma que este bot usa neste servidor.

ComandoO que fazQuem pode usar
/language set <language>Define o idioma. Avisos, formulários e respostas passam a segui-lo.Gerenciar servidor
/language showInforma o idioma configurado neste servidor.Qualquer pessoa

/release

Avisos de atualização do pacote e do Corvus.

ComandoO que fazQuem pode usar
/release channel <channel>Define o canal padrão. Tudo sem canal próprio chega aqui.Gerenciar servidor
/release statusMostra todas as configurações atuais deste servidor.Qualquer pessoa
/release latestMostra a versão mais recente que o bot conhece, sem anunciá-la no canal.Qualquer pessoa
/release enableLiga novamente os avisos neste servidor.Gerenciar servidor
/release disablePara os avisos sem remover o bot nem perder as configurações.Gerenciar servidor
/release launcher <enabled>Escolhe se as versões do inicializador Corvus também são anunciadas.Gerenciar servidor
/release upcoming <enabled>Liga ou desliga as prévias e mostra o que vem a seguir.Qualquer pessoa
/release testPublica um aviso de exemplo para conferir o canal e as permissões.Gerenciar servidor

/request

Pedir um recurso ou uma mudança e acompanhar o que acontece.

ComandoO que fazQuem pode usar
/request newAbre um formulário curto: o que você gostaria e por que ajudaria.Qualquer pessoa
/request list <status>Mostra os pedidos deste servidor, os abertos primeiro. Só você vê a resposta.Qualquer pessoa
/request close <number> <resolution>Marca um pedido como resolvido e registra o que foi decidido.Gerenciar servidor
/request reopen <number>Devolve à lista um pedido fechado.Gerenciar servidor

Três relatos do mesmo tipo a cada dez minutos, por pessoa e por servidor. Relatar problemas nunca impede você de fazer pedidos.

Treze idiomas

O idioma é escolhido por servidor, não por pessoa: os avisos vão para um canal compartilhado e todos ali devem ler a mesma coisa. Formulários, respostas e mensagens de erro seguem a mesma escolha.

Os nomes dos comandos continuam em inglês, porque o Discord os tira das configurações do cliente de cada leitor, não do servidor.

O que é guardado

Um relato guarda o que você escreveu no formulário, seu identificador do Discord e nome exibido, e onde foi publicado. Só isso. O bot não guarda histórico de mensagens, não lê canais para os quais não foi apontado e não tem nada a ver com sua conta do Minecraft.
