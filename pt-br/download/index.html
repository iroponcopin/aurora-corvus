Download

Baixe o ZIP do pacote de MODs Alpha (os 12 MODs) direto desta página. O ZIP contém os 12 jar dos MODs, o arquivo de dados do MOD de Sapporo, os manuais de instalação, o README e o pacote de recursos.

Versão 3.8.0 2026-09-01

Alpha_MODs_v3.8.0+mc26.2.zip

Tamanho do arquivo 44.7 MB (46,821,809 bytes)
SHA-256 737ceba643715c5e624c1adb39d565398f6fcb59603397d793b647eeacbf2802

Baixar

Para administradores de servidor: extraia os arquivos jar do ZIP direto na sua pasta mods. Só o MOD de Sapporo precisa, além disso, que você copie o arquivo sapporo_mode_a.spro que vem junto para a pasta config/sorakaze_sapporo/data/ do servidor (veja também “Como instalar” abaixo).

O MOD de Sapporo (sorakaze-sapporo) foi distribuído pela primeira vez na V2.2.0. É um mundo de geração urbana baseado no terreno e nos prédios reais de Sapporo, no Japão (a altura dos prédios é, por ora, uma estimativa, à espera dos dados 3D reais; será atualizada assim que eles estiverem disponíveis).

O que mudou na V3.8.0

Adiciona a perfuratriz pesada: uma máquina de esteiras que você pilota, assenta e usa para perfurar. Ela abre uma face de 5x5 em uma passada e atravessa obsidiana — em troca é muito lenta e não pode se mover enquanto perfura. A mesma versão permite que itens pesados, projéteis e armas de longo alcance danifiquem blocos, com potência diferente para cada arma: uma pistola mal marca a pedra, um foguete abre um buraco nela. Aureum (mod leve de otimização, download separado)

Aureum é um mod independente, separado do pack Alpha. Ele otimiza a lógica do jogo, a memória e o custo de tick do servidor, e deliberadamente nunca toca no pipeline de renderização de chunks. Não substitui o Sodium — ele otimiza o lado que o Sodium não toca, então é seguro usar os dois juntos. Se quiser mais FPS, instale o Sodium separadamente.

Versão 1.0.0

aureum-1.0.0.jar

Tamanho do arquivo 35.4 KB (36,216 bytes)
SHA-256 9085efc7670357fe15c408a4f75e52f3bf0ff1cc0a847beef894ab98c2dfa18a

Baixar Aureum

Medido até agora: -6,3 MB com 2.209 chunks carregados, -17,2 MB após gerar uma área nova de tamanho semelhante (reproduzido em duas execuções independentes). O MSPT (tempo de tick) não muda dentro da margem de ruído da medição. Dois ajustes do lado do cliente (limite de partículas, distância de renderização de bloco-entidade) vêm desativados por padrão e não medidos, pois este ambiente de desenvolvimento não tem cliente. Veja o README no GitHub para instalação e configuração.
