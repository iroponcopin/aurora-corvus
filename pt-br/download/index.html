Download

Baixe o ZIP do pacote de MODs Alpha (os 11 MODs) direto desta página. O ZIP contém os 11 jar dos MODs, o arquivo de dados do MOD de Sapporo, os manuais de instalação, o README e o pacote de recursos.

SHA-256 5514ad49630cbaebf3dafaf399c1aeefa36568e301bb4dad672c1f12e52172f3

Baixar

Para administradores de servidor: extraia os arquivos jar do ZIP direto na sua pasta mods. Só o MOD de Sapporo precisa, além disso, que você copie o arquivo sapporo_mode_a.spro que vem junto para a pasta config/sorakaze_sapporo/data/ do servidor (veja também “Como instalar” abaixo).

O MOD de Sapporo (sorakaze-sapporo) foi distribuído pela primeira vez na V2.2.0. É um mundo de geração urbana baseado no terreno e nos prédios reais de Sapporo, no Japão (a altura dos prédios é, por ora, uma estimativa, à espera dos dados 3D reais; será atualizada assim que eles estiverem disponíveis).

O que mudou na V3.2.0

O sistema do computador e do telefone passa de Mine OS para Corvus OS, e a tela bancária de Mine Bank para Corvus Bank — o mesmo nome que o aplicativo de desktop e este site já usam. O sistema foi reestilizado para lembrar Linux, com registro de inicialização, uma paleta mais sóbria e uma marca de corvídeo. A tela do computador não deixa mais ver o mundo através dela: agora é opaca, como uma tela de verdade. O caixa eletrônico foi refeito para que suas aberturas e o teclado sejam formas reais, e não desenhos sobre uma caixa. Ver o histórico de atualizações →

Como instalar

Os passos completos de instalação, tanto do servidor quanto dos jogadores, estão no guia de instalação: Ver o guia de instalação →

Esta página distribui sempre a versão atual (V3.2.0). Se você precisar de uma versão anterior, peça diretamente ao administrador do seu servidor.

Corvus

O Corvus é um aplicativo de desktop que mantém o seu pacote de MODs Alpha atualizado automaticamente, conferindo cada download com este Wiki por SHA-256 — o Wiki continua sendo a única fonte em que ele confia.
