Visão geral: sobre a instalação do Glimpse Alpha

Glimpse Alpha (antigo nome: Sorakaze) é o conjunto de MODs Fabric usado no Servidor Sorakazekarasu. Ele é formado por 8 MODs independentes, que podem ser instalados e atualizados separadamente. Elementos da vanilla (o Minecraft padrão, sem MODs), como arco e flecha ou vagonete, não são substituídos nem removidos — os MODs só adicionam novos itens, blocos e dimensões.

MODConteúdo
Armas de fogoArmas de longo alcance que não existem na vanilla (fuzil de assalto, espingarda, sniper etc.)
FerroviaUm trem que acelera aos poucos, além de vagões de passageiros e de carga que podem ser acoplados
Materiais de construção e decoraçãoMateriais de construção para montar cidades, como semáforos e guard-rails, além de eletrodomésticos como câmera de segurança, caixa eletrônico e elevador
VeículosCarros, ônibus, aeronaves e mais
ChefesAlvos poderosos para caçar e equipamentos exclusivos de drop
CéuA nova dimensão “Céu” e a cidade/reino dos anjos que mora nela
SobrevivênciaNovos minérios, armaduras e elementos do dia a dia, como temperatura e estações do ano
EnergiaRede de geração e transmissão de energia, além de aparelhos elétricos

Para ver os itens e as receitas detalhadas de cada MOD, acesse a página de receitas; para o histórico de mudanças, veja o histórico de atualizações.

Para usar os MODs, você precisa do “Fabric”

O Fabric é a base que permite ao Minecraft carregar MODs. É como o sistema que um console precisa ter antes de rodar qualquer jogo: antes de instalar os MODs em si, é preciso instalar o Fabric tanto no servidor quanto no PC de cada jogador.

⚠ O ponto onde mais gente erra

Os MODs precisam ser instalados não só no servidor, mas também no PC de todo mundo que for jogar. Não existe isso de “instalar no servidor e valer automaticamente para todo mundo”. Se a versão do Minecraft, do Fabric ou dos MODs não estiver exatamente igual entre o servidor e todos os jogadores, ninguém consegue entrar.

Quem precisa preparar o quê

  • Servidor (Servidor Sorakazekarasu) — o Fabric Server + Fabric API + os 8 MODs do Glimpse Alpha
  • O PC de cada pessoa que for jogar — Fabric Client + Fabric API + os 8 MODs do Glimpse Alpha (exatamente a mesma combinação do servidor)
Este site não distribui os MODs

Este site só publica material de leitura — tabelas de receitas, histórico de atualizações e guias de instalação — e não distribui os arquivos (jars) dos MODs em si. Peça o conjunto de jars necessário diretamente à administração do servidor.

Como esta página está organizada

Este guia é dividido em duas partes. A maioria das pessoas só precisa ler o capítulo para jogadores para conseguir entrar no servidor. Se você for administrar ou operar o próprio servidor, leia também o capítulo para administradores do servidor.

Para jogadores

Para jogadores: configuração para entrar no servidor

Aqui explicamos a configuração para quem vai entrar no servidor como jogador. Não é preciso nenhum conhecimento técnico difícil. Seguindo os passos na ordem, leva de 15 a 20 minutos, mais ou menos.

Só tem 3 coisas para fazer
  • ① Instalar o Fabric (a base que carrega os MODs) no seu PC
  • ② Colocar o conjunto de arquivos de MOD recebido da administração do servidor na pasta certa
  • ③ Mudar só 1 detalhe na forma de abrir o jogo e entrar no servidor

O que você precisa ter

  • Um PC Windows ou Mac que rode o Minecraft Java Edition
  • O conjunto de MODs (9 arquivos jar = 1 Fabric API + os 8 MODs do Glimpse Alpha) recebido da administração do servidor
🛑 Muito importante

Você só consegue entrar se tiver exatamente a mesma versão e exatamente os mesmos arquivos de MOD que o servidor. Esta página usa como exemplo a versão 26.2 do Minecraft, mas, se a administração do servidor informar um número diferente, use esse número no lugar. Não dê duplo clique nos arquivos jar recebidos para abri-los. Basta colocá-los na pasta.

① Instalar o Fabric

Abra https://fabricmc.net/use/installer/ e baixe o instalador. Deixe a aba em “Client” (não mude para “Server”), escolha em Minecraft Version o mesmo número usado pelo servidor e clique em “Install”.

No Windows

  1. Baixe o instalador clicando em um botão como “Download installer (Windows/.exe)” e dê duplo clique para executar (se aparecer “O Windows protegeu seu PC”, clique em “Mais informações” → “Executar assim mesmo”).
  2. Com a aba “Client” selecionada, escolha 26.2 (o mesmo número do servidor) em Minecraft Version, deixe Loader Version como está e clique em “Install”.

No Mac

  1. Clique no botão “Download universal jar” para baixar o instalador (.jar). Não existe versão executável (.exe) para Mac.
  2. No arquivo baixado fabric-installer-〜.jar, em vez de dar duplo clique, clique com o botão direito (ou clique segurando a tecla control) e escolha “Abrir”. Se aparecer um aviso, clique em “Abrir” de novo.
  3. Com a aba “Client” selecionada, escolha em Minecraft Version o mesmo número do servidor e clique em “Install”.
⚠ Se aparecer “Não é possível verificar o desenvolvedor” no Mac

Em versões recentes do macOS, mesmo clicando com o botão direito → “Abrir”, às vezes não aparece nenhum botão — só um aviso do tipo “Não foi possível verificar se ‘fabric-installer〜.jar’ contém malware”. Nesse caso, siga esta ordem para abrir o arquivo.

  1. No aviso, clique em “Concluído” (nunca clique em “Mover para o Lixo”)
  2. Abra o menu Apple no canto superior esquerdo da tela → “Ajustes do Sistema” → “Privacidade e Segurança”
  3. Mais abaixo vai aparecer algo como “O uso de ‘fabric-installer〜.jar’ foi bloqueado”; clique em “Abrir mesmo assim” ao lado
  4. Se perguntar de novo, clique em “Abrir mesmo assim” → digite a senha do Mac (ou use o Touch ID)

Esse é o aviso padrão que aparece em qualquer arquivo não registrado junto à Apple. Se você baixou o instalador direto do site oficial do Fabric, não há motivo para preocupação. Depois de autorizar uma vez, os próximos acessos abrem normalmente.

💡 Se nada acontecer ao abrir o instalador no Mac

Se, mesmo clicando com o botão direito → “Abrir”, nada acontecer, é porque o sistema não tem o Java instalado. Acesse adoptium.net, baixe o instalador do “Temurin” para macOS (.pkg) e tente de novo depois de instalá-lo. Em Macs com chip Apple (M1/M2/M3/M4 etc.), escolha “aarch64”; em Macs Intel, escolha “x64”. Se não souber qual é o seu caso, veja o campo “Chip” em menu Apple → “Sobre este Mac” no canto superior esquerdo da tela (se aparecer “Apple M〜”, é aarch64).

② Colocar os arquivos de MOD na pasta mods

Windows: %appdata%\.minecraft\mods

  1. Na barra de endereço do Explorador de Arquivos, digite %appdata%\.minecraft e aperte Enter.
  2. Se não existir uma pasta mods, crie uma nova (tudo em letra minúscula).
  3. Copie os 9 arquivos jar recebidos para dentro dessa pasta mods (não é preciso extrair nada, coloque os jars como estão).

Mac: ~/Library/Application Support/minecraft/mods

  1. Clique 1 vez na área de trabalho e, em seguida, pressione ⌘ command+⇧ shift+G ao mesmo tempo (ou use o menu superior “Ir” → “Ir para a Pasta…”).
  2. No campo que aparecer, cole exatamente ~/Library/Application Support/minecraft e aperte Enter (não esqueça o “~” no início). Como “Library” é uma pasta que o Finder normalmente esconde, esse é o jeito mais seguro de chegar até ela.
  3. Se não existir uma pasta mods, clique com o botão direito ali mesmo e escolha “Nova Pasta” para criá-la.
  4. Arraste e solte os 9 arquivos jar recebidos para dentro dessa pasta mods.

③ Abrir com o Fabric e entrar no servidor

  1. Abra o launcher do Minecraft e, na lista de perfis de inicialização perto do botão “Jogar”, escolha um com nome parecido com fabric-loader-26.2 (se deixar em “Última versão lançada”, o jogo abre sem os MODs).
  2. Clique em “Jogar” normalmente para abrir o jogo. Se der certo, vai aparecer um botão extra “Mods” na tela de título. Clicando nele, você consegue ver os 8 MODs do Glimpse Alpha e o Fabric API.
  3. Depois, é só entrar no servidor pelo “Multijogador”, como sempre.

Quando os MODs forem atualizados

Quando os MODs do servidor forem atualizados, todo mundo precisa atualizar para a mesma versão ao mesmo tempo.

  1. Receba os novos arquivos de MOD da administração do servidor (espere o aviso antes de fazer qualquer coisa).
  2. Abra a pasta mods e apague os arquivos jar antigos do Glimpse Alpha antes de colocar os novos (mesmo que o nome do arquivo mude, ele continua sendo tratado como o mesmo MOD — se sobrar um arquivo antigo, o jogo não abre).
  3. Abra o jogo com o perfil fabric-loader de sempre.
⚠ Atenção

Se só um dos lados (você ou o servidor) estiver com a versão nova, você não consegue entrar. Se tiver problemas, veja também as perguntas frequentes.

Para administradores do servidor

Para administradores do servidor: preparação (backup e confirmação de versão)

A partir daqui, o conteúdo é para quem opera e administra o próprio servidor. Vamos explicar como adicionar o Fabric e os 8 MODs do Glimpse Alpha a um servidor de Minecraft já em funcionamento (vanilla, ou seja, o servidor padrão sem MODs). Este capítulo usa como exemplo um servidor Windows. Se você administra em Mac / Linux, adapte os caminhos das pastas e a forma de rodar os comandos para o seu ambiente e siga um passo a passo parecido (o guia oficial do site do Fabric).

🛑 Antes de qualquer coisa

Para não perder o mundo caso algo dê errado na instalação dos MODs, sempre faça um backup antes de começar.

1. Faça o backup do mundo

Abra a pasta do servidor (exemplo: C:\MinecraftServer) e rode o processo de backup que você já usa normalmente (exemplo: um script de backup como Backup-Server.bat). Se não tiver um script específico, basta parar o servidor e copiar a pasta world inteira para outro lugar.

2. Confira a versão do Java

  1. Abra o Prompt de Comando (ou qualquer terminal).
  2. Digite java -version e aperte Enter.
  3. Confira se o número mostrado é 25 (exemplo: java version "25.0.3").
🛑 Muito importante

Para rodar o Minecraft 26.2, é preciso Java 25. Algumas instruções antigas de configuração mencionam “Java 21”, mas essa informação está desatualizada — com o Java 21, o servidor não inicia. Se o número for menor que 25, acesse adoptium.net, baixe e instale o “Temurin 25 (LTS)”, reinicie o computador e confira de novo.

3. Confira a versão do Minecraft do servidor

  1. Inicie o servidor como você sempre faz (exemplo: Start-Server.bat).
  2. No começo do console (a tela preta), procure uma linha parecida com Starting minecraft server version X.Y e anote esse número.
  3. Digite stop no console e aperte Enter para parar o servidor com segurança.
⚠ Atenção

Este guia usa “26.2” como exemplo, mas, se o número que você conferiu de verdade for diferente, use esse número em todos os passos seguintes (ao escolher as versões do Fabric, do Fabric API e dos MODs). Se a versão do servidor, dos jogadores e dos MODs não estiver alinhada em todos os pontos, nada funciona.

Para administradores do servidor

Para administradores do servidor: instalação do Fabric

Instalar o Fabric Server

  1. No navegador, abra https://fabricmc.net/use/server/ e baixe o instalador clicando em um botão como “Download installer (Windows/.exe)”.
  2. Dê duplo clique no arquivo baixado fabric-installer〜.exe para abri-lo (se aparecer “O Windows protegeu seu PC”, clique em “Mais informações” → “Executar assim mesmo”).
  3. Na tela de configuração do instalador, confira estes 4 pontos.
    • Deixe a aba em “Server”
    • Em Minecraft Version, escolha a mesma versão do servidor que você conferiu na preparação anterior (exemplo: 26.2)
    • Loader Version pode ficar como está
    • Em Install Location, aponte para a pasta do servidor já existente (exemplo: C:\MinecraftServer)
  4. Clique em “Install”.
  5. Se der certo, vai aparecer um novo arquivo fabric-server-launch.jar dentro da pasta do servidor.

Criar um novo arquivo de inicialização (batch)

O arquivo de inicialização que você já usa (exemplo: Start-Server.bat) inicia o servidor “sem MODs”. Não apague esse arquivo (assim você pode voltar para a versão sem MODs se precisar). Em vez disso, vamos criar um novo arquivo de inicialização para o Fabric.

  1. Abra o Bloco de Notas (Notepad).
  2. Copie e cole exatamente o conteúdo abaixo. 
    @echo off
cd /d "%~dp0"
title Minecraft Fabric Server
java -Xms2G -Xmx4G -jar fabric-server-launch.jar nogui
echo O servidor foi encerrado.
pause
  3. Em “Arquivo” → “Salvar como”, salve na pasta do servidor (exemplo: C:\MinecraftServer), com o nome de arquivo Start-Fabric-Server.bat e o tipo de arquivo definido como “Todos os arquivos”.
⚠ Atenção

Se você não escolher “Todos os arquivos” no tipo de arquivo, vai acabar criando um arquivo que não funciona, chamado Start-Fabric-Server.bat.txt. Além disso, se a memória (RAM) reservada quando o servidor foi montado for diferente de 4GB, troque o “4” de -Xmx4G pelo número correto.

Para administradores do servidor

Para administradores do servidor: instalação dos MODs e verificação de inicialização

O MOD em si é um arquivo único chamado “jar”. Para instalar, basta colocá-lo na pasta mods da pasta do servidor.

1. Prepare a pasta mods

Verifique se já existe uma pasta chamada mods dentro da pasta do servidor (exemplo: C:\MinecraftServer). Se não existir, clique com o botão direito → “Novo” → “Pasta” e crie uma pasta chamada mods (tudo em letra minúscula).

2. Baixe o Fabric API

Abra https://modrinth.com/mod/fabric-api/versions e baixe o primeiro item da lista em que “Game version” (a versão do jogo) seja igual à do servidor (exemplo: fabric-api-0.154.2+26.2.jar).

3. Coloque o conjunto de MODs na pasta mods

Copie os 9 arquivos jar no total — 1 Fabric API + os 8 MODs do Glimpse Alpha — para dentro da pasta mods (não é preciso extrair nada, coloque os jars como estão). Continue obtendo esses 8 MODs pelo mesmo canal de distribuição de sempre. Este site não distribui os arquivos dos MODs em si.

MODExemplo de nome de arquivo

Ferroviaglimpse-alpha-rail-…+mc26.2.jar
Materiais de construção e decoraçãoglimpse-alpha-deco-…+mc26.2.jar

Chefesglimpse-alpha-boss-…+mc26.2.jar

⚠ Atenção

Não dê duplo clique nos arquivos jar (não é preciso abri-los). Basta colocá-los na pasta.

4. Inicie o servidor e confira se deu certo

  1. Dê duplo clique no Start-Fabric-Server.bat que você criou (não use mais o antigo Start-Server.bat).
  2. No console (a tela preta), confira estes 2 pontos.
    • Na linha em que os MODs são carregados, aparece o nome dos MODs que você instalou
    • No final, aparece Done (…s)! For help, type "help", e o servidor continua rodando sem travar
💡 Se aparecer um erro de Java e o servidor não abrir

Se aparecer um erro em inglês do tipo “class file version” ou “requires Java”, é provável que o Java esteja desatualizado. Instale a versão para Windows (.msi) do “Temurin 25 (LTS)” em adoptium.net, reinicie o computador e tente de novo.

Depois de confirmar que o servidor abre normalmente, avise todos os jogadores para seguirem o capítulo para jogadores e instalarem o mesmo conjunto de Fabric + MODs em seus próprios PCs.

Para administradores do servidor

Ao trocar os MODs para uma nova versão

Como os 8 MODs do Glimpse Alpha são totalmente independentes entre si, nem toda atualização substitui os 8 de uma vez. Basta trocar só os MODs que realmente mudaram (dá para saber quais MODs mudaram pelo aviso da distribuição ou pelo histórico de atualizações).

Como atualizar

  1. Digite stop no console do servidor para pará-lo.
  2. Faça o backup do mundo pelo processo de sempre.
  3. Na pasta mods do servidor, apague o arquivo jar antigo do MOD que vai ser atualizado e coloque o novo arquivo jar no lugar (se sobrar a versão antiga e a nova do mesmo MOD ao mesmo tempo, o servidor não abre).
  4. Inicie o servidor com o Start-Fabric-Server.bat e confira se a versão atualizada aparece no console.
  5. Distribua os novos arquivos jar para todos os jogadores também, para que eles façam a mesma troca (veja o capítulo para jogadores). Se só o servidor ou só os jogadores estiverem na versão nova, ninguém consegue entrar.
🛑 Muito importante

Se você abrir o servidor com um MOD completamente removido (em vez de atualizado), os blocos colocados e os itens obtidos com aquele MOD (como os semáforos) desaparecem. Isso é uma característica do Minecraft e do Fabric em geral, e não tem como desfazer. Sempre faça backup antes de remover um MOD.

Sobre os arquivos de configuração (o sistema de reparo automático)

Cada MOD gera automaticamente um arquivo de configuração (exemplo: sorakaze_guns.json) dentro da pasta config/ ao iniciar. Valores como poder de fogo e velocidade podem ser ajustados ali, e, em geral, não é mais preciso apagar ou reescrever esses arquivos manualmente a cada atualização.

💡 Como funciona atualmente

Quando o valor padrão de um item muda em uma nova versão, a atualização automática só acontece nos itens que ainda estão com o valor padrão antigo (ou seja, que você nunca ajustou). Valores que você ajustou manualmente não são alterados. Novos itens de configuração também são adicionados automaticamente ao iniciar o servidor. Tudo o que for atualizado fica registrado em logs/latest.log, no formato “valor antigo → valor novo”.

⚠ Cuidado ao editar o arquivo de configuração

Se você apagar manualmente só uma parte de um valor dentro do arquivo de configuração (por exemplo, apagar só a linha de dano de dentro do bloco de configuração de uma arma), esse item pode acabar sendo silenciosamente substituído por outro valor inicial interno do MOD (sem mostrar nenhum erro). Se quiser ajustar um número específico, edite diretamente o valor daquele item. Se quiser voltar tudo ao estado inicial, apague o arquivo de configuração inteiro do MOD em questão — ele será recriado com os valores padrão na próxima vez que o servidor iniciar.

Pontos de atenção para saber antes de jogar

O Glimpse Alpha também traz algumas mudanças que afetam o comportamento da vanilla. Aqui reunimos os pontos mais fáceis de passar despercebidos. Como os números exatos podem ser ajustados a cada atualização, confira sempre as informações mais recentes no histórico de atualizações e nos bugs conhecidos. Os ajustes de configuração são feitos pela administração do servidor.

A redstone agora precisa de “eletricidade”

Com a instalação do MOD de Energia, parte da redstone da vanilla deixa de funcionar sozinha.

  • Passam a precisar de eletricidade: pó de redstone, repetidor, comparador, bloco de redstone e tocha de redstone. Eles só emitem sinal depois de ligados por cabo à rede elétrica. Fazendas automáticas, estações, portas automáticas e filas de funil ficam paradas até você fazer a fiação.
  • Continuam funcionando sem eletricidade, como sempre: alavanca, botão, placa de pressão, gancho de fio de gatilho, observador, sensor de luz do dia, sensor de sculk, alvo, baú-armadilha, trilho detector, estante de livros, jukebox, para-raios, entre outros. Abrir portas e portões manualmente também continua funcionando normalmente.
  • Cerca de 10 minutos depois de colocado, o Bloco de Redstone se quebra sozinho (e volta para o inventário como item).
💡 Como desfazer (para a administração do servidor)

Definindo powerEnabled como false no arquivo config/sorakaze_power.json, dá para desativar por completo a eletrificação da redstone.

Alguns equipamentos de materiais de construção/decoração também precisam de eletricidade

Câmera de segurança, elevador, escada rolante, porta automática e caixa eletrônico — esses 5 itens só funcionam com um cabo levando eletricidade até eles (o elevador continua funcionando “para descer” mesmo sem eletricidade). Definindo o item correspondente como false em config/sorakaze_deco.json, dá para liberar cada equipamento individualmente da exigência de eletricidade.

Geradores esquentam o ambiente

Um gerador ou uma usina nuclear em funcionamento aumenta a temperatura do espaço ao redor. Só o ar-condicionado consegue resfriar. Isolar a sala de máquinas com paredes e uma porta fechada é a forma mais simples de evitar que o calor se espalhe para outros cômodos. Essa função em si pode ser desativada definindo temperatureMachineHeatEnabled como false em config/sorakaze_survival.json.

A altura do mundo do Céu foi ampliada

Com a instalação do MOD Céu, o limite de altura para construir no Mundo Normal (a dimensão principal) foi ampliado. Só o limite superior mudou — a profundidade do subsolo (o fundo do mundo) e o terreno já existente continuam do mesmo jeito.

O lança-foguetes destrói o terreno

Por padrão, o lança-foguetes do MOD de armas de fogo destrói o terreno no ponto de impacto. Isso continua acontecendo mesmo com a regra de jogo mobGriefing da vanilla definida como false. Para impedir a destruição, é preciso definir rocketDestroysTerrain como false em config/sorakaze_guns.json. Tenha cuidado especial perto da sua base.

Sobre o poder de fogo das armas

As armas do MOD de armas de fogo, principalmente o fuzil de assalto, têm um poder de fogo muito alto, e a maioria dos chefes adicionados pelos MODs cai em poucos segundos. Se quiser mais desafio, a administração do servidor pode ajustar a dificuldade alterando o valor de dano de cada arma em config/sorakaze_guns.json.

Remover um MOD apaga os blocos e itens dele

Isso é uma característica dos MODs em geral, não um bug específico do Glimpse Alpha. Blocos colocados e itens obtidos enquanto um MOD estava instalado desaparecem do mundo quando esse MOD é removido. A única forma de recuperar é restaurar a partir de um backup.

Perguntas frequentes e solução de problemas

Perguntas frequentes

PerguntaResposta
O mundo não vai ser apagado?Não. Instalar o Fabric não apaga o mundo que você já tem — ele continua funcionando normalmente. Se estiver preocupado, faça um backup antes de instalar.
Um amigo sem os MODs consegue entrar?Não. Todos os jogadores precisam seguir a configuração do capítulo para jogadores.
Quero voltar para a vanilla (sem MODs)No servidor, basta iniciar com o arquivo de inicialização sem MODs que você já usava antes (os blocos e itens adicionados pelos MODs desaparecem).
Depois de atualizar um MOD, não consigo mais jogarConfira se a versão do MOD está igual no servidor e no jogador. Se só um dos lados estiver na versão nova, ninguém consegue entrar.
Não consigo ler a mensagem de erro em inglêsNão tem problema não conseguir ler. Basta enviar o arquivo latest.log, que fica dentro da pasta logs, direto para a administração do servidor.

Se o servidor não iniciar

  1. Mova temporariamente todo o conteúdo da pasta mods para outro lugar.
  2. Coloque os arquivos de volta um por um, testando a inicialização a cada vez, até descobrir qual arquivo é o causador.
  3. Se aparecer um erro relacionado ao Java, confira a versão do Java seguindo o capítulo de preparação.

Se você consegue entrar no servidor, mas não consegue se conectar

  1. Confira se a versão e o conjunto de MODs de todos os jogadores são exatamente iguais aos do servidor.
  2. Diferenças na versão do Fabric API costumam ser a causa mais comum — confira essa primeiro.
💡 Se mesmo assim não resolver

Envie o logs/latest.log para a administração do servidor e converse com ela. Não precisa se apressar — se você tiver um backup, sempre dá para voltar ao estado anterior.

Como restaurar o mundo a partir de um backup (para a administração do servidor)

  1. Digite stop no console do servidor para pará-lo.
  2. Pegue o backup mais recente no local onde eles são salvos (exemplo: C:\MinecraftServer\backups) (se estiver em zip, clique com o botão direito → “Extrair Tudo”).
  3. Troque a pasta world da pasta do servidor pela pasta world extraída do backup (sobrescrevendo a atual).
  4. Inicie o servidor.
