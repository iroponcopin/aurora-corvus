Corvus

O Corvus é um pequeno aplicativo de desktop que mantém o pacote de MODs Alpha sempre atualizado automaticamente. Ele consulta este Wiki para saber qual é a versão mais recente, baixa o que mudou e, antes de mexer na pasta do pacote, confere todos os arquivos baixados com a soma de verificação SHA-256 publicada neste Wiki. A única fonte em que ele confia é este Wiki.

O que é o Corvus e por que ele foi feito

Manter um pacote de MODs grande atualizado na mão exige visitar a página de download, comparar os números de versão, baixar o novo ZIP e extraí-lo de novo na pasta certa a cada lançamento. O Corvus automatiza isso — ele lê as informações de lançamento deste Wiki, compara com o pacote que você já tem instalado e busca apenas o que mudou.

Todo arquivo que o launcher baixa é conferido, antes de ser usado, com a soma de verificação SHA-256 publicada neste Wiki. Se não bater, o arquivo não é instalado. Sobre “qual é a versão mais recente”, a única fonte em que o launcher confia é este Wiki.

Como instalar o Corvus

O Corvus é distribuído em duas formas na página de download deste Wiki, no mesmo lugar em que fica o ZIP do pacote de MODs.

  • Instaladores nativos para cada sistema operacional (.msi para Windows, .dmg para macOS, .deb para Linux) — a instalação segue os mesmos passos de um aplicativo de desktop comum e não precisa de Java. Como ainda não fizemos a assinatura de código, o sistema operacional mostra um aviso na primeira execução. No macOS, em vez de dar dois cliques, clique com o botão direito no aplicativo e escolha “Abrir”. No Windows, no aviso do SmartScreen, escolha “Mais informações” → “Executar assim mesmo”.
  • O jar multiplataforma corvus-1.8.0.jar — o mesmo arquivo funciona tanto no Windows quanto no macOS e no Linux, mas exige o Java 21 ou mais recente já instalado. Se ele não abrir com dois cliques, abra o Terminal (ou o Prompt de Comando) na pasta em que você baixou o arquivo e execute java -jar corvus-1.8.0.jar.

Apontar para uma pasta de pacote de MODs já existente

Mesmo que você já tenha instalado o pacote de MODs Alpha na mão, não precisa começar do zero. Na primeira execução, em vez de criar uma pasta nova, dá para escolher a pasta em que o seu pacote de MODs já está. Se você apontar para a sua pasta mods já existente, daí em diante o launcher passa a tratar essa instalação como a que ele gerencia.

A diferença entre o modo de atualização automática e o manual

No modo de atualização automática, o launcher confere por conta própria as informações de lançamento deste Wiki e instala as versões novas assim que elas são publicadas. Sem que você faça nada, a pasta do pacote fica sempre atualizada.

No modo de atualização manual, o launcher confere se há atualização, mas espera a sua confirmação antes de baixar ou instalar qualquer coisa. É útil quando você quer escolher o momento da atualização, por exemplo para evitar que ela interrompa uma partida.

Como conferir se a atualização foi mesmo aplicada

A partir da versão 1.1.0, ao apertar Update os novos arquivos de MOD são gravados diretamente na pasta mods do pacote. A mensagem “Update complete” só aparece depois que o conteúdo da pasta é de fato conferido de novo, após a atualização, e se confirma que os arquivos esperados estão mesmo lá. Se algo falhar no meio do caminho, ele reporta a falha em vez de exibir um sucesso falso.

Como conferir de verdade no macOS: abra a pasta mostrada na tela de configurações (no Finder, aperte ⌘+⇧+G e cole o caminho), olhe dentro de mods e confira o número de versão dentro do nome de cada arquivo alpha-*.jar antes e depois do Update.

Se a atualização partir de uma pasta de pacote que foi mexida pela última vez por um launcher anterior à 1.1.0, só na primeira vez pode acontecer de o jar de versão antiga daquele MOD ficar ao lado do jar novo (porque os launchers anteriores não guardavam um registro de quais arquivos eles próprios tinham colocado). Isso se resolve sozinho a partir da atualização seguinte. Se você quiser resolver na hora, não há problema em apagar manualmente o alpha-*.jar de versão antiga, depois de confirmar que o novo está lá.

Restaurar a partir de um backup quando a atualização dá errado

Para o caso de a atualização deixar o pacote em um estado indesejado, como um MOD com defeito, ou de você querer desfazer a atualização, o launcher guarda como backup o estado do pacote de antes da atualização. Em vez de tentar consertar os arquivos na mão, use a função de restauração do launcher para voltar a pasta do pacote ao estado do backup.
