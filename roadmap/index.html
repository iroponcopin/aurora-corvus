このページは、すでに出荷されたものと、これから作るものを分けて並べたページです。以前ここに「予定」として並んでいた項目のほとんどは、すでに配布中のパックに入っています。まず出荷済みのぶんをまとめ、そのあとに、これから作るものを書いています。

緑の「出荷済み」と書かれたカードの内容は、いま配布しているパックに実際に入っています。青いカードの内容は、まだあなたのゲームには入っていません。時期・内容・仕様は、変更されることも取りやめになることもあります。実際に出荷されたものだけが「更新履歴」のページに載ります。

出荷済み V2.2.0 〜 V2.5.1

以前このページで「予定」としていたもの — そのほとんどは、すでに出荷されています

このページ自体が古くなっていました

  • このページは長いあいだ、V2.2 をこれから着手する次回のリリースとして案内したままでした。事実と違います。V2.2.0(2026-08-23)から V2.5.1(2026-08-28)までがすでに配布済みで、いま配っているパックは V2.5.1 です。
  • 札幌MOD(sorakaze_sapporo)はまだ同梱されておらず V2.2 へ持ち越し、とも書いていました。これも事実と違います。札幌MODは V2.2.0 で11個目のMODとして出荷され、現在配布中のZIPにも入っています。導入する jar は Fabric API 1 個 + Alpha の 11 個です。
  • なお V2.3 という番号のリリースはありません。V2.2.1 のつぎは V2.4.0 です。番号が飛んでいるだけで、抜けている更新はありません。

まだ計画中のものとして書いていたのに、すでに動いていたもの

  • 天候と災害(吹雪・台風・地震・津波・火山)は5種類とも実装済みで、いずれも既定で有効です。地震は既定の設定のままでも、石・丸石・砂岩・土・砂・砂利・粘土といったごくふつうの建材を壊すことがあります。
  • 物価を10倍〜100倍に引き上げる仕組みは、天空MODと二相楽園MODで既定で有効です(バニラの村人取引は対象外)。
  • ATMのダイヤモンド残高は既定で有効です。ただし、このページが「実測をもとに決めたうえで公表する」と書いていた点は、すでに決まっています。レートは1ダイヤ=4エメラルドの固定で、設定では変えられません。ダイヤ残高に利息は一切つきません。
  • 利息の上限を1,000万エメラルドへ引き上げる件も、すでに反映済みです。正確には「利息がつく残高の上限」で、特別口座だけは5,000万エメラルドです。
  • のどの渇きが0のまま10分続くとダメージが増えていき、ピースフル以外では実際に死ぬことがある仕様、電車を除く車両のガソリン、仮面の耐久と一度きりの復活も、すべて既定で動いています。仮面の耐久は当初の「800ほど」ではなく814、復活までは320秒です。
  • 以上の詳しい数値と、それぞれの config キーは「機能紹介」ページの「書かれていなかった仕様」にまとめてあります。この一覧は実際のMODのコードを1件ずつ確認して書き起こしたものです。

V2の計画のうち、出荷されたもの

  • 二相楽園(Planarcadia)への入口とポータルアメジストブロック、新ボス4体(体力600・800・750・1,200)と召喚儀式、水道インフラ(水道管・ポンプ・蛇口)、冷蔵庫と食料の腐敗、ガソリンと携行缶、空気清浄機と原子力発電所の大気汚染、防護服 — V2.0.0(2026-08-18)。
  • 核弾頭が着弾した場所がゲーム内20日間汚染される仕組みも実装済みです。ガスマスクと防護服の両方を着ていれば無効化でき、どちらか欠けるとダメージとデバフを受けます。
  • 水筒の容量は4倍になりました(8回ぶん → 32回ぶん)。
  • 村人・ニワトリなどの小さなモブ・チェストを、壊さずに持ち運べます。中身はそのまま保たれ、ラージチェストは2人がかりです。
  • ペスト医師がウィザーストームを呼ぶまでの20秒の間隔、死神の「魂を狩る死神の鎌」とスポーンエッグ、死神の強さ+15%と攻撃パターン3種の追加、ウィザーストームの第2形態と新しい破壊的な攻撃 — すべて実装済みです。
  • 天使の盾が盾として機能しない不具合は修正済みです。いまは実際に受け流せます。
  • 銃火器の調整(ミニガン・アサルトライフル・ピストル・SMG・ロケットランチャー・タレット)、新規に作り起こした銃声、ロケットランチャーのスコープ使用時に本体が視界を遮る不具合の修正、核弾頭とミサイル弾頭の強化 — すべて出荷済みです。
  • ミサイルランチャーは MK-VII・VLS Mk-V・TEL-X3 の3種類が追加され、いずれもプレイヤーが乗り込んで操縦・照準・発射できます。設置して戦術マップから撃つ据え置き型の発射台も、これとは別に用意されています。
  • 動画アプリの再生・一時停止・早送り/巻き戻しは動きます。サーバー退出後やディメンション移動後に音声が鳴り続ける不具合と、音声は出るのに黒画面のままになる不具合も修正済みです。
  • iPhone と MacBook の見た目は作り直され、インベントリのアイコンと、手に持ったとき・設置したときの見た目が別々に用意されています。
  • バックルームズの怪異の見た目は作り直し済みです。立体モデルとドット絵を組み合わせた作りで、病んだ黄色を基調とした配色と、周囲に漂う粒子の演出がつきます。なお怪異はどんな攻撃でも倒せません。
  • 自動バックアップも実装済みです。サーバー管理者は /glimpsebackup ui から間隔・保存数・保存先を画面で設定でき、ワールドは日時つきのZIPで保存され、古いものは保持数に従って自動的に整理されます(既定では無効・30分ごと・5個保存)。
  • Corvus バンクの画面も出荷済みで、いまはATMを開くと既定でこちらが開きます。預入/引出の切り替え、25%/50%/75%/MAX のクイック選択、1/10/100/1k のステッパー、手数料のプレビュー、確定/取消がそろっています。ただしタブは通貨ではなく口座(個人/共有/特別)の切り替えです。
  • Sparxieの杖(定価200,000エメラルド)、砲台、ガラスランタン52種、地上の襲撃、ドローンとドローンアプリ、札幌の街の再現なども出荷済みです。1回ごとの詳しい中身は「更新履歴」のページを見てください。

いま進んでいるもの

  • V3は探索・防衛・貯蔵・新しい地形などを中心に50の新機能を予定しているメジャーアップデートです。2026年8月29日の V3.0.0 から配信が始まりました。
  • 1回のリリースでまとめて出すのではなく、複数回に分けて少しずつ実装しています。そのため V3 の機能が V2 系のリリースに先に入ることもありました。目玉の「マップ照準式のミサイルランチャー」は V2.4.5 〜 V2.4.9 で、収納ブロック3種・ドローンの刷新・店舗「Meridian Store」は V3.0.0 で出荷済みです。
  • 現時点で出荷済みなのは50機能のうち5件です。残り45件の配信時期は決まっていません。実装が確定したものは、そのつど「更新履歴」のページに載ります。

水の流れそのものの作り直し

  • バニラの水の挙動を置きかえる計画は、まだ実装されていません。平らな場所で水が際限なく横に広がる挙動は、いまも変わっていません。
  • パックには独自の「有限の水」の仕組みがあり、蛇口から出る水と津波の水はこれで動きます。ただしこれはバニラの水とは別のブロックで、バニラの水そのものには一切手を触れていません。バケツで汲める有限の水もありません。
  • つまり水道インフラと津波は動いていますが、「水の仕組みの作り直し」そのものは、まだこれからです。

蓄電池の見た目

  • 端末の見た目の作り直しのうち、iPhone と MacBook は終わっています。蓄電池(電力MOD)には立体モデルはありますが、インベントリ用の平面アイコンはまだ用意されていません。どの画面でも同じ立体モデルが表示されます。

まだ公表していない数字

  • 天候5種類の発生頻度(平均間隔)は「実測した数字で公表する方針」と書いていましたが、その数字はまだこのサイトのどこにも載っていません。設定でそれぞれ個別にオフにできること自体は実装済みです。
  • 公表できているのは、火山の噴火確率(地震1回につき5%)とクレーターの大きさ(半径6・深さ4ブロック)だけで、これは「機能紹介」ページに載せています。
