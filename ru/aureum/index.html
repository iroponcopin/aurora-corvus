Aureum (лёгкий мод оптимизации, отдельная загрузка)

Aureum — отдельный, независимый мод. Он оптимизирует игровую логику, память и нагрузку серверного тика и намеренно никогда не трогает конвейер отрисовки чанков. Он не заменяет Sodium: он оптимизирует ту сторону, которой Sodium не касается, поэтому его безопасно запускать рядом. Если нужен более высокий FPS, установите Sodium отдельно.

Измерено на данный момент: −6,3 МБ при 2209 загруженных чанках, −17,2 МБ после генерации нового ландшафта сопоставимого размера (воспроизведено в двух независимых прогонах). MSPT (время тика) не изменилось в пределах погрешности измерения. Два клиентских переключателя (лимит частиц, дистанция отрисовки блок-сущностей) по умолчанию отключены и не измерены, поскольку в этой среде разработки нет клиента. Установка и настройка — в README на GitHub.

Каждую оптимизацию можно отключить по отдельности

Каждый ключ в config/aureum.json можно отключить независимо от других. Отключение означает, что изменения байткода Aureum для этой функции вообще не применяются — самая надёжная изоляция на случай конфликта с другим модом.

Требования

  • Minecraft 26.3 (Fabric)
  • Fabric Loader 0.19.5+
  • Fabric API
  • Java 25+
