Обзор: об установке Glimpse Alpha

Glimpse Alpha (ранее: Sorakaze) — это группа Fabric-модов, установленных на сервере Sorakazekarasu. Она состоит из 11 независимых модов, каждый из которых можно устанавливать и обновлять по отдельности. Ванильные (стандартные, без модов) элементы вроде лука со стрелами или вагонеток не заменяются и не удаляются — вместо этого добавляются новые предметы, блоки и целые измерения.

Для работы модов нужен «Fabric»

Fabric (Фабрик) — это основа, на которую Minecraft загружает моды. Представьте: прежде чем ставить программы на игровую приставку, нужна сама операционная система приставки. Точно так же перед установкой самих модов Fabric нужно поставить и на сервер, и на компьютер каждого игрока.

⚠ Самая частая ошибка

Моды нужно установить не только на сервер, но и на компьютер каждого, кто будет играть. Не бывает такого, что «поставил на сервер — и всем автоматически подключилось». Если версия Minecraft, Fabric и набор модов на сервере и у всех игроков не совпадают полностью, подключиться к серверу не получится.

Кто что готовит

  • Сервер (Sorakazekarasu) — сам сервер Fabric + Fabric API + 11 модов Glimpse Alpha
  • Компьютер каждого игрока — клиент Fabric + Fabric API + 11 модов Glimpse Alpha (набор должен полностью совпадать с серверным)
Сами файлы модов на этом сайте не распространяются

На этом сайте есть только справочные материалы — таблицы рецептов, история обновлений, инструкция по установке, — но сами файлы модов (jar) здесь не выкладываются. Полный набор jar-файлов, нужных для установки, нужно получить у администратора сервера.

Для игроков: настройка для подключения к серверу

Здесь описана настройка для тех, кто просто хочет играть на сервере. Специальных технических знаний не нужно. Если делать всё по порядку сверху вниз, весь процесс займёт примерно 15–20 минут.

Всего 3 шага
  • ① Установить Fabric (основу для загрузки модов) на свой компьютер
  • ② Положить набор файлов модов, полученный от администратора сервера, в нужную папку
  • ③ Немного изменить способ запуска игры и подключиться к серверу

Что понадобится

  • Компьютер на Windows или Mac, на котором может работать Minecraft Java Edition
  • Набор из 12 файлов модов (1 файл Fabric API + 11 модов Glimpse Alpha), полученный от администратора сервера
🛑 Очень важно

Подключиться к серверу можно только с точно такой же версией и точно такими же файлами модов, как на сервере. На этой странице для примера указана версия Minecraft 26.2, но если администратор сервера сообщил другое число — ориентируйтесь на него. Полученные jar-файлы не открывайте двойным щелчком — их нужно просто положить в папку, этого достаточно.

Какие файлы вы получите (пример)

От администратора сервера вы получите примерно такие 12 файлов (номера версий будут меняться с каждым обновлением).

① Установка Fabric

Откройте https://fabricmc.net/use/installer/ и загрузите установщик. Оставаясь на вкладке «Client» (не переключайтесь на «Server»), выберите в Minecraft Version то же число, что и на сервере, и нажмите «Install».

Для Windows

  1. Скачайте установщик по кнопке вроде «Download installer (Windows/.exe)» и запустите его двойным щелчком (если появится сообщение «Windows защитила ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае»).
  2. Оставаясь на вкладке «Client», выберите в Minecraft Version значение 26.2 (то же, что и на сервере), оставьте Loader Version как есть и нажмите «Install».

Для Mac

  1. Скачайте установщик (.jar) по кнопке «Download universal jar». Исполняемого файла (.exe) для Mac не существует.
  2. Скачанный файл fabric-installer-〜.jar откройте не обычным двойным щелчком, а через правый клик (или клик с зажатой клавишей control) → «Открыть». Если появится предупреждение, снова нажмите «Открыть».
  3. Оставаясь на вкладке «Client», выберите в Minecraft Version то же число, что и на сервере, и нажмите «Install».
⚠ Если на Mac появляется «Не удаётся проверить разработчика»

В новых версиях macOS даже клик правой кнопкой → «Открыть» может не показать кнопку, а появится только предупреждение: «"fabric-installer〜.jar" не удалось открыть, так как Apple не может проверить его на наличие вредоносного ПО». В этом случае откройте файл в таком порядке.

  1. В предупреждении нажмите «Готово» (ни в коем случае не нажимайте «Переместить в Корзину»)
  2. Откройте меню Apple в левом верхнем углу экрана → «Настройки системы» → «Конфиденциальность и безопасность»
  3. Внизу будет надпись вида «Использование "fabric-installer〜.jar" заблокировано» — нажмите рядом кнопку «Открыть в любом случае»
  4. Если появится ещё один запрос, снова нажмите «Открыть в любом случае» → введите пароль Mac (или используйте Touch ID)

Это стандартное предупреждение, которое появляется для любого ПО, не зарегистрированного у Apple. Если вы скачали файл с официального сайта Fabric, беспокоиться не о чем. После того как вы разрешите открытие один раз, в следующий раз файл откроется как обычно.

Если на Mac установщик вообще не реагирует на клики

Если после клика правой кнопкой → «Открыть» ничего не происходит, значит в системе не установлена Java. Откройте adoptium.net и установите установщик (.pkg) для macOS в разделе «Temurin», а затем попробуйте снова. Для Mac с Apple Silicon (M1/M2/M3/M4 и т. д.) выбирайте «aarch64», для Mac с процессором Intel — «x64». Если не уверены, откройте меню Apple в левом верхнем углу → «Об этом Mac» и посмотрите поле «Чип» (если там написано «Apple M…», значит нужен aarch64).

② Размещение файлов модов в папке mods

Windows: %appdata%\.minecraft\mods

  1. В адресной строке проводника введите %appdata%\.minecraft и нажмите Enter.
  2. Если папки mods нет, создайте новую (название целиком строчными буквами).
  3. Скопируйте все 12 полученных jar-файлов в эту папку mods (распаковывать не нужно, оставьте как jar-файлы).

Mac: ~/Library/Application Support/minecraft/mods

  1. Кликните один раз по рабочему столу, затем одновременно нажмите ⌘ command + ⇧ shift + G (либо в верхнем меню «Переход» → «Переход к папке…»).
  2. В появившееся поле ввода вставьте ~/Library/Application Support/minecraft как есть и нажмите Enter (не забудьте знак «~» в начале). Папка «Library» обычно скрыта в Finder, поэтому такой способ — самый надёжный.
  3. Если папки mods нет, создайте её на месте через правый клик → «Новая папка».
  4. Перетащите все 12 полученных jar-файлов в эту папку mods.

③ Запуск через Fabric и подключение к серверу

  1. Откройте лаунчер Minecraft и в списке конфигураций запуска рядом с кнопкой «Играть» выберите профиль вроде fabric-loader-26.2 (если оставить «Последний релиз», игра запустится без модов).
  2. Нажмите «Играть» и запустите игру. Если на титульном экране появилась кнопка «Mods» — всё получилось. Нажав на неё, можно увидеть 11 модов Glimpse Alpha и Fabric API.
  3. Дальше подключайтесь к серверу как обычно, через «Мультиплеер».

Когда моды обновляются

Когда моды на сервере обновляются, все участники должны обновиться до той же версии одновременно.

  1. Получите новые файлы модов от администратора сервера (дождитесь оповещения и только потом приступайте).
  2. Откройте папку mods и удалите старые jar-файлы Glimpse Alpha, затем добавьте новые (даже если имя файла изменилось, это считается тем же самым модом — если оставить старый файл, игра не запустится).
  3. Запустите игру как обычно, через профиль fabric-loader.
⚠ Внимание

Если обновится только одна сторона, подключиться к серверу не получится. Если возникли проблемы, загляните также в раздел частых вопросов.

Для администратора сервера

Для администратора сервера: подготовка (резервная копия и проверка версии)

Начиная с этого раздела — главы для тех, кто сам администрирует и обслуживает сервер. Здесь описан переход от уже работающего сервера Minecraft (ванильного, стандартного, без модов) к добавлению Fabric и 11 модов Glimpse Alpha. В качестве примера в этой главе используется сервер на Windows. Если вы администрируете сервер на Mac / Linux, адаптируйте расположение папок и способ выполнения команд под свою систему и следуйте той же процедуре (см. официальный сайт Fabric).

🛑 Обязательно перед началом работы

Чтобы не потерять мир даже при неудачной установке модов, обязательно сделайте резервную копию перед началом работы.

1. Резервное копирование мира

Откройте папку сервера (например, C:\MinecraftServer) и выполните привычную процедуру резервного копирования (например, скрипт вроде Backup-Server.bat). Если специального скрипта нет, достаточно остановить сервер и скопировать всю папку world в другое место.

2. Проверка версии Java

  1. Откройте командную строку (или любой терминал).
  2. Введите java -version и нажмите Enter.
  3. Проверьте, что отображается число 25 (пример: java version "25.0.3").
🛑 Очень важно

Для запуска Minecraft 26.2 требуется Java 25. В старых инструкциях по настройке иногда написано «Java 21» — это устаревшая информация, с Java 21 сервер не запустится. Если число меньше 25, откройте adoptium.net, скачайте и установите «Temurin 25 (LTS)», перезагрузите компьютер и проверьте снова.

3. Проверка версии Minecraft на сервере

  1. Запустите сервер обычным способом (например, через Start-Server.bat).
  2. В начале консоли (чёрного окна) найдите строку вида Starting minecraft server version X.Y и запишите это число.
  3. Введите в консоли stop и нажмите Enter, чтобы безопасно остановить сервер.
⚠ Внимание

В этой инструкции для примера используется запись «26.2», но если у вас получилось другое число, замените его во всех дальнейших шагах (выбор версий Fabric, Fabric API и каждого мода). Если версия сервера, всех игроков и модов не совпадает хотя бы в одном месте, ничего не заработает.

Для администратора сервера

Для администратора сервера: установка Fabric

Установка Fabric-сервера

  1. В браузере откройте https://fabricmc.net/use/server/ и скачайте установщик по кнопке вроде «Download installer (Windows/.exe)».
  2. Запустите скачанный файл fabric-installer〜.exe двойным щелчком (если появится «Windows защитила ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае»).
  3. На экране настроек установщика проверьте следующие 4 пункта.
    • Выберите вкладку «Server»
    • В Minecraft Version выберите ту же версию сервера, которую вы определили при подготовке (например: 26.2)
    • Loader Version можно оставить как есть
    • В Install Location укажите папку уже существующего сервера (например: C:\MinecraftServer)
  4. Нажмите «Install».
  5. Если в папке сервера появился новый файл fabric-server-launch.jar — установка прошла успешно.

Создание нового файла запуска (bat-файла)

Существующий файл запуска (например, Start-Server.bat) запускает сервер «без модов». Не удаляйте его — он пригодится, если понадобится вернуться к серверу без модов. Вместо этого создадим новый файл запуска для Fabric.

  1. Откройте «Блокнот» (Notepad).
  2. Скопируйте и вставьте следующий текст. 
    @echo off
cd /d "%~dp0"
title Minecraft Fabric Server
java -Xms2G -Xmx4G -jar fabric-server-launch.jar nogui
echo Сервер остановлен.
pause
  3. В меню «Файл» → «Сохранить как» укажите папку сервера (например, C:\MinecraftServer), имя файла Start-Fabric-Server.bat, а тип файла — «Все файлы».
⚠ Внимание

Если не выбрать тип файла «Все файлы», получится нерабочий файл Start-Fabric-Server.bat.txt. Также, если объём памяти (RAM), выделенной серверу, отличается от 4 ГБ, замените цифру «4» в -Xmx4G на нужное значение.

Для администратора сервера

Для администратора сервера: установка модов и проверка запуска

Сам мод — это отдельный файл, «jar-файл» (произносится «джар»). Установить его можно, просто положив в папку mods в папке сервера.

1. Подготовка папки mods

Проверьте, есть ли в папке сервера (например, C:\MinecraftServer) папка с именем mods. Если нет — создайте её через правый клик → «Создать» → «Папку» с именем mods (целиком строчными буквами).

2. Получение Fabric API

Откройте https://modrinth.com/mod/fabric-api/versions и скачайте самую верхнюю версию из списка, у которой «Game version (версия игры) совпадает с версией на сервере» (пример: fabric-api-0.154.2+26.2.jar).

3. Размещение всех модов в папке mods

Скопируйте в папку mods все 12 jar-файлов — 1 файл Fabric API и 11 модов Glimpse Alpha (распаковывать не нужно, оставьте как jar-файлы). Сами 11 модов получите привычным для вас способом раздачи. Этот сайт сами файлы модов не распространяет.

💡 Если появляется ошибка Java и сервер не запускается

Как только запуск подтверждён, сообщите всем участникам про главу для игроков — пусть каждый установит на своём компьютере тот же набор Fabric и модов.

Для администратора сервера

При замене модов на новую версию

Все 11 модов Glimpse Alpha полностью независимы друг от друга, поэтому при каждом обновлении не обязательно заменять все 11 сразу. Достаточно заменить только те моды, которые реально изменились (какие именно моды изменились, можно узнать из сопроводительной информации при раздаче или из истории обновлений).

Порядок обновления

  1. Введите в консоли сервера stop, чтобы остановить сервер.
  2. Сделайте резервную копию мира привычным способом.
  3. В папке mods на сервере удалите старый jar-файл обновляемого мода и положите новый (если в папке останутся и старая, и новая версия одного и того же мода, сервер не запустится).
  4. Запустите сервер через Start-Fabric-Server.bat и убедитесь, что в консоли отображается обновлённая версия.
  5. Раздайте новые jar-файлы всем участникам и попросите их так же заменить файлы (см. главу для игроков). Если новая версия установлена только на сервере или только у игроков, подключиться не получится.
🛑 Очень важно

Если запустить сервер с полностью удалённым (а не обновлённым) модом, все блоки и предметы, добавленные этим модом (например, светофоры), исчезнут. Это особенность самого Minecraft и Fabric, отменить это нельзя. Обязательно делайте резервную копию перед удалением мода.

О файлах config (механизм автоматического восстановления)

Каждый мод при запуске автоматически создаёт в папке config/ файл настроек (например, sorakaze_guns.json). В нём можно настраивать такие значения, как урон и скорость, и в базовом случае не нужно вручную удалять или редактировать этот файл при каждом обновлении.

💡 Как это работает сейчас

Если в новой версии изменилось значение по умолчанию для какого-то параметра, оно обновится автоматически только для тех параметров, которые вы ещё не настраивали (оставшихся на старом значении по умолчанию). Значения, которые вы настроили сами, не затрагиваются. Новые параметры, появившиеся в обновлении, тоже добавляются автоматически при запуске. Все обновлённые значения обязательно записываются в logs/latest.log в формате «старое значение → новое значение».

⚠ Внимание при редактировании файла настроек

Если вручную удалить только часть значения в файле настроек (например, стереть только строку урона из блока настроек одного оружия), этот параметр может незаметно замениться другим значением по умолчанию из самого мода (без вывода ошибки). Если хотите настроить конкретное значение, редактируйте его напрямую. Если же хотите сбросить настройки мода полностью, удалите весь файл настроек этого мода — при следующем запуске он будет создан заново со значениями по умолчанию.

Что нужно знать перед началом игры

Glimpse Alpha включает несколько изменений, влияющих на поведение ванильной игры. Здесь собраны самые незаметные из них. Точные цифры могут корректироваться с каждым обновлением, поэтому актуальную информацию всегда сверяйте с историей обновлений и страницей известных проблем. Настройку config выполняет администратор сервера.

Редстоуну нужно «электричество»

После установки мода электричества часть ванильных механизмов на редстоуне перестаёт работать сама по себе.

  • Требуют электричества: пыль редстоуна, повторитель, компаратор, блок редстоуна, факел редстоуна. Они не будут подавать сигнал, пока к ним не подведён кабель с электричеством. Автофермы, станции, автоматические двери, цепочки воронок остаются неактивными, пока не будет проложена проводка.
  • Продолжают работать без электричества как раньше: рычаг, кнопка, нажимная плита, крюк для верёвки, наблюдатель, датчик дневного света, скверный датчик, мишень, ловушка-сундук, детекторные рельсы, книжная подставка, музыкальный автомат, громоотвод и другие. Ручное открытие дверей и ворот тоже работает как обычно.
  • Примерно через 10 минут после установки блок редстоуна разрушается сам по себе (возвращается в виде предмета).
💡 Как вернуть прежнее поведение (для администратора сервера)

Если установить powerEnabled в false в файле config/sorakaze_power.json, электрификацию редстоуна можно отключить полностью.

Часть устройств из стройматериалов и декора тоже требует электричества

Пять устройств — камера видеонаблюдения, лифт, эскалатор, автоматическая дверь и банкомат — не работают, пока к ним не подведено электричество кабелем (лифт может двигаться «вниз» даже без электричества). Отключить требование электричества для каждого устройства по отдельности можно, установив соответствующий параметр в config/sorakaze_deco.json в false.

Генератор нагревает помещение

Работающий генератор или атомная электростанция повышают температуру в том же помещении. Охладить воздух может только кондиционер. Проще всего отделить машинное помещение стенами и закрытой дверью — тогда тепло не будет распространяться на другие комнаты. Саму эту функцию можно отключить, установив temperatureMachineHeatEnabled в config/sorakaze_survival.json в значение false.

Высота измерения «Небеса» расширена

После установки мода «Небеса» верхний предел высоты застройки в обычном мире (Верхнем мире) увеличен. Меняется только верхний предел — глубина подземной части (высота дна) и уже существующий рельеф не изменяются.

Ракетница разрушает рельеф

Ракетница из мода огнестрельного оружия по умолчанию разрушает рельеф в точке попадания. Ванильное игровое правило mobGriefing в значении false это не останавливает. Чтобы отключить разрушение, установите rocketDestroysTerrain в config/sorakaze_guns.json в значение false. Будьте особенно осторожны рядом с базой.

О мощности оружия

Оружие из мода огнестрельного оружия, особенно штурмовая винтовка, обладает очень высокой мощностью — многих боссов, добавленных модами, можно убить за несколько секунд. Если хочется большего вызова, администратор сервера может вернуть сложность, скорректировав значения урона каждого оружия в config/sorakaze_guns.json.

После удаления мода установленные блоки и предметы исчезают

Это общая особенность модов, а не проблема, специфичная для Glimpse Alpha. Блоки, установленные, и предметы, полученные благодаря моду, теряются из мира при удалении этого мода. Вернуть их можно только восстановлением из резервной копии.

Частые вопросы и решение проблем

Частые вопросы

ВопросОтвет
Мир не исчезнет?Не исчезнет. Даже после установки Fabric прежний мир можно использовать как есть. Если переживаете, обязательно сделайте резервную копию перед установкой.
Сможет ли подключиться друг без модов?Нет, не сможет. Настройку из главы для игроков должны выполнить все участники.

После обновления модов внезапно перестал(-а) игратьПроверьте, совпадают ли версии модов на сервере и у игрока. Если новая версия только с одной стороны, подключиться не получится.
Не могу прочитать сообщение об ошибке на английскомЧитать его не обязательно. Просто отправьте администратору сервера файл latest.log из папки logs как есть.

Если сервер не запускается

  1. Временно переместите всё содержимое папки mods в другое место.
  2. Возвращайте файлы по одному, каждый раз пробуя запустить сервер, чтобы определить, какой файл вызывает проблему.
  3. Если появляются ошибки, связанные с Java, проверьте версию Java, следуя главе о подготовке.

Если сервер запускается, но подключиться не получается

  1. Проверьте, что версия и набор модов у всех участников полностью совпадают с серверными.
  2. Особенно часто причиной становится несовпадение версии Fabric API — проверьте её в первую очередь.
💡 Если ничего не помогает

Отправьте logs/latest.log администратору сервера и обратитесь за помощью. Не переживайте — если есть резервная копия, всегда можно вернуться к прежнему состоянию.

Как восстановить мир из резервной копии (для администратора сервера)

  1. Введите в консоли сервера stop, чтобы остановить сервер.
  2. Возьмите самую свежую резервную копию из места хранения (например, C:\MinecraftServer\backups) (если это zip-архив, распакуйте его через правый клик → «Извлечь всё»).
  3. Замените папку world в папке сервера на извлечённую папку world (с перезаписью).
  4. Запустите сервер.
