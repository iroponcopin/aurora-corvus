Aureum（轻量化优化模组，单独下载）

Aureum 是与 Alpha 整合包完全独立的模组。它优化游戏逻辑、内存与服务器 tick 开销，且刻意从不触碰区块渲染管线。它不是 Sodium 的替代品——它优化的正是 Sodium 未涉及的那一侧，因此可以与 Sodium 一起安全使用。若想提升帧率，请另行安装 Sodium。

目前实测：加载 2,209 个区块时减少 6.3 MB，生成同等规模的新地形后减少 17.2 MB（两次独立测量结果一致）。MSPT（tick 用时）在测量误差范围内无变化。两个客户端功能（粒子数量上限、方块实体渲染距离）默认关闭且未经测量，因为本开发环境没有客户端。安装与配置方法请参阅 GitHub 上的 README。

每项优化均可单独关闭

config/aureum.json 中的每个设置项都可以单独关闭。关闭某一项后，Aureum 针对该功能的字节码修改将完全不会被应用——这是与其他模组发生冲突时可采取的最可靠隔离方式。

运行要求

  • Minecraft 26.2 (Fabric)
  • Fabric Loader 0.19.3+
  • Fabric API
  • Java 25+
