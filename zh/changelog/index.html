V1.3

The Washitsu Architectural Masterpiece —— 和室的三十件器物与一座自己运转的工厂

The Washitsu Architectural Masterpiece —— 和室的三十件器物与一座自己运转的工厂

加入了用来建造和室的 30 件器物，以及第二次工业化更新的 10 种设施。榻榻米与缘侧、障子与隔扇、栏间与屏风、矮桌与衣柜、挂轴与香炉，石灯笼、惊鹿与风铃，还有棋盘。工厂这边则有隔墙传送物品的收发器、用你交给它的工具开采的采掘机、直接从仓库取物的 I/O 总线等。所有新音效都从零合成。

更新内容 (10)

  • 榻榻米：蔺草榻榻米每 2 格为 1 张，包边有 4 种。站在 8 格以上相连的榻榻米房间里，饥饿值的消耗速度减半。无包边的方格榻榻米并排铺设时会拼出棋盘格。
  • 障子与隔扇：用空手或红石信号即可让它们滑开约 1 格；2 扇并排时会交错滑过彼此。4 扇隔扇排成一列，便合成一幅金箔山水画。
  • 鸭居与长押：上方可嵌入透雕栏间，也能悬挂挂轴、刀架、门帘、竹帘或风铃。门帘会从你穿过的那一侧掀开；竹帘最多可接 3 段，连成 1 幅一起卷收。
  • 家具：可以坐在坐垫上，也可以坐在和式座椅上，矮桌上最多可摆放 4 件物品，桐木衣柜有 27 格。点好抹茶再喝下，生命值回满，并获得急迫 II，持续 3 分钟（每 5 分钟 1 碗）。
  • 壁龛与庭院：挂轴每过游戏内 8 天就换成当季的画，雪见灯笼在冬天会积雪。惊鹿每 4.4 秒敲击一次石头，风铃随风鸣响。
  • OUKA 物质收发器：用共振连接器连接后，可隔墙传送到最远 32 格处，每刻最多一组物品和一桶液体。1 台发送器最多对应 4 台接收器，无需电力。
  • 共振采掘机：使用你交给它的镐或锹，不加速时，所需时间与你亲手用那件工具挖掘相同。精准采集和时运同样生效。范围最大 5×5，深度最多 16。
  • 量子仓库直连 I/O 总线：从仓库取出你选定的物品（最多 9 种），每刻最多 256 个，并在仓库中留下你设定的数量。OUKA 传送带每刻只接收 1 个。
  • 脉冲漏斗与圆石合成机：漏斗每刻向箱子或管道搬运 64 个物品（向 OUKA 传送带只搬运 1 个）。圆石合成机只要各放入 1 桶熔岩和水，就绝不会消耗它们，并用电网的电力持续产出圆石、沙砾、沙子或矿砂。
  • 此外：3×3 分子合成器、每刻输送 8 桶流体的泵与管道、把经验存进胶囊的生物粉碎机、即使在其他维度也能打开仓库的便携终端，以及最高可让 OUKA 机器加速到 ×10 的加速塔。

注意事项 (3)

  • 本版本修复了 V1.0.1、V1.1.0 和 V1.2.0 中从未响起的两个音效（OUKA 信标终端滑块的刻度音；Ouka Caster 选择盘的确认音）。如果你在使用更早的版本，请替换。
  • 也可以通过 Corvus Store 安装：首次请在 Corvus Store 中点击“获取”；之后 Corvus Store 会自动替换为新版本。如果你关闭了“自动更新”，请点击“更新”。（手动安装请前往 OUKA 页面。）
  • 需要 Minecraft 26.3、Fabric Loader 0.19.5 或更高、Fabric API 0.161.0+26.3 或更高、GeckoLib 5.5.6（已包含在 zip 中）以及 Java 25。

V1.2

The Heavy Industrial & Kinematics Epoch —— 看得见运转的重工业

The Heavy Industrial & Kinematics Epoch —— 看得见运转的重工业

加入了 20 种重工业机器与工具：电网与发电站、巨型仓库、传送带与无人机物流、冶炼与加工、采矿与自动收获，以及现场工具和防护外骨骼。没有一台机器只是数字上涨的箱子：机械臂、锤、钻头和旋翼都真的在动，每台机器的声音都随工作强度变化。本版本还修复了 V1.1.0 的两个缺陷。

更新内容 (10)

  • 电网：特斯拉电塔在 64 格内无线互联，电弧从电塔延伸到机器。无需线缆。
  • 发电与储能：核裂变反应堆（最高 2 MW；达到 800 °C 时紧急停堆，绝不爆炸），夜间依靠储存的热量继续运转的太阳能塔，以及 400 MJ 的超导储能方块。
  • 超维量子压缩仓：搭好 5×5×7 的外壳即可存放多达 2,147,483,647 件物品，可按名称或“@模组”搜索。
  • 磁悬浮传送带每秒运送 20 件物品。形状随相邻方块自动决定，每件物品都在带上可见，不会掉落，堵住时会排队等待。还有分流器和六向分拣器。
  • 物流无人机：用航线卡连接两个港口，无人机就会载货往返——即使途经未加载的区域，货物也会在飞行时间之后送达。
  • 冶炼与加工：以熔炉 16 倍速度一次熔炼 32 个矿石的电弧炉，产出双倍粉末与板材的液压粉碎机，三只机械臂焊接的装配线，以及提取钛、锂和氦-3 的离心机。
  • 采矿与收获：不破坏基岩、无尽开采矿石与原油的钻井，每秒抽取 200 桶的取水涡轮，伐木、制成木板并重新种植的锯木厂，以及培养槽。
  • 万能工业扳手（翻转机器、开关出口、最高 ×2.50 超频）与热解切割激光（一秒内将机器连同内容物收回背包）。
  • 全息电路蓝图：记录边长最多 16 格的区域，用等大的全息影像确认后，以随身物品建造。
  • 全天候防护外骨骼：不受电击、高温和坠落伤害，可在岩浆中游泳，挖掘速度提升到 3 倍。

注意事项 (3)

  • 本版本修复了 V1.1.0 的两个缺陷（挖掘樱花合金块不掉落任何东西；避难所的战利品表）。如果你在使用 V1.1.0，请替换。
  • 也可以通过 Corvus 安装：首次请在 Corvus 中点击“下载”；之后 Corvus 会自动替换为新版本。（手动安装请前往 OUKA 页面。）
  • 需要 Minecraft 26.3、Fabric Loader 0.19.5 或更高、Fabric API 0.161.0+26.3 或更高、GeckoLib 5.5.6（已包含在 zip 中）以及 Java 25。

V1.1

The Operating Shelter —— 只属于管理员的基岩

The Operating Shelter —— 只属于管理员的基岩

只有管理员才能放置或破坏的方块。任何爆炸、任何生物、创造模式的破坏都拿它没办法。本次更新还加入了十七种从零合成的音效，让所有配方一开始就出现在配方书中，并修复了 V1.0.0 的崩溃。

更新内容 (10)

  • Operating Shelter 方块：只有拥有管理员权限的玩家才能放置或破坏。其他人在任何游戏模式下都不行。
  • 任何爆炸都穿不过去 —— Alpha 的核武器、其他弹头和火箭、TNT 都一样。
  • 普通玩家在创造模式下也破坏不了。创造模式的瞬间破坏不看硬度，所以那条路另外堵住了。
  • 凋灵、末影龙、想搬走它的末影人、活塞 —— 一个都碰不到。它被放进了原版给基岩的全部十一个标签里。
  • 管理员在生存模式下照常挖掘并能回收（钻石镐或更好）。
  • 其他人碰到时，方块表面会张开六角形的能量栅格，伴随金属的回弹声与火花。
  • 十七种音效，全部从零合成。没有其他游戏的声音，没有素材库，没有录音。
  • 十二色即十二半音：每种圆环颜色以各自的音高发声，听声音就知道飞的是哪一种。
  • 所有配方从一开始就出现在配方书中。V1.0.0 的解锁条件过严，什么都不显示。
  • Shelter 由 4 个黑曜石、4 个下界合金锭和 1 个樱花合金块合成，一次产出 2 个。

注意事项 (3)

  • 如果你在用 V1.0.0，请务必更换：当视频设置中的「改进的透明度」开启时，V1.0.0 会在圆环弹进入画面的瞬间崩溃。
  • 请从 OUKA 页面安装。Corvus 会显示 OUKA 的更新日志，但不会安装 OUKA。
  • 需要 Minecraft 26.3、Fabric Loader 0.19.5 或更高、Fabric API 0.161.0+26.3 或更高、GeckoLib 5.5.6（已包含在 zip 中）以及 Java 25。

V1.0

The Apex Artifact —— 祭坛与十二色弹幕

The Apex Artifact —— 祭坛与十二色弹幕

OUKA 的首个版本：面向 Minecraft 26.3（Fabric）的模组，独立于 Alpha 与 Cherry。在基座上立起祭坛，1,000 格内的每位玩家都会获得其效果；两件物品可发射十二种颜色的圆形弹。

更新内容 (10)

  • OUKA 信标：3×3×3 的结构。破坏其中任意一块，27 块会一并脱落，并掉落一个带着设置的信标。
  • 由下界合金、钻石、绿宝石或樱花合金堆成八层、共 328 格的基座。328 格齐备时才会苏醒。
  • 半径 1,000 格的光环，即使信标所在区块未加载也能抵达玩家。旁观者不会获得。
  • 十种效果可在 0.00 到 20.00 之间无级调节：移动、挖掘、攻击速度、力量、跳跃、缓降、伤害吸收、生命恢复、饱食、抗性与夜视。
  • 只要光环仍然抵达，就持续享有附魔金苹果的效果——祭坛屹立时，死亡之后也会回来。
  • 磨砂玻璃终端：右键打开，拖动滑块，或用滚轮以 0.1 为步进，按住 Shift 则为 0.01。三组预设。
  • 只有放置者本人或管理员可以更改，且须在 8 格之内。其他人看到的是只读界面。
  • 十二种颜色的圆形弹，各有其效果：冻结、牵引、穿墙直线、一分为二的追踪，以及轮转其余十一色的一种。
  • 五种弹道：直线、螺旋、汇聚于视线落点的十二发、八发环绕的轨道护卫，以及追踪。
  • 着弹的冲击波：平展的环会抹去所经之敌。首领损失最大生命值的 20%。友方与方块安然无恙。

注意事项 (3)

  • 有一种颜色在着弹时会让画面闪白（Celestial White）。若已开启 Minecraft 的「隐藏闪电闪光」设置，则不会闪。
  • 请从 OUKA 页面安装。Corvus 会显示 OUKA 的更新日志，但不会安装 OUKA。
  • 需要 Minecraft 26.3、Fabric Loader 0.19.5 或更高、Fabric API 0.161.0+26.3 或更高、GeckoLib 5.5.6（已随 zip 附带）与 Java 25。

Cherry

更新于 2026-09-28

页面中显示的伤害、速度等数值均为导入时的默认值。服务器可能通过 config 进行了调整，实际游玩时体验到的数值可能有所不同。

V1.2

枪械、月球生物、Lunaris Prime 与火星

枪械、月球生物、Lunaris Prime 与火星

Cherry 最大的一次更新：五把带第一人称动画与后坐力的次世代枪械、三种月球生物、封印在月球远方遗迹中的首领 Lunaris Prime、寒冷且刮着铁尘暴的红色星球火星、可让 Apex-1 飞往三个世界中任意一个的导航控制台，以及能制造所有枪械、弹匣和载具零件的 Advanced Cherry Fabricator。

更新内容 (8)

  • 五把枪：CR-14 无托步枪、CP-9 冲锋枪、CS-50 轨道狙击枪、CX-12 磁脉冲霰弹枪和 C-Pistol。右键瞄准时，比瞄准点更近和更远的景物会柔和地虚化；R 键装填（生存模式下消耗一个该枪的弹匣），F 键检视；并带有后坐力、枪口焰、弹壳、全息瞄准镜、CS-50 的 6 倍热成像瞄准镜以及 C-Pistol 的激光瞄准器。
  • 月球生物：Selenite Stalker 潜伏在月壤之下，扑向不潜行走动的人，并咬穿加压服；Void Drifter 的 EMP 会让枪械的瞄准镜和弹药显示熄灭；Regolith Devourer 重击地面把你抛上高空，还会投掷熔融陨石。
  • Lunaris Prime：在月球上 8,000 格之外，一座巨大的陨坑中坐落着 Astraea Shackle（可用 /locate 找到）。将 Astral Catalyst 放入它的封印控制台即可唤醒首领；天空会染成深红色，生命值降到一半时，它的装甲会飞散，进入更快的第二阶段。
  • 它的遗物：Coreshard of Lunaris、Graviton Siphon（射击会打开一个黑洞）和 Crown of Selene。
  • 火星：在发射台上按下发射键，即可打开 Apex-1 的 Stellar Navigation 控制台，并选择地球、月球或火星。火星的重力为 0.38 g，空气温度 −60 °C 且无法呼吸：压力服能把空气挡在外面，在锻造台缝入的 Thermal Lining 能把寒冷挡在外面。
  • 火星上大约每 20 分钟刮起一次铁尘暴：雾气收拢到只剩几格远，Cherry 的 HUD 上会闪过杂波。
  • 火星的资源：Martian Ferrite 与 Perchlorate Energy Salt。Perchlorate Propellant 是相当于三罐的火箭燃料。
  • Advanced Cherry Fabricator：选择配方并填满它的六个输入口，即可制造枪械、弹匣、枪械零件、燃料和所有载具；它用氦-3 和月壤核心批量生产助推器与轨道炮炮管，再用助推器组装 Apex-1、用炮管组装 Dreadnought；也可以用漏斗供料。

注意事项 (1)

  • 需要 Minecraft 26.3、Fabric Loader 0.19.5 或更高、Fabric API 0.161.0 或更高、GeckoLib 5.5.6 或更高，以及 Java 25。

V1.1

更换音频设备后，声音会自动恢复

更换音频设备后，声音会自动恢复

当音频设备发生变化时（插拔耳机，或在选项中选择设备），游戏会重启声音引擎，并停止所有循环播放的声音。在 1.1.0 至 1.1.3 中，Cherry 的飞机引擎、加力燃烧、导弹发动机、锁定提示音以及压力服的呼吸声会一直保持静音，直到你重新登机或重新戴上头盔。现在它们会自动重新响起。

更新内容 (2)

  • 更换音频设备后，Stratos-900 与 Aegis-X 的引擎、Aegis-X 的加力燃烧、导弹发动机和锁定提示音会立即自动重新响起。
  • 在月球上，压力服的呼吸声也同样会恢复。

注意事项 (1)

  • 需要 Minecraft 26.3、Fabric Loader 0.19.5 或更高、Fabric API 0.161.0 或更高、GeckoLib 5.5.6 或更高，以及 Java 25。

操作更简单，主炮也能命中了

飞行与航行的操作已重新打造，人人都能上手。视角不再锁定：飞机朝你注视的方向飞行，舰船像小船一样用 W、A、S、D 操纵。Dreadnought 的电磁轨道炮现在会伤害命中的目标；在 1.1.0 至 1.1.2 中，它的炮弹不会伤害任何东西。

更新内容 (11)

  • 飞机朝你注视的方向飞行：转动视线，Stratos-900 或 Aegis-X 就会自行倾斜、转弯、爬升或俯冲，飞向那里。W 和 S 调节推力；左键向雷达自行选定的目标发射 Aegis-X 的导弹。
  • 襟翼、起落架、刹车、反推、加力燃烧室、座舱盖和着舰钩现在都会自动工作；登机时，屏幕上会显示操作的简短说明。
  • 视角由你掌控：不再锁定为第一人称，也不再随飞机倾斜；飞行中可以使用 F5，按住 Left Alt 即可环顾四周，飞机则保持航向。
  • 舰船：站在岗位处，屏幕上会显示就位的按键。在舵轮处，W 和 S 控制主机（低于零为后退），A 和 D 操舵，松开后舵轮回中并保持航向；按“潜行”离开。渡轮的舱门在 Y 键上。
  • 火炮岗位无人时，Dreadnought 的舵手可以在舵轮处开炮：左键齐射，右键发射垂直发射系统（VLS）。
  • 修复了 1.1.2 的问题：舵使舰船朝按键的反方向转、后退不产生推力、无法从岸边让舰船下水（现在舰船会浮起，船尾刚好越过你瞄准的水面）、生存模式下无法收回舰船。
  • 电磁轨道炮的炮弹会在弹道上遇到的第一个方块、生物、舰船或飞机处爆炸，并伤害 4 米内的一切；齐射落在同一目标上时，六发炮弹全部计入。注视船体或机体的任意部位，两座炮塔都会指向那一点。
  • 主炮不会伤害开火的舰船及其船员，也绝不破坏方块。任何舰船或飞机都不会被一轮齐射击沉或击落，操炮时也不再加载远处的区块。
  • 攻击者手持重命名的物品时，Cherry 武器造成的死亡消息不再显示未翻译的键名。
