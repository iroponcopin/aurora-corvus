Discord 机器人

Aurora Corvus 会在版本发布时公告，告诉服务器接下来会有什么，并接收缺陷报告与需求——语言由服务器自行选择。

把机器人加入服务器

将打开 Discord 官方授权页面。你需要对目标服务器拥有「管理服务器」权限。

设置步骤

  1. 1. 添加机器人

    点击上方按钮。它只申请四项权限——查看频道、发送消息、嵌入链接、读取历史——外加为每份报告开一个子区。绝不申请管理员权限。

  2. 2. 选择频道

    运行 /release channel 选择公告去向。这将成为默认频道：未单独指定的内容都会送到这里。

  3. 3. 选择语言

    运行 /language set。共 13 种语言，均以其自身文字列出。

  4. 4. 分开投递（可选）

    运行 /channels set，为更新、预告、缺陷报告和需求各指定一个频道。未设置的仍走默认频道。 update upcoming bug request

机器人会自动发布什么

三类内容，若已设置则分别发往各自频道。同一内容不会重复发布。

  • 版本发布时——整合包，以及在你开启后连同 Corvus 本体。
  • 发布预告时，内容直接取自「接下来」页面。
  • 有人提交缺陷报告或需求时，并附带一个讨论子区。

全部命令

命令 作用 可使用者
/bug — 报告缺陷并跟进处理进度。
/bug new打开一个简短表单：一行摘要、发生了什么，以及（若知道）如何复现。所有人
/bug list <status>按未处理优先列出本服务器的报告。回复仅你可见，可在重复提交前先查看。所有人
/bug close <number> <resolution>将报告标记为已处理，并说明解决方式。管理服务器
/bug reopen <number>当问题并未修复时，把已关闭的报告放回列表。管理服务器
/channels — 让每一类消息各用一个频道。
/channels set <kind> <channel>把更新、预告、缺陷报告或需求中的某一类指向指定频道。管理服务器
/channels show列出四个类别当前各自的去向。所有人
/channels clear <kind>让该类别回到服务器的默认频道。管理服务器
/language — 选择本机器人在此服务器使用的语言。
/language set <language>设置语言。此后公告、表单与回复都会使用它。管理服务器
/language show显示本服务器所设的语言。所有人
/release — 整合包与 Corvus 的更新公告。
/release channel <channel>设置默认频道。未单独指定的内容都会发到这里。管理服务器
/release status显示本服务器当前的全部设置。所有人
/release latest显示机器人已知的最新版本，但不向频道发布公告。所有人
/release enable重新开启本服务器的公告。管理服务器
/release disable在不移除机器人、不丢失设置的情况下停止公告。管理服务器
/release launcher <enabled>选择是否连同整合包一起公告 Corvus 启动器的构建。管理服务器
/release upcoming <enabled>开启或关闭预告，并显示接下来的内容。所有人
/release test发布一条示例公告，便于检查频道与权限。管理服务器
/request — 提出功能或改动需求，并跟进处理进度。
/request new打开一个简短表单：你想要什么，以及它为何有帮助。所有人
/request list <status>按未处理优先列出本服务器的需求。回复仅你可见。所有人
/request close <number> <resolution>将需求标记为已处理，并说明决定。管理服务器
/request reopen <number>把已关闭的需求放回列表。管理服务器

同一类型每人每 10 分钟最多 3 份。提交缺陷报告不会妨碍你提出需求。

13 种语言

语言按服务器而非按个人设置：公告发到共享频道，同一频道的所有人应当读到同一条消息。表单、回复与错误提示也遵循该设置。

斜杠命令名保持英文，因为 Discord 是按读者本人的客户端设置取用命令名，而非按服务器。

会保存哪些信息

一份报告只保存你在表单中填写的内容、你的 Discord 用户 ID 与显示名，以及发布位置。仅此而已。机器人不保存消息历史，不读取未被指定的频道，也与你的 Minecraft 账号无关。
