概述：关于 Glimpse Alpha 的导入

Glimpse Alpha（旧称：Sorakaze）是导入在 Sorakazekarasu 服务器中的 Fabric MOD 群。由 11 个相互独立的 MOD 组成，可以分别单独导入、更新。 它不会替换或删除弓箭、矿车等原版（未安装 MOD 时的标准）要素， 而是以新增物品、方块、维度的形式来实现。

MOD内容
枪械原版没有的远程武器（突击步枪、霰弹枪、狙击枪等）
铁道会逐渐加速的电车，以及可连结的客车厢、货运车厢
建材、装饰信号灯、护栏等城镇建材，以及监控摄像头、ATM、电梯等家电
载具汽车、巴士、航空器等
Boss强大的讨伐目标，以及专属的掉落装备
天空新维度「天空」，以及居住在那里的天使之城、王国
生存新矿石、护甲，以及气温、四季等生活要素
电力发电、输电网络，以及靠电力运作的设备
后室带理智值的异界探索

各 MOD 详细的物品与配方，请参阅合成配方；此前的变更内容，请参阅 更新日志。

使用 MOD 需要「Fabric」

Fabric 是让 Minecraft 能够读取 MOD 的基础平台。 可以理解为在游戏机上安装软件之前，需要先有主机系统一样， 在安装 MOD 本体之前，必须先在服务器和每位玩家的电脑上都导入 Fabric。

⚠ 最容易搞错的地方

MOD 不仅需要安装在服务器上，还需要每一位游玩者的电脑上都安装相同的内容。 并不存在"只要装在服务器上，就会自动反映给所有人"这种情况。 服务器与全体玩家的 Minecraft 版本、Fabric、MOD 组合必须完全一致， 否则将无法加入服务器。

谁需要准备什么

  • 服务器（Sorakazekarasu 服务器） — Fabric 服务端本体 + Fabric API + Glimpse Alpha 11 个 MOD
  • 每一位参与者的电脑 — Fabric 客户端 + Fabric API + Glimpse Alpha 11 个 MOD（与服务器完全相同的组合）
本站不提供 MOD 本体的下载

本站只刊载配方表、更新日志、导入教程等「阅读内容」， 并不提供 MOD 本体（jar 文件）本身的下载。导入所需的完整 jar 文件， 请向服务器管理员索取。

本页的结构

本指南按两种立场分别撰写。绝大多数人只需阅读 面向玩家的章节即可加入。 如果您是自行运营、管理服务器的一方，请接着阅读 面向服务器管理员的章节。

面向玩家

面向玩家：加入服务器所需的设置

这里说明的是准备加入服务器一方的设置方法，不需要任何高深的专业知识。 只要按顺序从上往下操作，大约 15〜20 分钟即可完成。

要做的事情只有 3 件
  • ① 在自己的电脑上安装 Fabric（读取 MOD 的基础平台）
  • ② 把从服务器管理员那里收到的整套 MOD 文件，放入指定的文件夹
  • ③ 只需改变一处启动方式，即可加入服务器

需要准备的东西

  • 能运行 Minecraft Java 版的 Windows 或 Mac 电脑
  • 从服务器管理员那里收到的 整套 MOD（共 12 个 jar 文件 = Fabric API 1 个 + Glimpse Alpha 的 11 个 MOD）
🛑 非常重要

必须与服务器的版本完全相同、MOD 文件完全相同才能加入。 本页以 Minecraft 版本 26.2 为例进行说明， 如果服务器管理员告知的是其他数字，请自行替换为该数字。 收到的 jar 文件请不要用双击打开，只需放入文件夹中即可使用。

① 安装 Fabric

打开 https://fabricmc.net/use/installer/，获取安装程序。保持在「Client」标签页（不要切换到「Server」），在 Minecraft Version 中选择与服务器相同的数字，然后点击「Install」。

Windows 的情况

  1. 点击页面上「Download installer (Windows/.exe)」这样的按钮下载安装程序，双击运行（如果出现「Windows 已保护你的电脑」，请点击「更多信息」→「仍要运行」）。
  2. 保持在「Client」标签页，Minecraft Version 选择 26.2（与服务器相同的数字），Loader Version 保持不变，点击「Install」。

Mac 的情况

  1. 点击「Download universal jar」按钮下载安装程序（.jar）。没有 Mac 专用的可执行文件（.exe）。
  2. 对下载好的 fabric-installer-〜.jar，不要用普通的双击，而是右键点击（或按住 control 键点击），选择「打开」。如果出现警告，请再次点击「打开」。
  3. 保持在「Client」标签页，Minecraft Version 选择与服务器相同的数字，点击「Install」。
⚠ 如果 Mac 提示「无法验证开发者」

在较新的 macOS 上，即使右键点击→「打开」也可能不会弹出按钮， 只会出现「无法验证"fabric-installer〜.jar"是否包含恶意软件」这样的警告。这种情况下可以按以下顺序打开。

  1. 在警告框中点击「完成」（绝对不要点击「移到废纸篓」）
  2. 打开屏幕左上角的苹果菜单 →「系统设置」→「隐私与安全性」
  3. 下方会显示「"fabric-installer〜.jar" 的使用已被阻止」，点击旁边的「仍要打开」
  4. 如果再次询问，选择「仍要打开」→ 输入 Mac 密码（或使用 Touch ID）

这是所有未在 Apple 注册的发布物都会出现的标准警告，只要是从 Fabric 官方网站获取的，就不必担心。允许一次之后，之后就能正常打开了。

如果 Mac 上安装程序毫无反应

如果右键点击→「打开」后毫无反应，说明系统中没有安装 Java。 请打开 adoptium.net，安装 macOS 版的「Temurin」安装程序（.pkg）后再试一次。 Apple 芯片（M1/M2/M3/M4 等）的 Mac 请选择「aarch64」，Intel 芯片的 Mac 请选择「x64」。 如果不确定，请查看屏幕左上角苹果菜单 →「关于本机」中的「芯片」一栏（如果显示「Apple M〜」则为 aarch64）。

② 把 MOD 文件放入 mods 文件夹

Windows：%appdata%\.minecraft\mods

  1. 在资源管理器的地址栏中输入 %appdata%\.minecraft，然后按 Enter。
  2. 如果没有 mods 文件夹，请新建一个（全部小写）。
  3. 把收到的全部 12 个 jar 文件都复制到这个 mods 文件夹中（不需要解压，以 jar 文件形式放入即可）。

Mac：~/Library/Application Support/minecraft/mods

  1. 先点击一次桌面，然后同时按下 ⌘ command+⇧ shift+G（或使用顶部菜单的「前往」→「前往文件夹…」）。
  2. 在弹出的输入框中直接粘贴 ~/Library/Application Support/minecraft，然后按 Enter（不要忘记开头的「~」）。「Library」是 Finder 中平时不显示的文件夹，用这种方法打开最为可靠。
  3. 如果没有 mods 文件夹，请在当前位置右键点击→「新建文件夹」来创建。
  4. 把收到的全部 12 个 jar 文件，用拖放的方式放入这个 mods 文件夹。

③ 用 Fabric 启动并加入服务器

  1. 打开 Minecraft 启动器，在「play」按钮附近的启动配置（配置文件）列表中，选择类似 fabric-loader-26.2 这样的名称（如果保持「最新版本」不变，将会以无 MOD 的状态启动）。
  2. 直接点击「play」启动。如果标题画面上出现了「Mods」按钮，就说明成功了，点击它可以确认 Glimpse Alpha 的 11 个 MOD 与 Fabric API。
  3. 之后照常从「多人游戏」连接到服务器即可。

当 MOD 更新时

如果服务器一侧的 MOD 更新了，所有参与者需要同时更新到相同的版本。

  1. 从服务器管理员那里收到新的 MOD 文件（请等待通知后再进行操作）。
  2. 打开 mods 文件夹，先删除此前放入的 Glimpse Alpha 的 jar 文件，再放入新文件（即使文件名有变化，内部也会被当作同一个 MOD 处理，如果旧文件残留，将无法启动）。
  3. 照常使用 fabric-loader 的配置文件启动。
⚠ 注意

如果只有一方停留在新版本，将无法加入服务器。遇到困难时，请查阅常见问题。

面向服务器管理员

面向服务器管理员：前期准备（备份与版本确认）

从这里开始是面向运营、管理服务器本体一方的章节。本章说明的是从已经运行着 Minecraft 服务器（原版、无 MOD 的标准服务器）的状态出发，添加 Fabric 与 Glimpse Alpha 11 个 MOD 的步骤，以 Windows 服务器为例进行说明。 如果您使用 Mac / Linux 运营服务器，请将文件夹位置与命令执行方式替换为自己的 环境，并参照相同的步骤（Fabric 官方网站的说明）进行操作。

🛑 作业前请务必执行

为了防止即使 MOD 导入失败也不会丢失世界，请务必先备份，再开始作业。

1. 备份世界

打开服务器文件夹（例如 C:\MinecraftServer），执行平时使用的备份步骤（例如 Backup-Server.bat 这样的备份脚本）。如果没有专用脚本，只需在服务器停止的状态下，把整个 world 文件夹复制到别处即可。

2. 确认 Java 版本

  1. 打开命令提示符（或任意终端）。
  2. 输入 java -version 并按 Enter。
  3. 确认显示的数字是否为 25（例如：java version "25.0.3"）。
🛑 非常重要

运行 Minecraft 26.2 需要 Java 25。旧的搭建步骤中有时会写着 「Java 21」，但这是过时的信息，如果保持 Java 21 不变，服务器将无法启动。 如果数字低于 25，请打开 adoptium.net， 下载并安装「Temurin 25 (LTS)」，然后重启电脑再次确认。

3. 确认服务器的 Minecraft 版本

  1. 用平时的方法（例如 Start-Server.bat）先启动一次服务器。
  2. 在控制台（黑色画面）开头附近寻找类似 Starting minecraft server version X.Y 的一行，记下其中的数字。
  3. 在控制台输入 stop 并按 Enter，安全地停止服务器。
⚠ 注意

本指南以「26.2」为例进行标注，如果您实际确认的数字不同， 请将后续所有步骤（Fabric、Fabric API、MOD 各版本的选择）都替换为该数字。 服务器、全体玩家、MOD 的版本哪怕只有一处不一致，都将完全无法运作。

面向服务器管理员

面向服务器管理员：导入 Fabric

安装 Fabric 服务端

  1. 在浏览器中打开 https://fabricmc.net/use/server/，点击「Download installer (Windows/.exe)」这样的按钮下载安装程序。
  2. 双击下载好的 fabric-installer〜.exe 启动（如果出现「Windows 已保护你的电脑」，请点击「更多信息」→「仍要运行」）。
  3. 在安装程序的设置画面中确认以下 4 点。
    • 标签页选择「Server」
    • Minecraft Version 选择与前期准备中确认的服务器版本相同的数字（例如 26.2）
    • Loader Version 保持不变即可
    • Install Location 指定为现有的服务器文件夹（例如 C:\MinecraftServer）
  4. 点击「Install」。
  5. 如果服务器文件夹中生成了名为 fabric-server-launch.jar 的新文件，就说明成功了。

新建启动用文件（批处理文件）

此前的启动用文件（例如 Start-Server.bat）是用来启动「无 MOD」状态的文件。 请不要删除它，将其保留下来（以便万一需要时能恢复无 MOD 状态）。 另外新建一个用于 Fabric 的启动文件。

  1. 打开记事本（Notepad）。
  2. 直接复制粘贴以下内容。 
    @echo off
cd /d "%~dp0"
title Minecraft Fabric Server
java -Xms2G -Xmx4G -jar fabric-server-launch.jar nogui
echo 服务器已停止。
pause
  3. 选择「文件」→「另存为」，保存位置选择服务器文件夹（例如 C:\MinecraftServer），文件名设为 Start-Fabric-Server.bat，文件类型选择「所有文件」后保存。
⚠ 注意

如果不把「文件类型」设为「所有文件」，就会变成 Start-Fabric-Server.bat.txt 这种无法运行的文件。另外，如果搭建服务器时分配的内存（RAM）不是 4GB，请把 -Xmx4G 中的「4」改写为对应的数字。

面向服务器管理员

面向服务器管理员：导入 MOD 与启动确认

MOD 本体是名为「jar 文件」的单个文件，只需将其放入服务器文件夹的 mods 文件夹中即可完成导入。

1. 准备 mods 文件夹

确认服务器文件夹（例如 C:\MinecraftServer）中是否有名为 mods 的文件夹。如果没有，请右键点击→「新建」→「文件夹」，创建一个名为 mods（全部小写）的文件夹。

2. 获取 Fabric API

打开 https://modrinth.com/mod/fabric-api/versions，从列表中下载「Game version（游戏版本）与服务器相同数字」中排在最上方的那一个（例如 fabric-api-0.154.2+26.2.jar）。

3. 把整套 MOD 放入 mods 文件夹

把 Fabric API 1 个 + Glimpse Alpha 的 11 个 MOD，合计 12 个 jar 文件，复制到 mods 文件夹中（不需要解压，以 jar 文件形式放入）。这 11 个 MOD 本体，请按照以往的 发布渠道获取。本站不提供 MOD 本体本身的下载。

MOD文件名示例
枪械glimpse-alpha-guns-…+mc26.2.jar
铁道glimpse-alpha-rail-…+mc26.2.jar
建材、装饰glimpse-alpha-deco-…+mc26.2.jar
载具glimpse-alpha-vehicles-…+mc26.2.jar
Bossglimpse-alpha-boss-…+mc26.2.jar
天空glimpse-alpha-sky-…+mc26.2.jar
生存glimpse-alpha-survival-…+mc26.2.jar
电力glimpse-alpha-power-…+mc26.2.jar
后室glimpse-alpha-backrooms-…+mc26.2.jar
二相乐园glimpse-alpha-planarcadia-…+mc26.2.jar
⚠ 注意

请不要双击 jar 文件（不需要打开），只需放入文件夹中即可。

4. 启动服务器进行确认

  1. 双击刚才创建的 Start-Fabric-Server.bat（不再使用此前的 Start-Server.bat）。
  2. 在控制台（黑色画面）中确认以下 2 点。
    • 在读取 MOD 的那一行中，出现了已导入的 MOD 名称
    • 最后显示了 Done (…s)! For help, type "help"，并持续运行、没有停止
💡 出现 Java 错误无法启动时

如果出现「class file version」「requires Java」这样的英文错误，Java 版本可能过旧。 请从 adoptium.net 安装「Temurin 25 (LTS)」的 Windows 版（.msi）， 重启电脑后再试一次。

确认启动成功后，接下来请把面向玩家的章节分享给所有参与者， 让他们也在各自的电脑上导入相同的 Fabric、整套 MOD。

面向服务器管理员

更换 MOD 新版本时

Glimpse Alpha 的 11 个 MOD 彼此完全独立，因此不一定每次更新都会同时替换全部 11 个。 只需替换实际内容有变化的 MOD 即可 （哪些 MOD 有变化，可以在发布时的说明或更新日志中确认）。

更新步骤

  1. 在服务器控制台输入 stop，停止服务器。
  2. 按照平时的备份步骤备份世界。
  3. 在服务器的 mods 文件夹中，删除更新对象 MOD 的旧 jar 文件，放入新的 jar 文件（如果同一个 MOD 的新旧文件都残留着，将无法启动）。
  4. 用 Start-Fabric-Server.bat 启动服务器，确认控制台中显示了更新后的版本。
  5. 把新的 jar 文件分发给全体参与者，让他们也照样替换（参见面向玩家的章节）。如果只有服务器一方、或只有玩家一方更新到新版本，将无法加入。
🛑 非常重要

如果在完全移除某个 MOD（而非更新）的状态下启动服务器，该 MOD 所放置的方块与 持有的物品（信号灯等）都会消失。这是 Minecraft、Fabric 的规格所致，无法恢复。 移除之前请务必先进行备份。

关于 config 文件（自动修复机制）

各个 MOD 会在启动时自动在 config/ 文件夹中生成设置文件（例如 sorakaze_guns.json）。 威力、速度等数值可以在这里调整，原则上不需要在每次更新时手动删除或改写。

💡 目前的机制

在新版本中默认值发生变化的项目，仅限于尚未调整过（保持旧默认值）的项目， 才会自动更新为新的默认值。不会触碰您自己调整过的数值。 新增的设置项也会在启动时自动补充。哪些项目被更新过， 都会以「旧值 → 新值」的形式记录在 logs/latest.log 中。

⚠ 编辑设置文件时的注意事项

如果只手动删除设置文件中的一部分数值（例如：从某个武器的设置区块中 只删除伤害那一行），该项目有可能会被静默替换为 MOD 内部的另一个初始值 （不会报错）。想要调整特定数值时，请直接改写该项目的值。 如果想把设置整体恢复为初始状态，删除对应 MOD 的整个设置文件即可，下次启动时会以 默认值重新生成。

开始游玩前需要了解的注意事项

Glimpse Alpha 包含一些会影响原版行为的变更，本页汇总了其中特别容易被忽视的部分。 由于细节数值可能随每次更新而调整，请同时查阅 更新日志与已知问题页面 以确认最新情况。config 的调整由服务器管理员进行。

红石需要「电力」

由于导入了电力 MOD，原版红石的一部分将无法单独运作。

  • 变得需要电力的：红石粉、中继器、比较器、红石块、红石火把。这些装置在用电缆接通电力之前不会发出信号。自动农场、车站、自动门、漏斗队列，在布线之前都会保持停止状态。
  • 没有电力也能照常使用的：拉杆、按钮、压力板、绊线钩、侦测器、阳光传感器、幽匿感测体、标靶、陷阱箱、探测铁轨、讲台、唱片机、避雷针等。手动开关门与栅栏门的操作也能照常使用。
  • 放置约 10 分钟后，红石块会自然损毁（以物品形式回到手中）。
💡 恢复原状的方法（面向服务器管理员）

把 config/sorakaze_power.json 中的 powerEnabled 设为 false， 即可整体禁用红石的电气化。

建材、装饰的部分设备也需要电力

监控摄像头、电梯、扶梯、自动门、ATM 这 5 种设备，如果没有用电缆接通电力将无法运作 （电梯即使没有电力，也设计为只有「下降」能够运作）。 可以把 config/sorakaze_deco.json 中对应设备的项目设为 false，从而单独取消该设备的电力需求。

发电机会让房间变热

运转中的发电机、核电站会提升同一空间的气温，唯一能够降温的是空调。 用墙壁和关闭的门把机械室隔开，热量就不会扩散到其他房间，是最简单的对策。 这项功能本身可以通过把 config/sorakaze_survival.json 中的 temperatureMachineHeatEnabled 设为 false 来禁用。

天空维度导致世界高度被扩展

由于导入了天空 MOD，主世界（Overworld）可建造的高度上限被提升了。 变化的只是天空一侧的上限，地下深度（世界底部的高度）与既有地形均保持不变。

火箭筒会破坏地形

枪械 MOD 中的火箭筒，在默认设置下会破坏命中地点的地形。 即使把原版游戏规则 mobGriefing 设为 false 也无法阻止。 要停止破坏，需要把 config/sorakaze_guns.json 中的 rocketDestroysTerrain 设为 false。请在据点附近格外注意。

关于枪械的火力

枪械 MOD 的武器，特别是突击步枪，拥有非常高的火力，MOD 新增的许多 Boss 数秒内就会被打倒。如果想要更有挑战性，服务器管理员可以通过 调整 config/sorakaze_guns.json 中各武器的伤害数值来恢复难度。

移除 MOD 后，放置的方块、物品会消失

这是 MOD 的通用规格，并非 Glimpse Alpha 特有的问题。在导入 MOD 的状态下 放置的方块或获得的物品，一旦移除该 MOD，就会从世界中消失。要恢复原状， 只能从备份中还原。

服务器无法启动时

  1. 先把 mods 文件夹中的所有内容都转移到别处。
  2. 一次放回一个文件并反复启动，以确定是哪个文件导致的问题。
  3. 如果出现 Java 相关的错误，请参考前期准备章节确认 Java 版本。

能进入服务器控制台但无法连接时

  1. 确认所有参与者的版本与 MOD 组合，是否与服务器完全一致。
  2. 特别是 Fabric API 的版本不一致很容易导致此问题，请优先确认。
💡 如果仍然无法解决

请把 logs/latest.log 发送给服务器管理员咨询。不用着急，只要有备份，随时都能恢复到原来的状态。

从备份还原世界的方法（面向服务器管理员）

  1. 在服务器控制台输入 stop，停止服务器。
  2. 从备份保存位置（例如 C:\MinecraftServer\backups）中取出最新的备份（如果是 zip 格式，右键点击→「全部解压」）。
  3. 用取出的 world 文件夹，替换服务器文件夹中的 world 文件夹（覆盖）。
  4. 启动服务器。
