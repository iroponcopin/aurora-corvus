后续计划

本页根据开发方的需求文档，介绍目前计划中的下一次更新内容。

本页内容尚未实装、尚未发布。这些介绍基于内部的企划备忘录，实际实装的内容、时间与规格都可能发生变更甚至取消。确定后的内容会体现在「更新日志」页面中。

计划中 V2.2

V2.2（下一次。尚未着手，内容与日期均未确定）

札幌 MOD（自 V2.1.0 顺延）

  • 札幌 MOD（sorakaze_sapporo）未包含在 V2.1.0 中，顺延至 V2.2。
  • 在它随包发布之前，需要安装的 jar 数量不会增加。目前仍然是 Fabric API 1 个 + Glimpse Alpha 的 11 个。

自 V2 顺延的部分

  • 下方「V2 更新」卡片中仍然列出的项目 —— 水流机制本身的重做、新的天气与灾害、枪械的平衡与音效、金钱相关系统、后室怪异的重绘等 —— 将继续在这里处理。
  • 这些都还处于构想阶段。只有真正做出来并发布的内容才会出现在更新日志中。
计划中 V2

V2 更新（部分已在 V2.0.0、V2.1.0 中发布。此处留下的是尚未发布的部分）

本计划中已经发布的部分

  • V2.0.0（2026-08-18）已发布：二相乐园的入口与传送门紫水晶方块；4 个新 Boss 及其召唤仪式；瘟疫医生与收割者相关调整；自来水设施（水管、水泵、水龙头）；冰箱与食物腐坏；汽油与油桶；空气净化器与核电站的空气污染；防护服；面具破损后仅能自行修复一次的机制。
  • V2.1.0（2026-08-22）已发布：后室层级 3〜8（从示范小岛变为真正的无限层级）；电脑上的服务器管理应用（含自动备份设置）；Boss 召唤配方进入配方书与 4 个发现进度；3 把数据定义枪械的专属模型。
  • 详细内容请见「更新日志」页面。以下列出的，是这两次更新尚未发布的部分。

建材MOD:修复视频应用的问题、翻新终端设备外观

  • 计划修复视频应用中播放、暂停、快进/快退操作无法正常工作的问题(最优先的漏洞修复)。
  • 计划修复退出服务器或移动到其他世界后音频仍持续播放的问题。
  • 计划修复有声音但没有画面(画面一直黑屏)的问题。
  • 构想基于新的设计方案,全面重做iPhone、MacBook、蓄电池的外观。

水系统的重新设计、生活基础设施

  • 构想放弃原版的水流行为,改为从高处向低处物理性、自然流动的机制(取消在平地上无限横向扩散的现象,改为让水积存在低洼处)。
  • 计划新增连接水源到水龙头的整套供水基础设施,包括水管、水泵、给水口等。
  • 水壶容量将提升至现有的4倍。口渴度的下降速度预计会略快于饱食度,口渴状态持续10分钟后,若没有生命恢复效果,将开始累积伤害,可能致命。
  • 计划新增自动备份功能,管理员可通过UI设置备份间隔、保存数量和保存位置(操作说明也将发布在本站)。

枪械MOD:平衡性调整、音效翻新

  • 正在研讨的调整方案:机枪性能+50%,突击步枪+75%,手枪威力1.5倍,冲锋枪伤害减半但弹匣容量+30%,火箭筒伤害与爆炸威力均提升至3倍,炮塔伤害提升至4倍且耐久+70%。
  • 构想将核弹头的破坏规模提升至最多可破坏1000万个方块,导弹弹头的爆炸威力与范围均提升至3倍(预计以核弹头当前的威力为基础,即v1.8.8时点直击伤害67200)。
  • 计划修复使用火箭筒瞄准镜时本体模型遮挡视野的问题。
  • 构想全面重做枪声(据说不会直接使用某些现有游戏的音源,而是制作方向相近的全新音效)。
  • 构想新增3种新设计的导弹发射器,且均可由玩家操控使用。

Boss MOD:新增4只Boss、调整现有Boss

  • 计划新增4只Boss:「火山傀儡王」(HP600)、「深渊克拉肯守卫」(HP800)、「棱彩冰凰龙」(HP750)、「凋灵风暴恶魔霸主」(HP1200,击败以上3只为召唤条件)。构想均配有专属召唤道具与阶段制战斗。
  • 正在研讨瘟疫医生的新规格:被击中后到召唤凋灵风暴之间设置20秒的宽限时间,若在20秒内(或一击)将其击败可阻止召唤,但也将无法获得掉落物。
  • 构想死神Boss(冥界收割者)被击败时有低概率掉落专属武器「夺魂镰刀」,用该镰刀击杀敌人时有低概率获得刷怪蛋。同时计划将Boss自身强度提升+15%,新增3种攻击模式。
  • 构想进一步强化凋灵风暴,新增第二形态(阶段)变化。

生存·电力:污染系统与新的搬运动作

  • 预计核弹头命中的地点将进入为期20个我的世界日的「污染」状态。构想是同时装备防毒面具与防护服即可无害化。
  • 正在研讨的机制:持续运行核能发电机会污染周围空气,若无对策长时间停留其中会影响身体状况。计划新增运行后可净化周围污染的新方块「空气净化器」(支持多台同时运行)。
  • 计划让村民、鸡等小型生物可以用手搬运。
  • 正在研讨不破坏箱子即可双手搬运的功能(内容物保持不变。双箱预计需要2人协力搬运)。
  • 计划新增耐久32、攻击力200的新道具(暂定名称)。正在研讨与魔杖相同机制的远程攻击。

银行UI·后室·网站联动

  • 计划将ATM、Mine Bank的存款上限提升至1000万绿宝石。构想为ATM界面套用「Glimpse Alpha Glass」的设计元素,全面翻新UI。
  • 计划新增全新的「Mine Bank UI」(据说已有设计方案,配备根据余额显示的25%/50%/75%/MAX快捷选择,以及以1/10/100/1k为单位调整的滑块操作)。
  • 构想基于新的设计参考图,全面重做后室怪异(怪物)的外观。
  • 构想建立一套机制,在今后更新内容确定时能自动反映到本站的更新履历中(此项属于本站自身运营相关事宜)。
